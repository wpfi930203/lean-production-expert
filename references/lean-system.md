## 2. 概念地基

| 概念 | 定义 | 判据 / 量化阈值 | 易混淆点（什么不是它） |
|---|---|---|---|
| **精益生产** | 通过持续改进识别和消除所有产品和服务中浪费/非增值作业的系统方法；最大限度减少企业生产占用资源、降低管理运营成本 | 看"人均提案数"这类软性差异：世界级 61.6 vs 一般 0.4 | ≠ 一套工具合集。赶时髦、随机挑工具（cherry-picking）必然失败 〔9.LEAN-精益培训〕 |
| **TPS 两大支柱** | ① **JIT**：不采取预测性或计划性生产，仅接到客户订单之后才依订单数量、交货时间生产；② **自働化**（人字边的自动化）：赋予机器以人的智慧，机器可判断正常/异常并自动停机 | JIT 三要素在生产端落地为："看板 1 枚单位的多回搬运与补充生产""流动化、工程间整流化""一个一个按 Takt time 制造、不打乱顺序" | ≠ 自动化（Automation）。自働化 = 自动化 + 异常停机（省人），不是买贵设备 〔3.精益生产培训资料；8.精益生产管理（理念1）〕 |
| **精益五原则** | 价值 Value → 价值流 Value Stream → 流动 Flow → 拉动 Pull（BTR 按需求生产）→ 完美 Perfect | 第 1 条即判据：**价值只能由最终用户确定**；第 4 条判据：后工序需求拉动，而非按预测推动 | 顺序不可颠倒：不先定义价值就画价值流，等于给错误的产品做优化 〔4.精益思想与精益生产体制 Slide19〕 |
| **增值 vs 非增值** | 应有型态：物料在流动过程中增加其附加价值；现状型态：物与情报的停滞是没有附加价值的浪费 | 增值比 = 增值时间 /（生产周期天数 × 每日工时）；实测例 1.5/(11×16)=0.85% | ≠ "忙就是增值"。让物料/机器不停动而人在等，是典型反例 〔9.LEAN-精益培训〕 |
| **真效率 vs 假效率** | 真效率 = 以最少人员生产出仅需的产品；假效率 = 固定人员生产出更多产品（造成在库） | 需求 100 件/天时：10 人做 120 件 = **假效率**；8 人做 100 件 = **真效率** | ≠ 单件成本下降。超产被丰田视为最严重的浪费形式 〔4.精益思想与精益生产体制 Slide81-83；8.精益生产管理（理念35）〕 |
| **库存是万恶之源** | 库存掩盖交货、质量、效率、维修问题 | 库存隐藏 6 类问题：设计不良、机械故障、产品不良、材料不良、产能不均、人员过多 | ≠ 库存=安心。高库存求安心只会让问题晚爆发 〔9.LEAN-精益培训；4.精益思想与精益生产体制 Slide99〕 |
| **3M Loss** | Muda（無駄：浪费）、Muri（無理：勉强/难度大）、Mura（ムラ：不平衡/不均匀） | 现场排查三问：有没有浪费多？有没有多余或欠缺？有没有不合理多？ | ≠ 只盯 Muda。忽略 Muri/Mura 会导致"消浪费→造超负荷" 〔4.精益思想与精益生产体制 Slide22；6.精益-持续改善\1.创意功夫（现场3多）〕 |
| **拉动 vs 推动** | 拉动：只做客户需要的、按时按量；推动：按预测生产 | 拉动特征 = 小批量、可视的生产现场管理、尽可能减少浪费、良好沟通、准确真实的信息；推动特征 = 大批量、隐藏问题、浪费、低效沟通、估计 | ≠ 有看板就是拉动。看板规则第 9 条：不向后工序传送不合格品 〔3.精益生产培训资料〕 |
| **利润=售价−成本** | 利润中心思想：售价由市场定，成本可无限降低 | 三种经营思想：成本中心 / 售价中心 / 利润中心；传统"售价=成本+利润"仅适用卖方市场 | ≠ "成本+利润=售价"。后者在买方市场直接失效 〔4.精益思想与精益生产体制 Slide7-8〕 |
| **前置时间 L/T** | 工厂从受订之后到制品出货为止的时间；生产前置时间 = ①情报前置时间 + ②制造前置时间 | 见 §4 公式表（三版分解式） | ≠ 生产周期/加工时间。L/T 含**停滞**，MCT 只含物料进厂—加工—成品出厂 〔6.精益-持续改善\3.物与情报流程图〕 |
| **改善 vs 革新** | 改善 = 用小的变化累计起来；革新 = 大的变化、大的成果 | 改善：一点点、常时通常能力、该做的正正当当做、容易/危险小；革新：独创性创造性、特别能力·很大投资、很费劲 | ≠ 二选一。精益主战场是改善（每天一点点） 〔6.精益-持续改善\2.改善精神〕 |

## 3. 方法/工具逐项展开

### 3.1 TPS 两大支柱与精益生产体系（总纲）

- **定义/目的**：解释"为什么精益"与"精益包含哪些支柱"，作为一切精益工具的结构定位图。
- **触发条件**：要向管理层/全员做精益导入宣讲；要判断自家工厂缺哪一块（工具选型前）。
- **操作步骤**：
 1. 讲清两大支柱：JIT（准时生产）+ 自働化（人字边的自动化）。
 2. 讲清系统特点 4 项：① 拉动式准时生产（以最终需求为生产起点，强调物流平衡，追求零库存，上一道工序完的零件立即进入下一道工序）；② 全面质量管理；③ 团队工作方法；④ 并行工程。
 3. 画出 **JIT 技术体系构造（自下而上）**，作为推行顺序：
 企业教育·开发人力资源（5S）→ 全面质量管理·防错体系 → 低成本自动化 LCIA → 设备快速切换 SMED → 设备合理布置 LAYOUT → 标准作业/作业标准 → 多能工作业员 → 良好的外部协作 → 不断暴露问题不断改善 → 尊重人性发挥人的作用 →（看板管理·质量保证·小批量生产·均衡化生产·同步化生产）→ JIT 生产方式 →（消除浪费降低成本、柔性生产提高竞争力）→ 公司整体性利润增加。
 4. 收口一句 TPS 精髓："基于内部的团队式工作方式，在外部企业密切合作的环境下，无限追求物流的平衡。"
- **量化口径**：（语料未覆盖）
- **判读与决策**：若企业连 5S 与标准作业都没有，直接上"看板/拉动"必然失败——按体系构造自下而上补齐。
- **常见错误/反例**：把精益当工具箱随机挑（见 §7 A1）。
- **出处**：〔出处：8.精益生产管理（背后的36个理念）（理念1）；3.精益生产培训资料；9.LEAN-精益培训-精讲+案例介绍〕

### 3.2 精益五大原则（精益思想）

- **定义/目的**：精益思想的总纲，任何改善以此为出发点。
- **触发条件**：任何改善项目启动前，用来校验"我们改的是不是客户认为的价值"。
- **操作步骤**（五步，顺序不可乱）：
 1. **价值 Value**：站在客户的立场上；价值只能由最终用户确定。
 2. **价值流 Value Stream**：从接单到发货过程的一切活动；找出价值流并消除浪费。
 3. **流动 Flow**：像开发的河流一样通畅流动；使保留下来的可创造价值的各个步骤流动起来，彻底消除"等待"。
 4. **拉动 Pull（BTR—按需求生产）**：按下工序的需求进行生产。
 5. **完美 Perfect**：没有任何事物是完某家电企业，不断改进（降低成本、改善质量、缩短生产周期）。
- **量化口径**：（语料未覆盖）
- **判读与决策**：如果"价值"定义错了（美国式财务中心型/德国式产品技术中心型/日本式地域观等曲解），后面四步越努力越偏。
- **常见错误/反例**：价值提供者替客户定义价值，做出过剩品质（§7 A8）。
- **出处**：〔出处：9.LEAN-精益培训-精讲+案例介绍；1.精益意识导入培训；4.精益思想与精益生产体制〕

### 3.3 精益生产六大要素（自检清单）

- **定义/目的**：评估一个工厂精益要素的完整度，作为推行框架。
- **触发条件**：做精益现状诊断/要素体检时。
- **操作步骤**：逐项打分（六要素互为支撑，以"利润和效益"为目标）：
 1. **流畅生产 Flow**——基于时间的过程，拉动物料按用户要求速度不间断通过产线；含产品生产周期、价值流分析、客户节拍、生产周期分析、人工平衡。
 2. **工作场地组织 Workplace Org / 5S**——清理、整理、清洁、维护、自律。
 3. **质量 Quality**——质量计划、质量控制、质量改进三策略。

- **量化口径**：（语料未覆盖逐项评分标准）
- **判读与决策**：六项里哪项最低，就从哪项立项；单项突破（如只做 5S）不构成精益。

### 3.4 流线化生产 8 条件 + 精益布局五模式

- **定义/目的**：把批量生产改造成流线化生产，并选择适配单件流与多品种小批量的产线布局。
- **触发条件**：在制品堆积、生产周期长、搬运距离长、换型多但订单零散。
- **操作步骤**：
 1. **流线化 8 条件**逐条对照：① 单件流动；② 按工艺流程布置设备；③ 生产速度同步化；④ 多工序操作；⑤ 员工多能化；⑥ 站立作业、走动作业；⑦ 设备小型化；⑧ 生产线 U 形化（IO 一致原则）。
 2. **五模式选型**：① 串联式布局；② 并联式布局；③ U 型布局；④ 单元化布局（细胞/Cell Line）；⑤ V 型/L 型布局。
 3. **实现精益布局 11 步**：

 4. **宏观路径**：宏观布局（定位）→ 线体/物流方案设计 → 工位局部优化 → 布局实施 → 恢复生产（适应期）→ 产能提升。
- **量化口径**：
 - 物流路线分析取**距离最短原则**；语料散点数据：单元宽度约 1.5m、物流路线长 190m（未成体系，见 §9）。
- **判读与决策**：连续流无法向上游扩展时，用**超市控制方式**过渡；IE 部门根据价值流分析混合作业以满足柔性生产。
- **常见错误/反例**：只搬设备不改人（§7 A15）；各部门本位主义、局部利益最大化（§7 A13）。
- **出处**：〔出处：4.精益思想与精益生产体制 Slide28-36；7.精益布局lean layout；6.精益-持续改善\4.精益布局〕

### 3.5 3M Loss（三种损失）

- **定义/目的**：从"浪费/超负荷/不均衡"三个维度识别问题。
- **触发条件**：现场巡检、发现"某工位特别累"或"某时段特别忙"时。
- **操作步骤**：对每个工序/工位问三句：① 这里有没有浪费（Muda）？② 这里有没有超负荷/勉强的动作或安排（Muri）？③ 这里有没有负荷不均、时间不均（Mura）？
- **量化口径**：现场 3 多的量化排查对象——**人员、技能、时间、设备、工具、材料、场所、方法、产量、库存**，逐项判断"是否浪费多、是否多余或欠缺、是否不合理多"。
- **判读与决策**：Mura 先于 Muda 解（不均衡是浪费的制造源）；Muri 一旦出现，必须立即停手改设计，不能靠"员工努力"顶。
- **常见错误/反例**：只消 Muda，把负担转嫁给员工造成 Muri。
- **出处**：〔出处：4.精益思想与精益生产体制 Slide22；6.精益-持续改善\1.创意功夫〕

### 3.6 七种浪费（识别清单）

- **定义/目的**：通过七大浪费的检查得出改善目标与方案。
- **触发条件**：立项找改善主题；创意功夫提案无题可提时。
- **操作步骤**：逐条排查七项（含语料给出的"之最"定性）：
 1. **做太多的浪费（最坏的浪费）**——如增设机械设备、材料随便乱用、作业员多余、利息增加、摆放区或仓库扩大。
 2. **等待的浪费（最迟的浪费）**——材料、作业、设备的等待、作业宽放、监视设备、加班最多。
 3. **搬运的浪费（最长的浪费）**——拿取、摆置、搬运、反复点数目后再重新排放。
 4. **加工本身的浪费（最深的浪费）**——有没有没目的的作业？有没有不知所以然的作业？
 5. **库存的浪费（最大的浪费）**——库存虽是可以让人安心的良药，也会制造出许多不良。
 6. **动作的浪费（最多的浪费）**——不必要的动作、无附加值的动作；善用动作要素细分法。
 7. **制造、整修不良的浪费（品质不佳、过剩浪费）**——材料不合格、加工不够严谨、检验敷衍了事、索赔不甚积极、多余作业、多余材料、不良品堆积如山。
- **量化口径**：超产（"做太多"）在丰田体系中是**最严重的浪费形式**；按订单数量、不多不少、平稳运转。
- **判读与决策**：提案选题优先打"做太多"和"库存"——它们的杠杆最大；动作浪费最多，适合全员提案。
- **常见错误/反例**：把超产当好事（§7 A6）；只改善"结果"不追"原因"（§7 A9）。
- **出处**：〔出处：6.精益-持续改善\1.创意功夫（第二章第一节）；8.精益生产管理（理念35）〕
- **补充**：本模块语料只给出七项名称与定性，**逐项定义/案例的完整版在 02 分册（11.七大浪费）**。

### 3.7 增值与非增值判定 / 降本杠杆

- **定义/目的**：把"能不能创造利润"当作判定真效率的唯一标准，避免在无需求的地方做效率。
- **触发条件**：要评估"某个效率提升是否值得做"；要做降本测算。
- **操作步骤**：
 1. 先问：这项工作/这台设备产出的东西，有订单吗？→ 有 = 增值前提；无 = 在库。
 2. 再看负荷：整体效率是否受瓶颈制约（水桶效应）。
 3. 最后算钱：用"减少浪费=增加利润"的杠杆效应测算（见案例 C1）。
- **量化口径**：
 - **利润=售价−成本**；售价中成本占 **90%**、利润占 **10%** 时，剥离总成本 **10%** 的浪费 ≈ 利润翻倍（"减少一成浪费就等于增加一倍销售额"）。
 - **整体效率判据**：工序能力 100/125/80/100 件/H，需求 100 件/H → 工序 3、4 为低效率瓶颈。
 - **真/假效率判据**：需求 100 件/天，10 人做 120 件 = 假效率；8 人做 100 件 = 真效率。
- **判读与决策**：
 - 出现"固定人数/固定设备，产出超过需求"→ 立刻减人/减机，而不是表扬。
 - 出现个别工序效率高但整体不涨 → 去瓶颈工序（§3.15）。
- **常见错误/反例**：计件工资追个别效率（§7 A5）；让员工忙着让机器工作（§7 A3）。
- **出处**：〔出处：3.精益生产培训资料（大野耐一）；4.精益思想与精益生产体制 Slide81-85；9.LEAN-精益培训〕

### 3.10 改善六大步骤 / 改善九阶段与 QC7 手法

- **定义/目的**：解决单个改善课题的通用流程；标准化的"改善项目阶段 ↔ 统计工具"对应表。
- **触发条件**：任何单个改善课题立项。
- **操作步骤**：
 - **改善六大步骤**：
 1. **发掘可改善点**——关注：工作方面有无浪费/不合理？KPI 是否达成？QCD 方面有无问题或隐患？工具操作有无不便？身边的异常及不合理现象。
 2. **现状调查分析**——立即调查、收集资料分析，做到：① 了解改善的重要程度；② 掌握改善的关键因素；③ 制定改善的目标。
 3. **改善思路整理**——排除法（不做不必要的工作，如把板卡类包装搬到 2 楼单板加工处，省去不增值的搬运且防止混板）/ 逆向法（如把磅秤陷入洞中与地面平齐）/ 对比法（如橡皮章姓名固定、日期可调）/ 替换法（如用电批代替手工打螺丝）。
 4. **拟定改善方案**——必含四要素：责任人（谁做？哪个部门支援？谁验收？）/ 方法（详细改善方法及验证方法）/ 时限性（何时开始、何时必须完成）/ 量化目标（目标值是多少）。
 5. **方案实施**——获得上司认可及支持；知会相关部门；明确职责；掌握进度及新问题点；控制实施成本；接收各方建议。
 6. **效果确认**——追踪、让效果维持、并从中寻找新的改善点。
 - **改善九阶段 ↔ QC7 手法**：1.Theme 设定 → 2.目标设定 → 3.推进计划 → 4.原因分析 → 5.改善案商定 → 6.改善案实施 → 7.结果确认 → 8.标准化 → 9.事后管理；对应 Plan / Do / Check / Action。
- **量化口径**：无量化阈值；但方案第 4 步的"量化目标"是强制项。
- **判读与决策**：第 6 步若无人跟催 = 改善归零；标准化的输出物是修订后的作业标准。
- **常见错误/反例**：只拉结果不拉原因（§7 A9）；只用一个对策案、像撞窗的苍蝇（§7 A10）。
- **出处**：〔出处：6.精益-持续改善\1.创意功夫（第三章）；6.精益-持续改善\2.改善精神〕

### 3.11 物与情报流程图（JIT 前身 · 前置时间诊断主力工具）

- **定义/目的**：从物与情报的流动中发现"**停滞**"（=问题），统一用时间尺度度量，缩短前置时间。
- **触发条件**：交期长、库存高、前后工程衔接乱、要提升 JIT 水平但不知从哪下手。
- **操作步骤**：
 1. **掌握现状**：用自己的眼睛以现地现物掌握事实（也调查"为什么变成这个样子"），**从后工程依序往前进工程追溯**。
 2. 按 **7 个观察点** 逐项调查并画图：
 - **① 贩卖（订购）的情报**：①-1 情报如何传递（看板 or 指示、FAX）？①-2 频度是多少（看板系数 or 回数）？E 看板何时到达？①-3 做到平准化的贩卖了吗（彻底调查看板张数有无变异：顾客别、便单位别、品番别）？
 - **② 交货物流**：②-1 理货场、出货场是怎么样的相互关系？②-2 到最终目的地为止是怎么样搬运的（直接还是经由中转站、中转场所的停滞如何、便与便之间是否等间隔）？
 - **③ 理货的做法**：③-1 是否有从生产线领取的方法（看板 or 指示清单 or 没有）？③-2 对理货情报加工的方法与时机（平准化 or 集中；何时开始领取、何时结束）？③-3 引取的频度和领取的量如何（定量 1 箱单位＝小批量引取；多回领取＝定时每隔 15 分）？
 - **④ 完成品及材料的放置方式**：④-1 置场是什么形态（店面按品番别 or 依顺序排列的置场 or 其他）？④-2 完成品的正面数（种类）、深度（在库量）；④-3 有没有在必要场所设置完成品店面？④-4 东西的流动条件如何决定的（量、设备限制、品质限制）？
 - **⑤ 着工准备（生产指示）的方法**：⑤-1 生产指示依据什么运作（依看板后补充 / 依电气信号指示情报顺序生产 / 依监督者的直觉秘诀）？⑤-2 如何做可加工的指示传达（顺序 1 枚 1 枚的看板传达 / 依批量形成后的顺序传达 / 1 日分汇整）？⑤-3 着工准备的种类（见下方 A/B/C 仕挂）。
 - **⑥ 工程内半成品和前置时间**：⑥-1 设备有多少能力（Takt Time 和 MCT 比较、可动率、不良率）？⑥-2 标准手持量是多少个？⑥-3 加工线的加工的前置时间是多少、半成品如何控制？
 - **⑦ 搬运的方法**：⑦-1 后工程领取还是硬塞至下工程？⑦-2 根据什么指示开始搬运、搬运单位是多少（搬运规则：定时 30 分 / 定量 1 箱 / 呼叫 / 随机对应）？⑦-3 利用什么工具搬运（推高机 / 牵引车 / 台车 / 输送带）？
 3. **改善五阶段**：
 第一阶 以现地现物忠实描绘现状（使用记号）→ 第二阶 描绘应有形态（理想态）→ 第三阶 比较现状与理想、画出问题点（**GAP = 发掘问题**）→ 第四阶 从"资金、时间、工数、智慧、技术"多角度鉴别限制条件，放入管理者/STAFF 的意志 → 第五阶 作成行动计划（明确改善内容、个别目标、日程、担当者），实施改善与跟催。
 4. **作成留意点（6 条）**：① 流程日图不仅画对象工程，前后工程连结也要画（物的流动路线由左向右）；② 从生产指示的源头开始一直到最后工程为止正确掌握流动，就算不常有的状况也要全部画进去；③ 把搬运/生产的时机（频度、时间、量）、生产的前置时间尽量在图中注记；④ 每工程注记荷姿、收容数、种类；⑤ 工程复数或同一工程通过 2 次时（如洗净、处理、涂装），预备"容易了解全体前置时间的描绘方式"与"表示工程流动的描绘方式"两种画法；⑥ 彻底描绘现状后，以"物与情报的停滞"为主轴整理问题点。
- **量化口径**：
 - **A / B / C 三种仕挂（丰田使用的生产指示类型）**：
 - **A Type（后补充生产）**——有反复性的零件；根据被领取的情报生产、补充。前提：必须可重复。
 - **B Type（依据受订顺序生产）**——大型、种类多、空间不足、少量品；依据顺序表生产。需要确定的流动路径、且顺序不可弄乱的工夫；需要"1 个 1 个制造的能力"（直行率好的生产线）；**如有分歧·合流时则难以控制**。用"通行证"（Tablet）作总量限制，可让制造的问题显在化。
 - **C Type（A Type·B Type 的组合）**——后补充＋接单顺序生产；以 Tablet 挂总量规制，显现造的问题。注：**B、C 类型的受订生产，没有"1 个 1 个造"的能力是不行的**。
 - **使用记号 21 项**（改订前 13 项 → 改订后 21 项）：1.物的流动；2.情报的流动；3.看板（生产/领取，橡皮圈记号标在右上方）；4.工程内看板（记号中注记"仕"）；5.取引看板（记号中注记"引"）；6.临时看板（休出时追加）；7.信号看板；8.指示（清单）；9.シート（Sheet，终端机出来的清单）；10.その他（电送信号）；11.工程（含受入·理货场·出货场；1 台或 2 台、同工程是否 2 连要确实表示）；12.ストア（店面，整理好、做好库存管理的完成品置场，记号向前工程侧开口）；13.顺序店面；14.一时放置；15.纳入先（供货商，记号内记供货商名、记号外记看板周期）；16.外注部品（记号内记该生产线使用零件数、记号外记搬运方法）；17.理货ポスト；18.ロット成型箱；19.看板放置 BOX；20.顺序ラック；21.前置时间（注文→制品出货的 L/T）。
 - **前置时间分解公式**（三版，逐字保留）：
 - 基本式：**生产前置时间 = ① 情报的前置时间 + ② 制造的前置时间**。
 - ① 情报的前置时间 = 接到「制造指示」情报之后到开始制造为止的时间。
 - ② 加工（制造）的前置时间 =（工程内半成品 + 1 箱收容数）× Takt Time（即 1 箱分做好为止的时间）。
 - 运营生产线时：**生产前置时间 = ① 加工的前置时间 + ② 完成品在库 + ③ 等待回收看板 + ④ 等待批量形成 + ⑤ 等待开始生产 + ⑥ 领取量变化对应在库 + ⑦ 紧急用在库 + ⑧ 直差对应在库**；缩短方法：① 减少未在加工的物料；② 领取的多回化；③ 看板回收间隔的多回化（废止回收箱）；④ 减少生产的批量（做换模改善，⑤ 也一样）；⑥ 减少领取的变化量；⑦ 提升生产线的信赖性；⑧ 生产能力向上。**生产前置时间 = 总看板回转枚数**。
 - 用语集版：**生产前置时间 = A + B + C + D + E**，其中
 A = 该当制品生产指示情报的停滞时间；
 B = 该当制品从材料着工开始到完成品为止的时间（加工时间 + 停滞时间）；
 C = 该当制品的完成品的最初 1 个（台）生产出来以后，到后工程要领取的完成品数量（收容数）做好为止的时间（**收容数 × 该当制品的生产 Takt**）；
 D = 完成品店面的在库数量 × T/T；
 E = 紧急用在库、领取量变动对应在库、稼働日差对应在库数量等 × T/T。
 - **物流的前置时间 = 总看板回转枚数分 = ① 看板的周期 + ② 交货时间的变异 + ③ 卸货时间的变异 + ④ 供给时间的变异 + ⑤ 生产的变异 + ⑥ 回收的变异 + ⑦ 发注时机 + ⑧（变异对应分）**；缩短方策：① 便的多回化（减少延迟系数、减少收容数）；② 交货时刻表等间距化；③ 空箱、台车的整理；④ 送货量的安定化（解消通路的混杂）；⑤ 平准化生产；⑥ 回收看板等间距化；⑦ 发注时刻表等间距化。
 - **加工前置时间算例**：A=15″/个、B=23″/个、C=30″/个、D=25″/个 4 工程 → Σ加工 = **93″**（①）；停滞各 5″/个 → **20″**（②）；1 托盘收容数 10 个 → **300″**（③）；合计 ①+②+③ = **413″**。
 - **停滞折算例**：T.T=1 分、半成品=46 个 → 通过时间 46 分。
 - **"必要的店面"应设在**（物流动面）① 后补充生产工程的最后；② 工程分开之处；③ 工程合流之处；④ 做批量生产之处；⑤ 稼働时间有偏差之处；（工程管理面）① 生产前置时间长的工程；② 工程能力不足的工程。
 - **车间地址/物流**：记事例中，A 工场 1-4-4（看板周期）；B 工场 1 回/日；理货·出货场 2 回/直。
- **判读与决策**：
 - 画完图后，凡出现"物或情报停滞"的地方就是改善课题；把停滞**翻译为时间值**（如"领取情报有 4H 停滞""生产情报有 8H 停滞""5 枚集中制造""完成品在库 2.0 日分"）。
 - 判断优先序：先打"情报的停滞"（改动成本最低），再打"物的停滞"。
- **常见错误/反例**：
 - 各社使用记号与绘图方法差异大 → 对策：**记号表统一**（某汽车零部件企业合同研的实际做法）。
 - 只画对象工程、不画前后工程连结 → 无法判断工程间流动。
 - 在第四阶"妥协"（接受"自称专家·传说"的限制条件）→ JIT 水平无法提升。
- **出处**：〔出处：6.精益-持续改善\3.物与情报流程图〕

### 3.13 快速换型 SMED / QCO（八步法）

### 3.15 生产线平衡改善（编成效率）

- **定义/目的**：以标准时间/考查时间为基准，找出并消除产线编成浪费（等待）。
- **触发条件**：产线上有人等活、有人堆活；瓶脖工序拖累整体产出。
- **操作步骤**：
 1. **测定标准时间（含余裕）与考查时间**：
 - 考查时间程序：1 事前准备（① 策划实施计划 ② 向现场责任者说明 ③ 用具准备：1/100 分计秒表 DM 计、观测用表）→ 2 作业现场的准备（① 向作业者说明、避开不安定时期、选熟练作业者并明确要求"以 1 天当中能够持续的最高速度作业" ② 一般情报记录 ③ 按要素作业分解）→ 3 测定（记录方法 / 测定次数 / 测定态度 / 作业速度评价）→ 4 观测结果的整理（算代表值、排除异常值、当天完成整理）。
 - 要素作业分解重点：分开主要要素（组装、焊接、分解、吹气）与付随要素（取材料、放部品、走到机器旁）；分割单位尽量小但须保持可观测程度（**5 DM 程度**）；分开规则性作业与不规则性作业。
 2. **计算生产线编成效率**（见量化口径）。
 3. **平衡度向上 4 手段**：① 对瓶颈⑤进行作业改善降低工数（变更标准作业）；② 提高作业者技能（技能教育）；③ 移动工作量（⑤ ⇒ ④）；④ 掌握作业难易度与作业者能力进行工位调整（④ ⇔ ⑤）。
 4. **按作业分派 8 点注意排工位**：① 明确每位作业者的作业内容（品质对应）；② 需要用干净的手操作的作业和容易弄脏的作业要分开（品质对应）；③ 生产线第一工位的作业者尽量减少工作量，避免工作延误（投入不足对应）；④ 使用相同治工具·设备的工程尽量集中在一个工位（设备投资对应）；⑤ 作业时间相差大的作业不应安排在一起（考虑整个生产线平衡）；⑥ 当作业稳定之后，区分工程（品质对应）；⑦ 机器标准时间分割困难时，应考虑其需要的台数（设备投资对应）；⑧ **编成效率目标为 90% 以上**。
- **量化口径**：
 - **标准时间 = 实质时间 + 余裕时间 = 实质时间（1 + 余裕率）**；
 实质时间 = 主作业（产生附加价值、每次反复）+ 付随作业（跟随主作业、每次反复，如工具取放、治具固定、固定螺丝、粘贴）；
 余裕时间 = 人的余裕（生理余裕、疲劳余裕）+ 非人的余裕（作业余裕、职场余裕）；
 有效重复作业 = 主作业 + 付随作业；**多余作业 = 多余的动動 + 不要的作業**。
 - **生产线编成（平衡）效率（%）＝ Σ（各作业工程的时间）÷（PT × 作业工程数）× 100**；其中 **PT = 负荷工程的实测时间（间隔时间）**；**目标：90% 以上**。
 > 注：语料给的是"编成效率"；本册即按此式作为线平衡率口径。**节拍约束下的最少工位数公式语料未出现**（见 §9）。
 - **测定次数（理论性/统计性，信頼度 95%、相对误差 ±10%）**：
 | 周期时间（分） | 0.5 到 | 1.0 到 | 2.0 到 | 5.0 到 | 10.0 到 | 10.0 超过 |
 |---|---|---|---|---|---|---|
 | 观测次数 | 40~20 | 20~15 | 15~10 | 13~8 | 10~7 | 8~5 |
 连续作业情况下，从 **5~10 次**的观测结果中决定代表值比较好。
 - **要素作业时间的整理**：从观测时间的差异中计算每个要素作业的时间值；排除误读和作业错误等异常值；计算代表值（一般取平均值）；例：要素作业时间 85−73 = 12。
 - **作业长短区分（所需时间）**：动動 1/1000 分 → 要素作业 1/100 分 → 単位作业 1/10 分以上 → 工程 → 大工程 → 业务。
- **判读与决策**：
 - 编成效率 < 90% → 按 4 手段改善；先看瓶颈（间隔时间最长者）。
 - 三类编成浪费根因对应：① 作业配分不合适/作业者太多 → 现象"每次出现等待、作业不积极"；② 作业者手快 → 完成后等下一个工作；③ 前工程作业慢 → 前后工程都出现等待（制品不流动），根因是"作业分割不合适、工位之间没有备用空间"。
 - 对应改善：把作业向前后工位分派来减少作业者，或在作业者之间加备用空间；把 2、3 合并；在 1、4 之间加一处备用空间。
- **常见错误/反例**：不测时就排工位；用"估算标准时间"当基准；把作业时间相差大的两工位排在一起。
- **出处**：〔出处：6.精益-持续改善\5.线平衡〕

### 3.16 创意功夫（合理化改善）制度框架

- **定义/目的**：员工提案改善制度的标准框架，丰田称之为"创意功夫提案"，即丰田生产方式的核心——改善。
- **触发条件**：路线图 1.11"提案改善系统建立和推行"；员工改善积极性低。
- **操作步骤**：
 1. 先立**概念**：工作 = 作业 + 改善（**v = v0 + at**）；作业=每天重复的事情，改善=创造性的事情。
 2. 明确**目的**：对公司（提高生产效率、降低成本，为公司创造更多利润）；对个人（增强问题意识、开发思维潜力，创造更容易工作的职场，增强相互交流，使工作更轻松/更安全/更高效，获得提升与展现才能的机会，获得奖金和荣誉）。
 3. 明确**原则（三自原则）**：**自查**（对自己或团队工作中的不足进行调查分析，找出可改善问题点）**自立**（针对问题点自己提出改善建议及有效可行的改善方案）**自改**（根据自己提出的方案，亲自去改进或协助专业人员改善）。
 4. 提供**发现目标**的五类工具：七大浪费（§3.6）/ 十六大损失（§3.17）/ 动作经济四原则 / QCDSM / 4M / 现场 3 多 / ECRSI + 5W2H。
 5. 用**改善六大步骤**（§3.10）闭环。
- **量化口径**：
 - **动作经济四原则**：① 减少动作项目（减少拿取、放置，将装配、拆卸简化；消除寻找、挑选、思考、换取）；② 动作可同时进行（消除单手持物/等待，消除均衡起见的等待、班内等待、机械缘故的等待与监视）；③ 缩短工作间的距离（缩短手腕移动距离、消除身体动作如扭曲肩膀、缩短步行距离、消除腰部扭曲、减少时站时蹲）；④ 使动作更轻松（消除重物作业、弯腰作业、需特别集中注意力的作业）。
 - **QCDSM 检查项**：品质（不良/整修/报废/抱怨是否减少，差异有无变大，错误、异常有无发生）；交期（生产量是否按计划完成、是否遵守交期、是否有过剩库存、故障是否提升、作业速度是否提升、工时是否缩短、作业是否简化）；成本（经费有无节省、效率有无提升、工时是否减少、有无浪费资材、单位成本是否下降、生产率是否提升、是否不作无效工作）；安全（灾害是否减少、疲劳度是否减少、整理整顿是否良好、安全护具是否穿戴、危险物品处理是否良好、危险区域是否明确）；士气（人际关系是否良好、干劲有否提升、品管圈是否活跃、提案改善是否活泼、出勤率是否提升）。
 - **4M**：Man（人）/ Machine（机器）/ Material（物）/ Method（方法）——即人、机、事、物。
 - **ECRSI**：E(Eliminate) 排除 / C(Combine) 合并 / R(Rearrange) 交换 / S(Simplify) 简化 / **I(Investment) 投资**。
 - **检查清单 5 类**：① 对 4M 的检查清单；② 对生产合理化三要素（Q/D/C）的检查清单；③ 对作业动作的检查清单（手脚/身体/疲劳/安全/操作）；④ 对作业者环境的检查清单（布置/环境/照明/整理/搬运）；⑤ 各部门改善业务的检查清单（设计质量、原资材设计品质、原资材品质价格、原材料使用法、人、机械装备、库存、制造、检查、搬运、修理费用、办公费、电力动力）。
- **判读与决策**：
 - 提案数量的对标信号：世界级人均提案 **61.6** vs 北美日企 1.4 / 北美美企 0.4 / 欧洲 0.4——**提案数是精益企业最显著的软性差异**（见案例 C7）。
 - 多产建议的 6 条动作：a. 多看、多听、多想、然后做做看；b. 养成观察习惯，边观察边思考；c. 有良好构想马上记下来；d. 好构想经研究便是好建议；e. 从身边做起，对份内工作再检讨；f. 时刻抱着"没有最好，只有更好"的念头。
- **常见错误/反例**：把提案当"合理化建议箱"而不给制度出口（无评审、无奖励、无实施反馈）。
- **出处**：〔出处：6.精益-持续改善\1.创意功夫；3.精益生产培训资料（对标数据）〕

### 3.17 设备效率化损失体系（16 大损失）

- **定义/目的**：全面识别设备/人/原料的效率损失，作为改善目标发现与设备管理体系（TPM）的问题清单。
- **触发条件**：设备效率低于预期、OEE 停滞、要建立设备改善课题库。
- **操作步骤**：按三大类 16 项清点，逐项定性+定量：
 - **企业阻碍设备"效率化"的八大损失**：
 1. **故障损失**——机器的停止或能力的降低（包括生产停止或产量减少）、为恢复机器生产能力所做的更换零件和修理；**修理时间在 5－10 分钟以上者**。
 2. **制成中准备、调整损失**——指正在生产的产品完成后到下一个产品的切换、调整，直到可生产出合格品为止的时间损失。
 3. **刀具损失**——因刀具的定期更换或因刀具的损伤而临时更换所引起的时间损失，以及更换前后所发生的物料损失（品质不良、工人整修等）。
 4. **暖机期间的损失**——定期修理后开机时、长期停机后开机时、假日后开机时、午休后开机时。
 5. **短暂停机（空转）损失**——暂时停止机能所引发的损失、简单处置（例如取走异常的工件于机器重设定）即可恢复机能的损失、不包括更换零件与修理损失；**恢复正常所需时间在 2—3 秒以上、5 分钟以下者**。
 6. **速度降低损失**——设备因速度慢下来所产生的损失。
 7. **品质不良、人工整修损失**——因品质不良、人工整修所发生的物量损失（报废品），以及因人工整修所造成的时间损失。
 8. **SD（SHUTDOWN）损失**——实施设备的计划保养时，设备停止所发生的时间损失，以及再开机后暖机期间所发生的物量损失。
 - **企业阻碍"人效率化"的 5 大损失**：
 1. **管理损失**——等待材料、等待指示、等待故障修理等管理上发生的人员闲置损失。
 2. **动作损失**——违反动作经济四原则所发生的损失、不够熟练发生的损失以及因机器、物料配置不佳发生的损失。
 3. **编成损失**——多制程等待、多台机器生产等待所发生的人员闲置损失，或在输送带作业时的生产线平衡损失。
 4. **自动化替换损失**——实施自动化可以达成省人化的目标，同时也发生人员的损失。
 5. **测定调整损失**——为防止不良品发生、流出而频繁实施测定调整所发生的工时损失。
 - **企业阻碍"原料效率化"的 3 大损失**：
 1. **成品率损失**——素材重量与产品重量之差，或者总投入素材重量与产品重量之差因而产生的物量损失。
 2. **能源损失**——电力、燃料、蒸汽、压缩空气、水（包括废水处理）等的能源损失。
 3. **模具治工具损失**——在制作、修补制造产品所必须的模具、治工具时，所发生的金钱损失。
- **量化口径**（阈值，原样保留）：故障损失 **5－10 分钟以上**计为故障；短暂停机 **2—3 秒以上、5 分钟以下**；合计 **8 + 5 + 3 = 16** 项。
- **判读与决策**：按损失"金额化"排序立项；16 项是**选题库**，不是考核表。
- **常见错误/反例**：只盯设备八大损失而漏掉人的编成损失——产线平衡损失（§3.15）就属人的损失。
- **出处**：〔出处：6.精益-持续改善\1.创意功夫（第二章第二节）〕

### 3.17a 质量控制三策略 与 TQM（三全四一切）

- **定义/目的**：质量体系搭建框架；把质量从事后检验转为源头管理。
- **触发条件**：不良靠检验兜底、质量与生产对立、要做质量体系。
- **操作步骤**：
 1. **质量控制三策略**：**质量计划**（Quality Planning）→ **质量控制**（Quality Control）→ **质量改进**（Quality Improvement），构成"加工过程管理模型"；配套工具：D/PFMEA、APQP、PPAP、QS9000/ISO9000、SPC、防错。
 2. **TQM 核心思想**：**三全**——全员、全过程、全范围的品质管理；**四一切**——一切为用户着想、一切以预防为主、一切用数据说话、一切工作按 PDCA 循环。TQM 口号含 QCDSM 框架。
 3. **后工序是客户**：三不原则——**不接受不良品、不制造不良品、不流出不良品**（DON'T ACCEPT / DON'T MAKE / DON'T DELIVER）。
- **量化口径**：**85% 品质问题属管理不善**（不是作业者责任）。
- **判读与决策**：当品质问题被归咎于作业人员时，先查管理体系；追求"过剩品质"（高品质=高档）不可取。
- **常见错误/反例**：把品质当品管部门的责任（§7 A7）；追求过剩品质（§7 A8）。
- **出处**：〔出处：4.精益思想与精益生产体制 Slide74-78；3.精益生产培训资料（质量系统）；9.LEAN-精益培训 Slide570-573〕

### 3.18 供应链开发五阶段（成熟度）

- **定义/目的**：判断与供应商关系的成熟度层级，决定下一步合作姿态。
- **触发条件**：来料不稳、成本谈不下来、要与核心供应商走向战略合作。
- **操作步骤**（逐级跃迁）：
 1. **传统做法**——敌对关系，价格是决定因素。
 2. **SCM 供应链管理**——长久关系，质量优先，减少供应商数量。
 3. **生产联盟 Operational Alignment**——时间优先，关注关键工艺能力。
 4. **战略联盟 Strategic Alignment**——业务及流程一体化，战略业务伙伴。
 5. **世界级水平 World Class Attainment**——端到端精益企业。

- **判读与决策**：处在 1–2 阶段时，先做"减少供应商数量 + 质量优先"；不要跳过阶段谈战略联盟。采购关键评价指标 = **回转率**（= 上周周末库存金额 / 本周实际使用金额，例 2 千万元/1 千万元 = 2 周）。

### 3.19 SDCA–PDCA 循环

- **定义/目的**：解释标准化与改善的关系——先维持再提升。
- **触发条件**：改善成果反复回退；标准作业不落地。
- **操作步骤**：Standardize（S）→ Do → Check → Action，再回到 Plan-Do-Check-Action；**先标准化维持（SDCA），再改善提升（PDCA），往复循环**。
- **量化口径**：（语料未覆盖）
- **判读与决策**：**标准代表最好的、最易的、最安全的方法，提供衡量绩效的手段；无标准则无法维持改善成果**。改善→新标准→再改善，缺任一步就归零。
- **常见错误/反例**：改善完成后不更新标准作业书；标准作业书不更新随零件/设备变化（§3.15 已验证该风险）。
- **出处**：〔出处：9.LEAN-精益培训（改善的工具：SDCA–PDCA）〕

### 3.20 SMART 目标原则

- **定义/目的**：制定改善目标时校验是否合格。
- **触发条件**：目标设定（改善九阶段第 2 步、示范线报告第四部分）。
- **操作步骤**：逐要素校验——**S** 明确性（Specific）/ **M** 可量化（Measurable）/ **A** 可达成（Attainable）/ **R** 实际性（Relevant）/ **T** 时间性（Timetable）。
- **量化口径**：五要素缺一即不合格。
- **判读与决策**：含糊目标无人无所适从 → 打回重写。
- **常见错误/反例**：目标写成"提升效率"（无 M/T）；目标写"每月提升 30%"（无 A）。
- **出处**：〔出处：6.精益-持续改善\2.改善精神〕

### 3.21 精益人才育成（三阶段）

- **定义/目的**：人才培养路线；HR 担当组织者/管理者/监督者。
- **触发条件**：路线图 1.4/2.1 领导力培训；多能工/少人化的前置条件。
- **操作步骤**：
 1. **准备阶段**：选对象、定方案、定激励。
 2. **入门阶段（OJT、道场训练）**：确定培训负责人 → 制定培训计划（课程/对象/时间/地点/老师/讲义审核）→ 培训开展（名单、出勤记录）→ 培训考核组织（编制考题）→ 培训记录与跟踪（个人跟踪记录卡）→ 培训结果反馈。

- **判读与决策**：对应项目初期/中期/后期；表单 = 个人跟踪记录卡、多能工技能训练计划表、技能统计表。
- **常见错误/反例**：只培训不考核、不跟踪、不留记录卡。
- **出处**：〔出处：5.精益人才培养方案（成长大计划）；4.精益思想与精益生产体制（多能工）〕

### 3.22 改善 vs 革新（KAIZEN vs INNOVATION）

- **定义/目的**：区分渐进改善与突破创新两种改进路径，避免"改善"被当成唯一手段或"革新"被当成逃避现场改善的借口。
- **触发条件**：资源分配决策（预算投在渐进改善还是设备大改造）。
- **操作步骤**：按下表对照定位：
 | 维度 | 改善 KAIZEN | 革新 INNOVATION |
 |---|---|---|
 | 变化量 | 小的变化累计起来 | 大的变化、大的成果 |
 | 能力要求 | 常时通常能力 | 特别能力 · 很大投资 |
 | 做事姿态 | 该做的正正当当做 | 独创性创造性 |
 | 风险 | 容易、危险小 | 很费劲 |
- **量化口径**：（语料未覆盖）
- **判读与决策**：精益主战场是改善；革新用于突破瓶颈（如设备能力根本不足）。
- **常见错误/反例**：用"要投资"回避日常改善；用"改善"拖延必要的设备升级。
- **出处**：〔出处：6.精益-持续改善\2.改善精神（1.改善概念）〕

### 3.23 现场三大管理基石 + 七个"零"

- **定义/目的**：精益之路的起点（三大基石）与终极目标（七个零）。
- **触发条件**：现场没底子（乱、无标准、不落地）时的先手动作；愿景设定。
- **操作步骤**：
 1. **三大管理基石**：① **5S 活动**（心态：从我做起、从身边做起）；② **改善活动**（手段：没有最好只有更好）；③ **5 现主义**（作风：实事求是）。
 2. **七个"零"目标**逐项对标：
 零切换（转产工时）浪费 → 多品种对应；零库存 → 消减库存；零浪费 → 全面成本控制；零不良 → 高品质；零故障 → 提高运转率；零停滞 → 快速反应短交期；零事故（另有一版本第 7 项作"零灾害"）→ 安全第一。
- **量化口径**：七个零，逐个都是**目标项而非指标项**，必须各自落到可测指标（如零不良→合格率、零故障→MTBF/PM%）。
- **判读与决策**："精益求精，尽善尽美，永无止境地追求七个零"——作为年度方针口号，不作为考核指标直接打分。
- **常见错误/反例**：把"七个零"当成 KPI 直接考核导致数据造假。

## 5. 打法（组合拳）

### 打法 A：交期长、库存高、前后工程衔接乱（最常用）

1. **画物与情报流程图**（§3.11）：7 观察点逐项取证 → 输出"现状图 + 停滞清单（情报停滞 X H、物停滞 Y H）"。
 产出物：现状流程图（21 记号）、停滞清单。
2. **定量分解前置时间**（§4）：把总 L/T 拆成"①情报前置时间 + ②制造前置时间"，再拆成 8 项（等待批量形成、等待回收看板…）。
 产出物：前置时间分解表（每项 = 多少 H/分）。
3. **选 A/B/C 仕挂**（§3.11）：反复性零件走 A Type 后补充；大型/多品种/少量走 B Type 接单顺序；混着走 C Type。
 产出物：生产指示方式决策表。
4. **打两个硬件瓶颈**：SMED（§3.13）缩批量 + 线平衡（§3.15）削等待。
 产出物：换型改善方案（内→外）、编成效率 ≥90% 的新工位表。
5. **固化**：更新标准作业书（§3.19 SDCA），月度看 L/T 与看板枚数。
 产出物：新标准 + 月度 L/T 趋势图。

### 打法 B：从零推行精益（老板说"我们要搞精益"）

1. **导入宣讲**：TPS 两大支柱 + 精益五原则（§3.1、§3.2），统一语言。
2. **定路线**：照抄 31 项路线图（§3.8），先做第一阶段 13 项，**先建 3 个样板区**（6S/目视化、TPM、标准化）。
3. **选样板**：按示范线 9 章模板立项（§3.14）→ 每天 9:00 日清会 → 月度绩效 × 12 换算成年化。
4. **建提案系统**：创意功夫制度（§3.16）+ 改善六大步骤（§3.10）。
5. **评成熟度**：VPS Level（§3.9）逐年抬级，横向推广（路线图 2.2）。

### 打法 C：成本下不来、利润薄

1. **清点损失**：16 大损失三大类逐项列（§3.17），金额化排序。
2. **识别浪费**：3M Loss 三问 + 七种浪费（§3.5、§3.6），优先打"做太多"和"库存"。
3. **判定真效率**：用整体效率（水桶）+ 真/假效率（§3.7）剔掉假效率项目。
4. **出方案**：ECRSI + 5W2H + 动作经济四原则（§3.16）。
5. **算钱**：按示范线口径把成果换算为 **月绩效 × 12 = 年绩效**（§3.14）。

### 打法 D：产线效率上不去

1. **实测**：考查时间（秒表/要素作业分解，观测次数按周期时间查表）（§3.15）。
2. **诊断**：编成效率 = Σ工程时间 ÷（PT×工程数）×100，定位瓶颈（PT 所在工位）。
3. **改善**：① 瓶颈作业改善降工数 → ② 技能教育 → ③ 移动工作量 → ④ 工位调整。
4. **排工位**：按作业分派 8 点注意重排；目标编成效率 ≥ 90%。
5. **固化**：标准作业书 Ⅰ/Ⅱ + 现场"发现与标准作业不同点 ⇒ 異常 ⇒ 指导改正"的日常确认。

## 6. 案例（保留真实数字）

### C1. 降低成本的杠杆效应
- **背景**：当前销售 \$100,000、成本 \$80,000、毛利 \$20,000、财务费用 \$6,000、利润 \$14,000。
- **做法/结果**：增加销售 50% → 利润 \$24,000（**+71.4%**）；削减支出 50% → 利润 \$17,000（**+21.4%**）；降低成本 20% → 利润 \$30,000（**+114.2%**）。
- **可迁移点**：通过管理使制造成本下降 20%，利润可增加 114%——**降本的杠杆远大于增销**。
- 〔出处：9.LEAN-精益培训-精讲+案例介绍〕

### C2. Q5 行李架示范线改善（汽车零部件）
- **背景**：Q5 行李架月订单量 **2715 set**；现状：机加 2 人、组立 6 人、生产周期 **8.1 天**、机加合格率 **70%**、每套负毛利 **−87 元**；氧化挂具 **20 pcs/挂具**、飞靶 **2 挂具**。
- **做法（四大策略）**：
 1. **减员增效·设备优化**——机加自动化送料翻转，2 人→1 人；氧化挂具由倾斜悬挂改垂直悬挂，**20 片/挂具→26 片**，飞靶 **40 根→52 根**，产能 **+30%**；组立治具合并消除转身行走。
 2. **打通动脉·物流优化**——组立线布局优化、建立配送系统、WIP 由前后端 **620 set→330 set**、后拉式生产。
 3. **防呆防错**——专机光幕安全防呆/顺序防呆、组立治具顺序防呆警报。
 4. **以人为本**——5S/目视化、多能工培训、标准化。
- **结果**：
 - 生产周期 **8.1 天 → 6.1 天**；组立效率 **20 pcs/h → 30 pcs/h**；氧化 **40 pcs/挂 → 52 pcs/挂**。
 - 成本总降低月绩效 = (87.06 − 57.12) × 2715 = **81287.1 元/月**，年绩效 **97.54 万元/年**。
 - 子项年绩效：组立 **65160 元**、氧化 **10525.8 元**、机加 **21710 元**。
- **可迁移点**：示范线改善以"**价值流 + 瓶颈 + 防错 + 人**"四位一体推进，成果必须换算为**年化金额**（月绩效 × 12）。
- 〔出处：10.精益示范线项目计划与改善报告〕

### C3. 目视化样板线改善（某家电企业资料）
- **背景**：外机生产 C 线为目视化样板线，项目周期 **2012-09-03 至 2012-12-31**，目标在原有基础上提升 **20%**；现状问题：物料三定未彻底、5S 有空间、安全小隐患、物品物料标示不完善；**评分基线 41 分**。
- **做法**：PDCA 推进；**六类标示改善**（管理看板、物品物料、安全警示、设备电器、地面通道、工具器具）；团队纪律 4 条；**每天上午 9 点项目日清会**。
- **结果**：目视化评分 **41 分 → 73 分**（目标 50 分），提升 **78%**。
- **可迁移点**：样板线以**评分**为量化抓手，先立标准再全厂推广。
- 〔出处：11.精益样板线改善成果报告(美的资料)〕

### C4. 物与情报流程图（某汽车零部件企业 / 丰田案例）
- **背景**：某汽车零部件企业汽车中坜厂 TPS 合同研活动（造隆、合信、台扣、三龙等 B 组四社）。
- **做法（五步）**：
 - STEP1 整理现状（**前置时间 16H**，看板 5 枚集中批量形成）→
 - STEP2 描绘应有姿态（**多回引取 0.3H 每**、同步化生产）→
 - STEP3 画出问题点（**仕挂情报停滞 20 分**、**外段取时间 8.3 分/回**、**压入不良 1 件**、**粉尘异物 1 件**、**完成品在库多 1.2H**）→
 - STEP4 描绘目标姿态（**安全在库 = 0.3H**）→
 - STEP5 行动计划。
 - 附带改善：各社使用记号与绘图方法差异大 → 对策是**记号表统一**（13 项→21 项）。
- **结果**：**前置时间由 16H 缩短至 1.2H → 0.6H → 0.3H**。
- **可迁移点**：把"物与情报的停滞"翻译为**时间值**，是 JIT 改善的统一尺度。
- 〔出处：6.精益-持续改善\3.物与情报流程图〕

### C5. 生产线平衡改善（从照片找问题）
- **背景**：三类典型现象——例① 作业分割少（每次出现等待、作业不积极）；例② 作业者手快（做完自己活等下一个）；例③ 前工程作业慢（前后工程都等待、制品不流动）。
- **做法**：把作业向前后工位分派来减少作业者，或在作业者之间加备用空间；把 2、3 合并；在 1、4 之间加一处备用空间。
- **可迁移点**：产线编成浪费的三类根因 = **作业配分不合适/作业者太多、作业速度差异、作业分割不合适**。
- 〔出处：6.精益-持续改善\5.线平衡〕

### C6. 丰田奇迹与精益企业对比
- **背景**：丰田 1937 年成立，累计生产 **2686 辆**；福特鲁奇工厂**一天生产 7000 辆**。
- **结果（分阶段）**：50 年代日本市占率 **4%** → 80 年代 **21.3%**；1980 年代纯利润 **1 万亿日元**超过美国三大总合；现市值超三大总合，成为世界第一大汽车公司，**60 年连续盈利**。
- **可迁移点**："不幸的是很多学习丰田的企业都以失败而告终"——**照抄工具不够**。
- 〔出处：1.精益意识导入培训 Slide4-5〕

- **并行布局改善**：单人操作两机台。
- **消除孤岛布局改善**：改善前工序分散、抛光粉尘多；改善后整齐集中、物流顺畅、采用除尘设备。
- **其他公司单元布局**：Canon 珠海数码相机 Cell、Canon 法国复印机 Cell、Canon 大分单眼相机一人 Cell（作业标准书 **1000 页**从组装到检查）、信泰 Cell 线。
- **可迁移点**：精益布局精髓 = 通过布局实现产品单件流动，**暴露问题以实现 JIT**。
- 〔出处：7.精益布局lean layout〕
