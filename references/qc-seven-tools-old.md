## 2. 概念地基

| 概念 | 判据 | 易混淆点（什么不是它） |
|---|---|---|
| **数据 = 事实** | "依据测量所获得的数值和资料等事实即数据"；问题发生要采取对策之前，一定要有数据作为依据 | 数据不是意见、印象、经验；"假数据比没有数据更坏" |
| **计量值 vs 计数值** | 计量值＝可连续取值、有小数（长度/重量/时间/温度/强度）；计数值＝离散、只取整数（不良品数/缺点数）。计件值服从二项分布，计点值服从泊松分布 | 比率值数据的性质**看分子**：分子是计量值则比率为计量值，分子是计数值则比率为计数值 |
| **老七大手法** | 查检表·层别法·柏拉图·特性要因图·直方图·散布图·管制图 | **不是**新七大手法（亲和图/KJ、关联图、系统图、矩阵图、PDPC、箭条图、矩阵数据分析法） |
| **口诀（每手法的唯一用途）** | 查检集数据 · 柏拉抓重点 · 鱼骨追原因 · 直方显分布 · 散布看相关 · 管制找异常 · 层别作解析 | 别把"抓重点"和"追原因"混用：柏拉先把项目排序，鱼骨再对中选项追根因 |
| **前置：先层别再收集** | 收集数据**之前**就要按条件背景层别化，事后再分常需重收 | 事后分类≠层别法；双峰/高原直方图、柏拉图"其他"栏过高都是层别不良 |
| **改善前后可比** | 数据整理时"改善前与改善后所具备条件要一致"；柏拉图前后对比要求期间和对象必须一样 | 期间/对象/基准不一致的对比无效 |
| **三现主义 / 三不政策** | 三现＝以现实合理的眼光观察现场与现物；三不＝不制造不良品、不良品不后流、不接受不良品 | 三不是现场品质总纲，不是"靠检验拦不良" |
| **管制界限 vs 规格界限** | 管制界限由**制程数据**算出（CL±3σ），用来看"稳不稳"；规格界限来自**规格**，用来看"合不合" | **绝不可**用规格界限代替管制界限；管控图异常点未追因不得删除 |
| **管制状态（安定状态）** | ①点没有逸出界外；②点的排列没有习性、呈随机现象 | 与"合格"无关：制程可以很稳但都不合格（Cp 不足） |

## 3. 方法/工具逐项展开

### 3.1 查检表（Check Sheet）
- **定义/目的**：为了便于收集数据，使用简单记号填记并予统计整理，以作进一步分析或作为核对、检查之用而设计的一种表格或图表。分类：① 记录用（改善用）查检表——调查不良项目/不良主因/工程分布/缺点位置；② 点检用查检表——确认作业实施、机械整备，预防不良事故、确保安全。
- **触发条件**：现状不明要先把现场"变成数据"；日常点检（设备每日检查、安全点检）；要报告需取得记录（推移图、直方图前身）。
- **操作步骤**（三版并存，择一执行）：
 - `01` 版 5 步：① 明确目的（把握现状解析，与使用目的相配合，将来能提出改善对策数据）② 决定查检项目——**从特性要因图圈选的 4~6 项决定** ③ 决定抽检方式（全检 / 抽检）④ 决定查检方式（查检基准、查检数量、查检时间与期间、查检对象，并决定收集者、记录符号）⑤ 设计表格实施查检。
 - `04` 版 6 步：① 明确目的所在 ② 决定检查项目 ③ 决定抽样方法 ④ 决定检查方式 ⑤ 设计表格实施检查 ⑥ 记下资料相关条件。
 - `21/8/10` 版 4 步：① 决定所要收集的数据及希望把握的项目 ② 决定查检表的格式 ③ 决定记录形式 ④ 决定收集数据的方法。
 - 点检用查检表制作 4 步（`3,202页`）：① 制作表格决定记录形式 ② 将点检项目、频率列出 ③ 检查并作好记录（含作业场所、工程、日期）④ 异常事故处理及记录。
- **量化口径**：
 - 查检项目数 = **4~6 项**（从要因图圈选）。
 - 记录形式：**"正"字记号**（最常用）；**"+++++"棒记号**（频数分布表用）；**"○△√×"图形记录**。
 - 点检用符号：OK 划"○"、NG 划"×"、未作业划"/"、不需点检项目划"△"。
 - 记录项目 8 项（`3,202页`）：标题（目的何在）/对象·项目（为什么）/人员（由谁做）/方法（何种做法）/时间（什么时间、期间间隔）/过程类别·检查地点（在什么地方）/结果整理（合计、平均、统计分析）/传送途径（谁需要了解、报告给谁）。
 - 表头字段示例（记录用）：原因别、机械别、人员别、缺点别、不良项目别、位置别；并注明抽样方法、时间、地点、检查方式（目视等）。
- **判读与决策**：数据收集完成应**马上使用**；观察整体数据是否代表某些事实、是否集中在某些项目、项目间是否有差异、是否随时间变化，**特别注意周期性变化**；统计完成即用柏拉图加工，掌握问题重心。若"集中在少数项目"→ 转柏拉图；若"随时间/周期变化"→ 转管制图。
- **常见错误/反例**：项目过多导致失焦（应控制在 4~6 项）；收集完不立即使用；未在收集前层别；只列数据不注明条件（抽样法/时间/地点）。
- **出处**：〔`21, QC七大手法之二（查检表）.txt`〕〔`01.品管七大手法.txt`〕〔`04.QC七大手法.txt`〕〔`3, 某上市企业QC七大手法培训教材（202页）.txt`〕〔`检查表.txt`〕

### 3.2 层别法（Stratification / 分层法）
- **定义/目的**：针对部门别、人别、工作方法别、设备、地点等所收集的数据，按照它们共同的特征加以分类、统计的一种分析方法；即为了区别各种不同原因对结果的影响，而以个别原因为主，分别统计分析的一种方法。它是七手法中较特殊的一种——**没有特定图形**，前六种手法其实都已包含层别观念。
- **触发条件**：整体看不出差异、无相关、双峰/高原分布；柏拉图"其他"栏过大；要评定作业员绩效/生产线效率/分析不良原因。
- **操作步骤**（`8,101页` 4 步）：① 确定使用层别法的目的（为何目的、用何种层别）② 确定层别的项目 ③ 收集与整理数据（用记录卡或查检表）④ 分析、比较与检定。`层别法.txt` 运用步骤：明确问题 → 选定层别角度 → 各层分别统计 → 比较找出差异最大的层。`3,202页` 3 步：① 确定分层对象 ② 利用检查表收集数据 ③ 绘成推移图分层比较。
- **量化口径**：
 - 观点：以特性要因图的 **4M1E** 作层别（MAN 人 / MACHINE 机械 / MATERIAL 材料 / METHOD 方法 / ENVIRONMENT 环境）。
 - **八大层别对象**（`01/20`）：① 时间（小时/日期/周/月/季节）② 作业员（班别、操作法别、熟练度、年龄、性别、教育程度）③ 机械·设备（场所、机型、年代、工具、编号、速度）④ 作业条件（温度、湿度、压力、天气、作业时间、作业方法、测定器）⑤ 原材料（供应者、群体批、制造厂、产地、材质、大小、贮藏期间、成分）⑥ 测定（测定器、测定者、测定方法）⑦ 检查（检查员、检查场所、检查方法）⑧ 其他（良品/不良品、包装、搬运方法）。
 - `8,101页` 层别项目示例：**时间**（年·季·月·日·上下午·作业时间别）/ **组织**（工厂·部门·组）/ **原料**（制造商·供应商·产地·性质·形状·批量·成份·尺寸）/ **环境气候**（温度·湿度·压力·风向·噪音·光度）/ **设备**（制造商·供应商·新旧·机种·用途）/ **员工**（职位·性别·年龄·经历·薪资·教育程度）/ **销售**（固定·一般客户·市场·运送方式）/ **作业方法**（方法·步骤·自动·手动）/ **商品**（设计师·价格·库存·名称）/ **量测**（方法·器具·人员·场所）。
 - **分层原则**：使同一层内的数据波动幅度尽可能小，而层与层之间的差别尽可能大。
 - 分层注意事项：数据分层与收集数据的目的性紧密相关；分层要合理，使问题暴露得更清楚。
 - 层别运用注意事项：① 在收集数据之前就应该运用层别法 ② 层别的方向应尽可能多 ③ 每次层别的结果未必都有用 ④ 层别时可以多层分解 ⑤ 层别到何时可以停止。
- **判读与决策**：制作柏拉图时若项目太多或"其他"栏比例过高 → 层别不良，须改层别或分类方法；直方图呈**双峰型或高原型** → 层别问题，**先层别再重作直方图**；散布图杂乱无倾向 → 先层别再分析；找出"差异最大的层" → 该层即改善靶心。
- **常见错误/反例**：数据收集前不层别、事后再分类（费时费力、常需重收）；柏拉图项目过多/"其他"栏过高；双峰/高原直方图未层别即下结论；层别方向单一（应尽可能多向分解）。
- **出处**：〔`01.品管七大手法.txt`〕〔`20, QC七大手法之一（层别法）.txt`〕〔`层别法.txt`〕〔`8, 老QC七大手法讲解（101页）.txt`〕〔`3, 某上市企业QC七大手法培训教材（202页）.txt`〕〔`corpus_video\QC工具之层别法.txt`〕

### 3.3 柏拉图（Pareto Diagram / 排列图 / ABC 法）
- **定义/目的**：将不良项目按发生频次由大到小排列的柱形，并叠加累计比率折线的图；用于"抓重点"（Vital Few, Trivial Many）。源起：意大利学者柏拉图（Pareto）1897 年研究社会财富分布，得出"关键少数与次要多数"；朱兰博士将之引入品管。
- **触发条件**：缺陷/抱怨/事故项目众多要排序；要定改善目标与攻击顺序；要确认改善效果（对策前后对比）；要整理报告记录。
- **操作步骤**（`3,202页 / 8,101页` 7 步）：① 决定数据的分类项目（按结果：不良项目别/场所别/时间别/工序别；按原因：材料别/方式别/人别/设备别）② 决定数据收集期间，并按分类项目收集数据 ③ 依分类项目作数据整理并作统计表（各项目按大小排序，"其他"项排最后，求累计数）④ 按数据大小排列画出柱状图 ⑤ 绘累计曲线（点上累计不良数或累计不良率，用折线连接）⑥ 绘累计比率（纵轴右边折线终点为 100%；0~100% 分成 10 等份；标出前三项（或四项）累计影响度是否大于 80% 或接近 80%）⑦ 记入必要事项（标题、数据搜集期间、数据合计、工序别、作成者）。
 - `01` 版 5 步：① 决定不良分类项目 ② 决定数据收集期间并按分类项目收集数据 ③ 记入图表纸依数据大小排列画柱形 ④ 点上累计值并用线连结 ⑤ 记入主题及相关资料。
- **量化口径**：
 - **前 2~3 项累计影响度应达 70% 以上**（`25,六`）；`3,202页`："前三个项目往往累计影响度可达 70-80%，如能针对前三项做改善，便可得到 70% 以上的成效"。
 - **三区域理论**（源自《管理的突破》，`corpus_video\QC七大工具之柏拉图.txt`）：**关键的少数**（前几项高柱）／**尴尬的区域**（中间）／**吃药的多数**（尾部琐细项）。
 - 分类项目数建议 **5~9 项**；"其他"项不得过高。`3,202页`：其他项不应大于前几项，若大于时应再分析；通常项目别包括其他项在内，**以不要超过 4-6 项**为原则。`04.QC七大手法.txt`：区别关键项 = 累计比率 80% 之内 2~3 项。
 - 图形规格：横轴按项目别依大小顺序由高到低，"其他"项排末位；柱形宽度一致，**纵轴与横轴比例为 3:2**；纵轴最高点为总不良数；连接各项目与纵轴对应点的线为**折线而非曲线**。
 - 纵轴可表示：品质（不良数/退货数/不良率）、时间（维修/作业/运转时间）、金额（销售/损失/材料费）、安全（灾害件数/故障次数）、其他（缺席率/提案件数）。横轴可表示：现象（不良项目别/位置/区域）、时间（月/周/季/年）、设备（机器/治具）、作业者（人员/年龄/性别）、其他（厂商/作业方法）。
 - 计数值用柏拉图，**计量值用直方图**；每一不良项目损失金额不同时，纵轴应以损失金额表示。
- **判读与决策**：前 2~3 项累计 ≥70%（或 70-80%）→ **只改善前 2~3 项即可拿到 70% 以上成效**；"其他"栏比例过高或分类项目 >9 项 → 层别不良，先改分类再重做；对策前后对比时三条铁律：① 收集数据的期间和对象必须一样 ② 对季节性变化应列入考虑 ③ 对对策以外的要因也须注意，避免解决主因时其他要因突然增加。
- **常见错误/反例**：分类项目太多；"其他"栏比例过高；对策前后期间/对象不一致；用折线画成曲线；柱宽不一致、纵轴间距不等。
- **说明（缺口）**：语料只给"其他项不应过高 / 不应大于前三项"等**定性**表述，**未出现"其他项 ≤5%"这一明确阈值**（见 §9）。
- **出处**：〔`25, QC七大手法之六（柏拉图）.txt`〕〔`3, 某上市企业QC七大手法培训教材（202页）.txt`〕〔`8, 老QC七大手法讲解（101页）.txt`〕〔`04.QC七大手法.txt`〕〔`柏拉图.txt`〕〔`01.品管七大手法.txt`〕〔`corpus_video\QC七大工具之柏拉图.txt`〕

### 3.4 特性要因图（鱼骨图 / 因果图 / 石川图）
- **定义/目的**：一个问题（特性）受到一些要因影响时，将这些要因加以整理，成为有相互关系而且有条理的图形；因形似鱼骨又称鱼骨图，由日本质量管理学者于 1952 年提出，故又称鱼骨图（因果图）。两类型：**原因追求型**（由结果追原因）、**对策追求型**（由原因找对策）。
- **触发条件**：问题整理；追查真正原因；寻找对策；教育训练；柏拉图选定重点项后要展开原因（与柏拉图串用）。
- **操作步骤**：
 - 发散整理法 5 步：① 决定问题或品质的特征 ② 尽可能找出所有可能影响结果的因素 ③ 找出各种原因之间的关系，用箭头联接 ④ 根据对结果影响的重要程度，标出重要因素 ⑤ 标出必要信息。
 - 逻辑推理法 5 步：① 确定品质特征 ② 将品质特性写在纸的右侧，从左至右画一箭头（主骨），结果用方框框上 ③ 列出影响大骨的原因即第二层次作为中骨，接着列出第三层次 ④ 标出重要因素 ⑤ 标注必要信息。
 - `3,202页` 7 步：① 确定特性 ② 绘制骨架（右方画"□"填特性，自左至右画较粗主干线，末端画一向右箭头指向方框）③ 确定原因类别（5M1E：人/机/料/法/环/测量），以约 **60°** 斜线画向干线，比主干稍细 ④ 依据大原因再分出中原因（同样 60° 插线，比大骨稍细）⑤ 再详细列出小原因 ⑥ 圈出最重要的原因 ⑦ 记载所依据的相关条件（目的、日期、制作者、参加人员、其他）。
 - 制作方法 5 步（`23,四`）：① 决定问题或品质的特性 ② 决定大要因 ③ 决定中小要因 ④ 决定影响问题点之主要原因及顺序（**圈选 4~6 项**）⑤ 填上制作目的、日期及制作者。
 - `10,238页` 7 步：① 召集相关有经验人员（**4-10 人**）② 画主干及主要因素（人机料法环）③ 发言（脑力激荡，不可批评质问）④ 时间约 **1 小时**，**搜集 20-30 个原因**则可结束 ⑤ 圈红圈 ⑥ 再圈两圈、三圈 ⑦ 记下制图部门人员、制图日期、参加人员。
- **量化口径**：
 - 骨架规格：主幹要粗；大骨**数目 4~8 根**（`1,98页`）／**4~6 项**用框圈起来（`8,101页`）；斜度约 **60°**（`23`/`1,98页`），亦作 **60~80°**（`8,101页`）；每大骨是一隻小鱼（至少问到二次因→小骨，至少两根中骨）；末端骨须是"原因"而非"现象"；特性要加框，前面可加"为什么"。
 - 四大思考原则（`23` 列 6 项）：① 脑力激荡法 ② 5W1H ③ 5M 法（Man 作业者 / Machine 机器设备 / Material 材料 / Method 方法 / Measurement 量具仪器）④ 系统图法（另列 ⑤ 创造性思考法：特性/希望点/缺点列举法 ⑥ 自由讨论）。
 - **脑力激荡法四原则**：① 严禁批评他人的构想和意见 ② 意见愈多愈好 ③ 欢迎自由奔放的构想 ④ 顺着他人的创意或意见发展自己的创意。实施：人员 **6~12 人最宜**（`8`）/ 5-10 人（`10`）；时间 15-60 分钟（`8`）/ 30 分左右不超过 1 小时（`10`）；记录员最好 2 人；准备小铃；一次只一个主题。
 - **5W1H**：WHY 为什么做·目的何在；WHAT 做什么·内容为何；WHERE 在何处做；WHEN 在何时做；WHO 由谁来做；HOW 如何做。（`3,202页` 为 5W2H，多 HOW MUCH 花费多少。）
 - 重要原因数目：`3,202页` **2-3 个，最多不超过 5 个**；圈出后应**到现场核实**并采取措施、经实践验证效果。
 - **像话原则**：你的鱼骨图……像话吗？**丰田原则**：连问五次 Why。
- **判读与决策**：圈选出的要因应整理出来**重新制作另一张特性要因图**；重要原因最终锁定 2-3 个（≤5 个），据此列对策表（要因→对策→责任人→期限）组织实施并验证；末端的骨若还是"现象"而非原因 → 继续问 Why，直到能直接采取措施。
- **常见错误/反例**：未层别化；只列现象不追"为什么"；大骨过多过散（>8）；把现象当末端原因；一个问题画多张因果图以外的混杂；凭个人好恶圈选；未记入必要事项。
- **出处**：〔`23, QC七大手法之四（鱼骨图）.txt`〕〔`01.品管七大手法.txt`〕〔`3, 某上市企业QC七大手法培训教材（202页）.txt`〕〔`8, 老QC七大手法讲解（101页）.txt`〕〔`10,顾问公司精品新老QC七大手法培训教材(238页).txt`〕〔`因果图.txt`〕〔`04.QC七大手法.txt`〕

### 3.5 直方图（Histogram）
- **定义/目的**：将收集的数据（特性值或结果值）用一定范围在横轴上区分为几个相等区间，将各区间内测定值出现的次数累积起来，其面积用柱形画出的图形。用途：测知制程能力、计算产品不合格率、调查是否混入两个以上不同群体、测知有无假数据、测知分配形态、藉以订定规格界限、与规格或标准值比较。
- **触发条件**：n≥50 的计量值数据要了解分布；要判断制程能力（Cp/Cpk 前）；要制定规格界限；要看改善前后分布变化。
- **操作步骤**（8 步）：① 收集数据并记录（注意随机抽样、全部均匀取，数据个数 >50，一般 n=100）② 找出最大值 L 与最小值 S ③ 计算全距 R=L−S ④ 决定组数 K 与组距 H ⑤ 决定各组的上下组界 ⑥ 决定组的中心点 ⑦ 制作次数分配表 ⑧ 制作直方图（横轴表示各组组中点，纵轴表示次数）。
- **量化口径**：
 - **组数公式**：**K = 1 + 3.32·Lg N**（史特吉斯公式）；238 页版作 **k = 1 + 3.31(logn)**。
 - 组数参考表（`01/24`）：数据 10~20 → 6~10 组；50~100 → 6~10 组；100~250 → 7~12 组；250 个以上 → 10~20 组。〔`10/04` 版：～50→5~7；51~100→6~10；101~250→7~12；250～→10~20。〕
 - **组距 H = 全距 R ÷ 组数 K**（h = R/k）；组距一般取 **5、10 或 2 的倍数**，最好是测定单位（测定之最小单位）的整数倍。
 - **最小一组下组界 = 最小值 − 测定值之最小位数 ÷ 2**（整数取 1；小数取精确到的最后一位 0.1 / 0.01 / 0.001）；最小一组上组界 = 下组界 + 组距；第二组下组界 = 最小一组上组界。
 - **组中点 = 下组界 + 组距 ÷ 2**（＝(该组上限 + 该组下限) ÷ 2）。
 - 制程能力（与规格比较）：**Cp = T / (6σ)**（双边），**Cp = (Su − X̄)/3σ 或 (X̄ − SL)/3σ**（单边）；**Cpk = (1 − |Ca|)·Cp**，或 min[(Su − X̄)/3σ, (X̄ − SL)/3σ]；**Ca = (X̄ − Sc)/(T/2)**；σ = R/d2。
 - **七种形态判读（成因→结论）**：

| 形态 | 图形特征 | 成因 / 结论 |
|---|---|---|
| **正常型** | 中间高、两边低，有集中趋势 | 左右对称分配（正态分配），制程运转正常 |
| **缺齿型（锯齿 / 凹凸不平型）** | 柱形高低不一呈缺齿 | 测定值或换算方法有偏差、次数分配不妥；检验员对测定值有偏好（如偏好 5、10）或假造数据；测量仪器不精密或组数宽度不是倍数 |
| **偏态型（偏左/偏右型）** | 高处偏向一边，另一边拖长尾巴 | 理论上规格值无法取得某一数值以下（或以上）所致；须检讨尾巴拖长在技术上是否可接受；治具松动或磨损也会拖尾 |
| **绝壁型（陡壁 / 切边 / 断裂型）** | 一端被切断 | 数据经过全检、或过程本身经过全检，把规格以下数据完全剔除所致 |
| **双峰型** | 左右各一座山，中央次数少 | 两种分配相混合（两台机器/两家不同供应商/两种不同原料），**应先层别后再作直方图** |
| **离岛型（离散 / 孤岛型）** | 左端或右端出现分离的小岛 | 测定有错误、工程调节错误或使用不同原料；**必然有异常原因存在，去除即可** |
| **高原型（平顶型）** | 形状似高原 | 不同平均值的分配混在一起（过程缓慢变化），**应分层后再做** |

 - **与规格比较（7 种）**：符合规格——A. 理想型（能力足够，**平均值与规格中心一致，±4σ 落在规格内**）；B. 一侧无余裕（须使制程中心值与规格中心值吻合）；C. 两侧无余裕（须提高制程精度）。不符合规格——A. 平均值偏左（偏右）（平均位置偏差，追查固定设备/机器原因）；B. 分散度过大（标准差太大，制程能力不足，追查人员/方法，或放宽规格）；C. 完全没有按规格考虑，或规格订得不合理。
 - 应用注意：**异常值应先除去再分组**；组数过少失次数分配本质、过多无法简化。
- **判读与决策**：正常型 + 平均值与规格中心一致且 ±4σ 在规格内 → 制程良好，维持；双峰/高原/离岛 → **先层别再重作**（离岛去除异常点）；偏态/绝壁 → 检查是否全检剔除/技术上是否可接受；平均值偏移 → 追固定设备原因，使中心值右移（或左移）到规格中心；分散度过大 → 追人员/方法或放宽规格。
- **常见错误/反例**：未剔除异常值；组距不规整（未取 5/10/2 的倍数）；双峰/高原未层别；数据不足 50 个；非随机抽样。
- **出处**：〔`24, QC七大手法之五（直方图）.txt`〕〔`01.品管七大手法.txt`〕〔`直方图.txt`〕〔`04.QC七大手法.txt`〕〔`8, 老QC七大手法讲解（101页）.txt`〕〔`10,顾问公司精品新老QC七大手法培训教材(238页).txt`〕

### 3.6 散布图（Scatter Diagram / 相关图）
- **定义/目的**：将互相有关连的对应数据，在方格纸上以纵轴表示结果、横轴表示原因，用点表示出分布形态，根据分布形态判断对应数据之间的相互关系。成对数据三种对应关系：① 原因与结果 ② 结果与结果 ③ 原因与原因。作用：了解两变量是否存在相关；检查孤岛（异常点）现象；相关高时二者可互为替代变量。
- **触发条件**：猜某"原因"影响某"结果"，要证据；要找异常点；要找出重大影响要因。
- **操作步骤**（5 步）：① 收集相对应数据，**至少 30 组以上**，整理写到数据表上 ② 找出数据之中的最大值和最小值 ③ 画出纵轴与横轴刻度，计算组距（横轴 X=原因/要因，纵轴 Y=结果/特性；坐标范围须包含最大最小值，横纵轴最大最小值之间宽度应基本相等）④ 将各组对应数据标示在坐标上（重复数据在点外加圈，重复 n 组加 n−1 圈）⑤ 记入必要事项（收集地点、时间、测定方法、制作者）。
- **量化口径**：
 - **相关系数 r**：`Lxx = ∑x² − (∑x)²/n`；`Lyy = ∑y² − (∑y)²/n`；`Lxy = ∑xy − (∑x)(∑y)/n`；**`r = Lxy / (Lxx·Lyy)^(1/2)`**。
 - **r 值判读表**（`10,238页`）：r = 1 完全正相关；1 > r > 0 正相关（越接近 1 越强、越接近 0 越弱）；r = 0 不相关；0 > r > −1 负相关（越接近 −1 越强）；r = −1 完全负相关。r 满足 −1 ≤ r ≤ 1；r 绝对值越大线性相关越强。
 - **符号判定法**（`散布图.txt`）：将图以中位数线分区，`n⁺ = n1 + n3`，`n⁻ = n2 + n4`；据 n⁺ 与 n⁻ 之差判断相关程度（实例 n⁺ = 28、n⁻ = 25）。
 - **六种相关形态**：① 强正相关（X 增 Y 也增，呈一直线）② 弱正相关（分布较广但有向上倾向，X 增 Y 一般也增但非相对性，可能还有其他因素影响，须再调查其他要因）③ 强负相关（X 增 Y 反减，呈一直线）④ 弱负相关（非显著性负相关，X 增 Y 减幅度不明显，尚有其他因素影响）⑤ 无相关（分布杂乱无任何倾向，应先层别再分析）⑥ 曲线相关（X 增 Y 增，增至某值后 Y 反减，分布有曲线倾向）。
 - Excel 拟合三参数（`10,238页` 思考题）：`Intercept a=170.1`、`Slope(Linearity) b=−0.55`、`Goodness of Fit r²=0.699`；b 为负 → 强负相关。
- **判读与决策**：强正/强负 → 可只控制 X 即可控制 Y（X 与 Y 互为替代变量）；弱正/弱负 → 还有其他因素，须再调查其他要因；**无相关 → 先层别再分析**；呈曲线 → 用曲线方程拟合；有异常点 → **查明原因后再删除**，不可任意下结论。
- **常见错误/反例**：数据不足 30 组；对无相关数据未层别即下结论；把异常点随手去掉；勿依据技术、经验作直觉判断；数据太少容易误判；假相关（技术上认为无关却显示相关）未进一步检讨。
- **出处**：〔`22, QC七大手法之三（散布图）.txt`〕〔`04.QC七大手法.txt`〕〔`散布图.txt`〕〔`10,顾问公司精品新老QC七大手法培训教材(238页).txt`〕〔`01.品管七大手法.txt`〕〔`corpus_video\QC工具之散布图法.txt`〕

### 3.7 管制图（Control Chart / 控制图）
- **定义/目的**：从每日生产产品线测得的零乱数据中，找出经常发生和偶然发生事故的数据，以便帮助找出问题原因。由中心线（CL）、管制上限（UCL）、管制下限（LCL）三条线加记录点/记录线构成；1924 年由 Shewhart 博士发明，以 ±3σ 订立管制界限。分**解析用**（数据齐备、相同条件，研究制程是否异常）与**管理用**（逐日测量绘入，随时判断、预防不良）两类。
- **触发条件**：要区分"经常/偶然事故"；要判断制程是否安定（该不该停线、调机）；要长期监控某品质特性。
- **操作步骤**（X̄–R 计量值 8 步）：① 确定产品型号、工序名称、品质特性 ② 确定控制图格式、规定子组大小（**2-5 个数据为一组，一般 4-5 个**）与频率 ③ 收集 **100 个以上数据**，依测定先后顺序排列 ④ 将各组数据记入数据表 ⑤ 计算各组平均值 X̄ ⑥ 计算各组极差 R（最大值−最小值）⑦ 计算总平均 X̄̄ 与极差平均 R̄，计算控制界限（X̄ 图与 R 图各一组）⑧ 绘水平中心线及控制线，将各点点入并用短实线依次相连；据判稳/判异准则判定制程是否存在特殊原因。
- **量化口径（全部公式原样保留）**：
 - **管制图选用逻辑**：数据性质 → 样本大小 → CL 性质。
 - 计量值：N=1 → X 图；N≥2 → X̄–Rm；N=2~5 → X̄–R；N=3 或 5 → X̃–R；N≥10 → X̄–S。
 - 计数值：不良数（N 相等 → Pn 图；不等 → P 图）；缺点数（单位大小相同 → C 图；不同 → U 图）。
 - **计量值管制图公式**：

| 图 | CL | UCL | LCL | 附注 |
|---|---|---|---|---|
| **X̄** | CL = X̄ | UCL = X̄ + A2·R̄ | LCL = X̄ − A2·R̄ | n=2~5 最适当，n<10 以下 |
| **R** | CL = R̄ | UCL = D4·R̄ | LCL = D3·R̄ | — |
| **X̄–S（X̄ 图）** | CL = X̄ | UCL = X̄ + A3·S̄ | LCL = X̄ − A3·S̄ | 10 ≦ n ≦ 25 |
| **X̄–S（S 图）** | CL = S̄ | UCL = B4·S̄ | LCL = B3·S̄ | 同上 |
| **X̃–R（中位数图）** | CL = X̃ | UCL = X̃ + m3·A2·R̄ | LCL = X̃ − m3·A2·R̄ | N=3 或 5 较佳；其 R 图与 X̄–R 之 R 图相同 |
| **X–Rm（单值图）** | CL = X̄ | UCL = X̄ + E2·R̄m | LCL = X̄ − E2·R̄m | k：组数，n：样本大小 |
| **X–Rm（Rm 图）** | CL = R̄m | UCL = D4·R̄m | LCL = D3·R̄m | — |
| **X–Rs（`8,101页` 写法）** | CL = X̄ | UCL = X̄ + 2.659·R̄s | LCL = X̄ − 2.659·R̄s | Rs 图 UCL = 3.267·R̄s |

 - **计数值管制图公式**：

| 图 | CL | UCL | LCL | 附注 |
|---|---|---|---|---|
| **P（小数）** | CL = P̄ | UCL = P̄ + 3√[P̄(1−P̄)/n] | LCL = P̄ − 3√[P̄(1−P̄)/n] | P 使用小数；下限为负取 0 |
| **P（%）** | CL = P̄ | UCL = P̄ + 3√[P̄(100−P̄)/n] | LCL = P̄ − 3√[P̄(100−P̄)/n] | P 使用 % |
| **P（n 不等）** | CL = P̄ | UCL = P̄ + 3√[P̄(1−P̄)/ni] | LCL = P̄ − 3√[P̄(1−P̄)/ni] | n 相差 <20% 用 n̄，>20% 用 ni |
| **Pn** | CL = Pn̄ | UCL = Pn̄ + 3√[Pn̄(1−P̄)] | LCL = Pn̄ − 3√[Pn̄(1−P̄)] | n = 1/P̄ ~ 5/P̄ |
| **C** | CL = C̄ | UCL = C̄ + 3√C̄ | LCL = C̄ − 3√C̄ | 样本大小相同时使用，n=20~25 |
| **U** | CL = Ū | UCL = Ū + 3√(Ū/n) | LCL = Ū − 3√(Ū/n) | 样本大小不同时使用（阶梯界限），n=20~25 |

 - **管制图系数表（n = 2~10，`8,101页` / `10,238页`）**：

## 5. 打法（组合拳）

**打法 A：不良率高、不知从哪下手**（最常用）
1. 用**查检表**按不良项目别收集 1~2 周数据（项目从要因图圈选的 4~6 项定）→ 产出：不良项目计数表。
2. 用**层别法**（时间/线别/机台/班别/材料）把数据切开 → 产出：分层不良率表。
3. 用**柏拉图**对差异最大的层排序 → 产出：前 2~3 项 ≥70% 的关键项清单（改善靶心）。
4. 对关键项用**特性要因图**追根因（4M1E，连问 5 个 Why）→ 产出：2-3 个重要原因 + 对策表。
5. 对策后再用**柏拉图**做前后对比（期间/对象一致）→ 产出：改善效果确认。

**打法 B：制程能力不足、要判"能不能接这张订单/能不能放宽规格"**
1. 用**直方图**（n=100）看分布形态与规格关系 → 产出：正态？偏移？分散？在不在规格内？
2. 算 **Cp / Ca / Cpk** 判等级（A/B/C/D 或 Ⅰ~Ⅴ）→ 产出：能力等级 + 处置建议（维持 / 改进 / 放宽规格 / 停线）。
3. 用**管制图**（X̄–R）判制程是否安定 → 产出：判稳/判异清单，异常点逐点追因。
4. 若分布双峰/高原 → 回**层别法**重做直方图。

**打法 C：想证实"某个原因真的影响结果"**
1. 用**散布图**（≥30 组）画 X（原因）—Y（结果）→ 产出：六形态判定。
2. 若弱相关/无相关 → **层别**后重画；算**相关系数 r**、或符号判定 n⁺/n⁻ → 产出：r 值与显著性判断。
3. 强相关 → **固定/控制 X 即可控制 Y**；或作为鱼骨图圈选重要要因的量化证据。

**打法 D：现场要日常盯质量、异常要立刻报警**
1. 定管制项目 → 选图（计量值 N=5 用 X̄–R；不良率用 P 图）→ 收 100+ 数据算 CL/UCL/LCL → 产出：管制图。
2. 每天打点，按**判稳（25/35/100 点）+ 判异（连串/趋势/接近界限/周期/过于集中）**双准则判读 → 产出：异常点清单。
3. 异常点逐点追查具体原因（如"新原料加入""无经验员工操作"）→ 对策 → 剔除后重算界限或修订标准。

## 6. 案例（保留数据）

**案例 1：电缆厂 A/B 设备直方图（含层别）**
- 背景：某电缆厂两台生产设备，经常发生不符合规格值（**135~210 g**）的异常产品。
- 做法：对 A、B 两台设备分别测定 **50 批**产品。全体最大值 **194**、最小值 **119**；根据经验取组数 **10**；组距 =(194−119)/10 = **7.5 取 8**；最小一组下组界 = 119 − 1/2 = **118.5**，上组界 = 118.5+8 = 126.5。次数分配（组中點 122.5/130.5/138.5/146.5/154.5/162.5/170.5/178.5/186.5/194.5）合计 100（A 设备 50 + B 设备 50）。
- 结果：全体分布**稍偏左**；**A 设备全部在规格界限内，没有不良品**；**B 设备可能发生超出规格下限的可能**，须使数据平均值右移到规格中心；A 设备若能使 CP 值再小则更好。
- 可迁移点：整体看不出问题时，用**层别**分开 A/B 才能定位问题设备。
- 〔出处：〔`24, QC七大手法之五（直方图）.txt`〕〔`01.品管七大手法.txt`〕〕

**案例 2：某电子器件企业厂 MOUSE 包装袋 P 管制图**
- 背景：检验包装袋底部是否破损（破损即不良品）；取 **30 个样本**，每样本数 **50 个**，机器每天三班制连续工作**每半小时取一次**。
- 做法/结果：平均不良率 **P̄ = 0.233（CL）**；**UCL = P̄+3√[P̄(1−P̄)/n] = 0.412**；**LCL = P̄−3√[…] = 0.054**。样本 **12 与 25** 两点超出管制上限，制程处于非管制状态。
- 根因：样本 12——这半小时里有一批**新进的包装袋原料**被使用（新原料加入）；样本 25——有一个**没有经验的员工**在操作此机器。
- 可迁移点：管制图异常点必须逐点追查**具体原因**，而非只报"异常"；确认后将超限两点删除，重新计算管制界限。
- 〔出处：〔`01.品管七大手法.txt`〕〔`26, QC七大手法之七（管制图）.txt`〕〕

**案例 3a：紫铜管 X̄–R 管制图（全铜棒内径，`8,101页`）**
- 背景：某厂制造全铜棒，选内径为管制项目，每小时随机抽取 **5 个**样本，共收集最近制程 **125 个**数据，依测定顺序排成 **25 组**。
- 结果：**X̄ = 1254/25 = 50.16**，**R̄ = 120/25 = 4.8**；N=5 查 **A2 = 0.58，D4 = 2.11，D3 = 负值（以 0 代表）**。
 - X̄ 图：CL = 50.16；UCL = 50.16 + (0.58)(4.8) = **52.93**；LCL = 50.16 − (0.58)(4.8) = **47.39**。
 - R 图：CL = 4.8；UCL = (2.11)(4.8) = **10.13**；LCL = (0)(4.8) = **0**。
- 可迁移点：计量值用 X̄–R 双图，分别看"均值漂移"与"变异大小"。
- 〔出处：〔`8, 老QC七大手法讲解（101页）.txt`〕〕

**案例 3b：X̄–R 管制图（`01/26` 另一版本）**
- 数据：**X̄ = 40.264，R̄ = 5.48**；N=5 查 **D4 = 2.115，D3 = 0**。
 - X̄ 图：CL = 40.264；UCL = **43.4249**；LCL = **37.1031**。
 - R 图：CL = 5.48；UCL = **11.5867**；LCL = **0**。
- 结论：第 **16、23** 个样本组点分别超出管制上限及下限，表示**制程平均发生变化**；R 管制图无点超出界限或在界限上，表示**制程变异并未增大**。

**案例 3c：P 管制图（每 2 小时抽 100 件，`8,101页`）**

- 结果：**CL = P̄ = 125/2500 = 0.05 = 5%**；**UCL = P̄ + 3√[P̄(100−P̄)/n] = 11.54%**；**LCL 为负值，视为 0**。

**案例 5：层别法——4 号线不良改善（`层别法.txt`，完整数字）**
- 背景：车间 4 条装配线，装配不良率高。
- 做法与结果（三级层别）：
 1. **线别层别**：1 号线 24、2 号线 27、3 号线 26、**4 号线 50**（占比 39.4%，累计 60.6%），4 号线最高。
 2. **不良项目别层别（4 号线，总不良 133）**：没装配到位 54（41%，累计 41%）→ 错装漏装 36（27%，累计 68%）→ 紧固不良 14（11%，累计 79%）→ 电路电器问题 11（8%，累计 87%）→ 外壁碰划伤 6（4%，累计 91%）→ 其他 12。
 3. **时间别层别**（周一均值 18.23、周二 15.725、周三 15.26、周四 15.625、周五 15.575、周六 15.6775）：**周一不良率几乎为其他时间的二倍**。
- 结论：4 号线装配不良率最高应重点改善；"没装配到位、错装漏装、紧固不良"为重点改善项目；周一应重点注意、加强员工质量意识。
- 可迁移点：层别可**多层分解**，先定位线别、再定位项目、再定位时间。
- 〔出处：〔`层别法.txt`〕〕
