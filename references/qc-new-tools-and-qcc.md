| **总体 / 样本** | 总体＝所研究的全部；样本＝从中抽取用于观测的部分；用样本推断总体 | 样本量不足即下结论＝无效推断 |
| **三现主义 / 三不政策** | 三现＝现场·现物·现实；三不＝不制造不良品、不良品不后流、不接受不良品 | 不是"靠检验拦不良"，是从源头断绝 |
| **QCC 品管圈** | Quality Control Circle：同一工作现场/工作关联区域人员**自动自发**进行品质管理活动所组成的小组；1962 年日本科技联盟(JUSE)建立 | 圈**必须注册登记**才受公司认可、才有资格参评优秀圈 |

## 3. 方法/工具逐项展开

### 3.1 亲和图（KJ 法 / Affinity Diagram）
- **定义/目的**：针对不很清楚的问题，从浑沌状态中把收集到的**语言资料**按其间类似性、亲和性分析归纳，使问题明确化；1953 年川喜田二郎创。分类：**个人亲和图**（重点在资料整理）/ **团队亲和图**（发动全员、重点在策略）。
- **触发条件**：讨论未来问题；讨论未曾经验的问题（如"如何导入 TQM"、新产品/市场预测）；针对以往不太注意的问题，从新角度重新评估；要获取部属心声、贯彻公司方针。
- **操作步骤**（8 步，`14`；`15` 版 9 步）：
 1. **决定主题**（可用：对杂乱事物求掌握／整理小组想法／归纳未理清思想／打破旧观念／读书心得／小组沟通）→ 产出：主题卡。
 2. **收集语言资料**（直接观察法／文献调查法／面谈调查法／个人思考法／团体思考法＝脑力激荡）→ 产出：语言资料。
 3. **重新确认、修正语言资料**。
 4. **语言资料卡片化**（文字尽量简单精练明了）。
 5. **卡片汇集、分群**（充分混合、摊开一览无遗，由主席引导找出最具亲和力的卡片）。
 6. **制作亲和卡**（把小组感受的意思表现出来写在卡片上，颜色区分）。
 7. **卡片配置排列**（一叠叠亲和卡依次排在大纸上粘贴固定）。
 8. **完成亲和图**（用框线连结亲和卡与资料卡；框线粗细/颜色区分更清楚）→ 完成后全员讨论、指定专人写报告。
- **量化口径**：卡片分群时**初期尽量具体，逐步提高抽象度**（步骤 5~7 反复进行并提高抽象度）；无固定阈值。
- **判读与决策**：图完成后若零散卡片仍混淆 → 关系未理顺，需继续分群/提高抽象度；理清后即转下一手法（对问题用关联图、对目标用系统图）。
- **常见错误/反例**：把数值资料硬塞进亲和图（应用老七）；把关联性弱的卡片勉强归一群；卡片文字过长无法一眼读懂。
- **出处**：〔出处：14新QC七大手法〕〔出处：15带案例讲解〕〔出处：07新旧七大工具〕〔出处：QC九大步骤〕

### 3.2 关联图（Relation Diagram）
- **定义/目的**：对原因复杂缠绕的问题，把与其有关的各种因素用箭头连接、展开成 1 次/2 次原因，使因果关系明朗化，**找出主要原因（必须采取对策的重点项目）**。
- **触发条件**：制造工程不良对策；市场抱怨对策；业务改善；QA/QC 方针展开；采取预防措施时；明确事件内容与关系时。
- **操作步骤**（`14` 版）：①确认目的 ②问题探讨（制作原因卡、排列卡、决定一次原因）③订出卡片因果关系 ④制作关联图 ⑤看关联图 ⑥修正图形 ⑦圈出重要项目 ⑧重要项目具体实施计划 ⑨关联图再修订。`15` 版：决定主题→列举原因→整理卡片→集群组合→以箭头联结原因结果（尽量用"为什么"发问）→整体检讨修正（主题置中）→粘贴卡片画箭头→明确重点（重要原因着色）→写出结论总结。
- **量化口径/制图规则**：问题用**粗框**圈起，箭头**只进不出**；末端原因的箭头**只出不进**。四种型式：**中央集中型 / 单方向集中型 / 关系显示型（不画问题点）/ 多问题点型**。
- **判读与决策**：指向箭线最多者＝主因；据"问题点→1 次原因"结构圈出重要项目，做具体实施计划，再回头修订关联图。常见"亲和图找问题 + 关联图明构造"组合。
- **常见错误/反例**：一次原因未定就画箭头（结构混乱）；把现象当末端原因；画完不改（图与现场脱节）。
- **出处**：〔出处：14新QC七大手法〕〔出处：15带案例讲解〕

### 3.3 系统图（树图 / Tree Diagram）
- **定义/目的**：为达成目标或解决问题，以"**目的—手段**"或"**结果—原因**"做有系统的层层展开（质问 1→2→3→4），寻求最适当手段/最根本原因。
- **触发条件**：方针目标展开、质量保证计划展开；新产品设计质量展开；可当因果图使用；明确部门职能；质量问题/成本/交期解决方案的创意展开。
- **操作步骤**（9 步，`15`）：①组成制作小组（选有相同经验/知识者）②**决定主题**（粗体字写卡）③记入**限制条件**（人/事/时/地/物/费用/方法）④**第一次展开**（讨论达成目的的方法）⑤**第二次展开**（把一次方法当目的继续展开）⑥同样展开第三、四次，直到可具体行动、可在日常管理中考核 ⑦制作实施方法**评价表**（按**重要性·可行性·急迫性·经济性**评价，用分数表示）⑧卡片与评价表贴白板，过 1 小时/1 天后复查有无遗漏 ⑨填入完成年月日、地点、小组成员等履历。
 （`14` 版 7 步：设定问题目标→记限制条件→一次展开→二次展开→作实施手段评价表→作成系统图→填履历。）
- **量化口径（评价表）**：**总分 ＝ 重要性 × 可行性 × 急迫性 × 经济性**；例证（"如何推行全面品质管理"）：单项 3 分＝相关性很强、2 分＝一般、1 分＝弱；实得总分最高 **81**（第①顺位）>36（②）>27（③）>24（④）>18（⑤）>16（⑥）。两种型态：**对策展开型**（目标/目的→对策手段）/ **构成要素型**（问题构成要素）。
- **判读与决策**：总分最高项＝优先实施手段，填责任单位与完成期限；下级手段须**具体规定并提出实施对策与行动计划**，并做有效性评估。
- **常见错误/反例**：展开只到"口号"层不落到可考核动作；评价只凭个人喜好；未记履历（无法追溯）。
- **出处**：〔出处：14新QC七大手法〕〔出处：15带案例讲解〕

### 3.4 矩阵图（Matrix Diagram）
- **定义/目的**：从问题事项中找出成对因素群，分别排成行与列，在**交点**表示成对因素间的相关程度，以探索问题所在与形态、并获得解决问题的构想。
- **触发条件**：竞争对手分析；新产品策划；探索新课题；方针目标展开；明确事件关系；纠正措施排序；**在系统图/关联图/亲和图已分析到极限时使用**。
- **操作步骤**（7 步，`14`）：①决定事象组合 ②决定图别类型 ③决定各组要素 ④矩阵图作成 ⑤决定关联表示方法（◎○△）⑥考量对应与关联 ⑦符号记入。`15` 以 L 型的实例：先用系统图找出"工厂利润降低"的 1/2/3 次原因→把三次原因及对策排入 L 型矩阵→依相关程度评比分→**各项分数加总取最高三项**成改善决策。
- **量化口径**：符号 **◎＝非常重要或非常显著关联 / ○＝重要或有显著关联 / △＝有关联**（亦可写文字或数据于交点上）。五类型：**L 型**（A-B，最基本）/ **T 型**（两句 L 型：A-B 与 A-C）/ **Y 型**（三句 L 型：A-B、A-C、B-C）/ **X 型**（A-B、B-C、C-D、D-A 四个 L 型）/ **C 型**（不常用）。
- **判读与决策**：交点计分加总，**分数最高三项即决策项**；无数据时凭全员讨论把经验转为资讯决定，并在图旁注明成员、时间、地点、数据取得方式。
- **常见错误/反例**：行列要素不对等（属性不同类）；无数据又不讨论就直接下结论；把矩阵图当"关系罗列"用而不做计分排序。
- **出处**：〔出处：14新QC七大手法〕〔出处：15带案例讲解〕

### 3.5 矩阵数据分析法（Matrix Data Analysis / 主成分分析）
- **定义/目的**：把矩阵图上各元素关系**用数据定量化**表示，经整理、计算、判断、解析得出结果，用以决定新产品开发或体质改善重点；主要方法为**主成分分析法**（把多个变量化为少数综合变量的多元统计方法）。
- **触发条件**：客户需求调查/预测；竞争对手分析；新产品策划；方针目的展开；方案优化。
- **操作步骤**（`15` 汽车案例）：①收集资料 ②求相关系数 r ③作成矩阵 ④判断 ⑤结果。
- **量化口径（相关系数判读）**：r = 1 完全正相关（2 个向量相叠 0°）；0 < r < 1 正相关（30°）；r = 0 不相关（90°）；−1 < r < 0 负相关（120°）；r = −1 完全负相关。实例矩阵（5 人评 4 车）：A-C = **0.90**、B-D = **0.85**、A-D = **−0.60**、A-B = −0.35、B-C = 0.00、C-D = −0.43。
- **判读与决策**：取**正相关对**（A-C、B-D）的共同项目 = 消费者想要的（"流线型""TURBO"）；**负相关对**（A-D）取不同项目。结论："流线型"及"TURBO"主导汽车销售。
- **常见错误/反例**：评价取样不满足常态分布；量化比较不客观（评价者主观偏差）。
- **出处**：〔出处：15带案例讲解〕〔出处：QC九大步骤〕

### 3.6 PDPC 法（过程决策程序图 / Process Decision Program Chart）
- **定义/目的**：对为达成目标的计划，事先预测可能发生的障碍（不理想事态/结果），设计一系列对策，把过程尽量导向预期理想状态，**防患于未然**。
- **触发条件**：事项进展中要预测、判断各种问题；为回避重大事故发生；充实计划以免措手不及；新产品设计开发、计划实施中发生不测需迅速修正。
- **操作步骤**：
 - **逐步展开型**：①明确起点与最终目标 ②作达成目标的乐观步骤 ③预想步骤中可能发生的不好的结果/现象 ④提出解决对策 ⑤逐项展开 ⑥实施中用新情报重复 ③~⑤ 至达成目标。
 - **强制连结型**：①明确最初状态/最终预期结果 ②预想欲达最终结果可能发生的重大事故 ③作图标示发生重大事故的经过 ④提出解决对策。`15` 细步骤：认识记号（起点/目标、对策/方法、决策重点、时间经过、资讯提供或不确定事态）→主题卡置上方、目标卡置下方、中间留白 → 标限制/前提条件于右上 → 写现有已知各项事实（**以事实为依据，不可凭个人推测**）→ 脑力激荡提对策（不明确者检讨至明确，否则舍弃）→ 依时间顺序排列卡片、用箭头连结，跨途径有影响用虚线连结 → 全员检查有无遗漏（或交资深上级复查）→ 贴卡框过程并记入负责单位名称。
- **量化口径**：（语料未覆盖数值阈值）

### 3.7 箭线图（Arrow Diagram / 网络技术 / PERT / 统筹法）
- **定义/目的**：把推进计划所必需的各项工作按**时间顺序与从属关系**用网络形式表示（有向、无回路）；决定最适日程计划、找关键路线。1956 年杜邦提出 CPM、1958 年美国海军提出 PERT，1965 年华罗庚引入我国称"统筹法"。
- **触发条件**：为使多项工作有效率进行；进度管理与调整；掌握整体计划、显示各项工作相互关系；特别适用于**一次性工程或任务**（愈复杂收益愈大）。
- **操作步骤**（7 步，`14`）：①决定主题 ②列举必要作业/实施事项 ③各作业卡化 ④按先行/并行/后续排列时间顺序（可增减卡片）⑤作网络图 ⑥计算结点日程 ⑦绘出关键路线。**网络图编制三步**（`15`）：①工程/任务剖析分解（列工序名称＋紧前/紧后关系，汇编工序表）②绘制网络图（**有向、无回路；相邻两事项间只能一支箭；虚工序用虚线箭；编号由小到大**）③编号。
- **量化口径（全部公式原样保留）**：
 - **最快结点日程 tE**：出发点 tE=0；tE(j) = max[ tE(i) + Dij ]。
 - **最慢结点日程 tL**：终点 tL(n) = tE(n)；tL(i) = min[ tL(j) − Dij ]。
 - **事项时差** R(i) = tL(i) − tE(i)；**工序总时差** R(i,j) = tL(i,j) − tE(i,j)；**单时差** r(i,j) = tE(j) − t(i,j)。
 - **关键路线**＝时差为零的关键工序串联（可从多条；关键路线越多网络越优）。
 - **不确定型工序时间**：tM = (a + 4c + b) / 6；例 (4 + 4×7 + 16)/6 = **8（天）**。
 - **费用率** K = (CM − CN) / (TN − TM)；CM 最短时间费用、CN 正常时间费用、TN 正常时间、TM 最短时间。
 - **时间优化实例**：完工期 35 天→要求 30 天；把工序③→⑥由 18 天压到 13 天，再压⑤→⑥由 5 天到 4 天，得三条关键路线。
 - **时间-费用优化实例**：任务原订 32 天，缩至 24 天直接费用由 21500 增至 25650（增 4150 元）；**总费用最低 25400 元、对应工期 30 天为最优**（32 天总费用 25500、30 天总费用 25400）。
- **判读与决策**：tE、tL 相等（时差 0）→ 关键事项/工序 → 集中资源保其完工期；非关键工序有时差可挖潜力支援关键工序；用**平行作业／交叉作业**缩短总工期。
- **常见错误/反例**：网络图出现回路（闭环）；相邻两事项间画两支箭（重复）；编号重复或混乱；虚工序不用/滥用。
- **出处**：〔出处：14新QC七大手法〕〔出处：15带案例讲解〕〔出处：QC九大步骤〕

### 3.8 PDCA 八步骤 · QC 九大步骤 · 提问框架 · 脑力激荡
- **定义/目的**：PDCA 是质量管理活动的运转规律（戴明博士 1950s 提出），是"维持(SDCA)"与"改善(PDCA)"的运转轴。**四阶段**：P 计划（问题定义→行动计划）·D 实施·C 核查·A 处理（标准化与推广）。
- **PDCA 八步骤**（`4PDCA循环`）：①分析现状找问题（1.1 确认问题 1.2 收集组织数据 1.3 设定目标和测量方法）②分析各种原因/影响因素 ③找出主要因素 ④制定措施、提出行动计划（4.1 寻找可能解决方法 4.2 测试并选择 4.3 提出行动计划与资源）⑤实施行动计划 ⑥评估结果（分析数据）⑦标准化和进一步推广 ⑧在下一个改进机会中重新使用 PDCA。
- **PDCA 五特点**：①大环套小环、小环保大环 ②爬楼梯上升式（每转一周质量提高一步）③综合性循环（四阶段相对、非截然分开）④推动关键是"处理(Action)" ⑤全员推动（非个人力量）。另一表述（`11数据与QC七手法`）：①决定目标(P)②决定达成方法(P)③教育训练(D)④实施(D)⑤查核结果(C)⑥对异常采取处置(A)，持续转动称"盘状上升(Spiral up)"。改善步骤 5 步：问题点把握→现状分析→改善对策实施→实施结果确认→标准化。
- **QC 九大步骤**（`QC九大步骤`）：①发掘问题（工具：脑力激荡）②选定题目（工具：选题评估）③追查原因（鱼骨图，从 4M1E 找）④分析资料（查检表/管制图/直方图/特性要因图/柏拉图/散布图/层别法）⑤提出办法（鱼骨图）⑥选择对象（朝防止再发方向、对策无副作用）⑦草拟行动（**3W：WHAT / WHO / WHEN**）⑧成果比较（期间比较/特性值比较/无形成果比较；工具：柏拉图比较、推移图比较）⑨标准化（效果维持/减少因人而异/技术储蓄/明确权限责任/易于追查不良/教育训练）。
- **提问框架**：
 - **5W1H**：What 何事·Why 为何·Who 何人·When 何时·Where 何地·How 如何。
 - **5W2H**：+ How much（花费多少）。**6W3H**（`4PDCA循环`）：What/When/Who/Why/Where/Which/How/How many/How much。
 - **28 问**：5W2H × 4 个层次（如 WHO：是谁→为什么是他→有更合适的人吗→为什么是更合适的人）→ 定人/定时/定位/定原因/定事/定方法/定耗费。
 - **5 Why**：分析出原因后连问 5 次为什么，追到最源头不良原因。
 - **5M1E**：人 MAN·机 MACHINE·料 MATERIAL·法 METHOD·测 MEASURE·环境 ENVIRONMENT。**4M1E**：人/机/料/法 + 环境。
 - **SMART**：明确的 Specific·可量化的 Measurable·切实可行的 Achievable·注重结果的 Result-oriented·有时间限制的 Time-limited。
- **脑力激荡法四原则**（`1头脑风暴`）：①**自由奔放**（观念愈奇愈好）②**禁止批评/评论**（评判留到会后；8 项忌讳句："太新奇了/不实际/没意义/无法成功/不符合目的/成本会增加/不合道理/想法陈旧"）③**多多益善**（1 分钟出 1 个创意，3 分钟内发表 10 个设想）④**借题发挥**（可"盗用"别人构思）。**8 点要求**：有主题、主题单一、问题大要细分、要有幽默感、45~60 分钟内完成、主持人写白板、会后评价、创意分类（可立即实施/需研究调查/缺实用性）。**新形式**：635 法（6 人×3 张卡×5 分钟，半小时 6 轮共 108 个点子）；CBS 卡片式法（高桥诚创立，3~8 人，每人 50 张卡）。
- **判读与决策**：原因分析到"根因"才停；头脑风暴结束时以"1 分钟无新点子"为收尾信号。
- **常见错误/反例**：会上就评审（扼杀创意）；"别人已说过了""请解释一下你的意思"等主持人禁用语；把原因写成现象就转对策。
- **出处**：〔出处：4PDCA循环〕〔出处：2PDCA78页〕〔出处：QC九大步骤〕〔出处：1头脑风暴〕〔出处：07新旧七大工具〕〔出处：11数据与QC七手法〕

 - **现场评审 13 项**：①圈组成 2~5 分 ②集体活动及记录 5~12 分 ③TQM 培训 3~6 分 ④参与程度 3~6 分 ⑤资料数据收集应用 4~8 分 ⑥改进对策努力程度及有效性 5~12 分 ⑦效果维持巩固 4~10 分 ⑧发挥才智创造性 3~7 分 ⑨QC 手法应用熟练度 3~6 分 ⑩QCC 知识了解 3~6 分 ⑪活动经历及持续性 3~7 分 ⑫活动环境 2~5 分 ⑬对部门/岗位影响贡献 5~10 分。

### 3.11 统计基础（数据收集与整理）
- **定义/目的**：用样本推断总体，为改善提供事实依据。**数据＝事实**；数据管理三要求＝真实性、准确性、精密性；整理数据五原则＝改善前后条件须一致、收集后立即使用、目的明确。
- **触发条件**：任何要下结论的地方（柏拉图排序、管制图判稳、能力指数）。
- **操作步骤**：明确目的 → 定收集周期/时间/方式/记录/责任人 → 收集（真实性优先，不得人为修饰造假）→ 层别整理 → 用图表直观化（≤3 种颜色）。
- **量化口径（全量公式）**：
 - 均值 X̄ = AVERAGE；标准差 s = STDEV；**变异系数 CV = 标准差 ÷ 均值**（`EXCEL制作质控图模版` 实例：均值 X=108.41967741935485、SD=7.978551449091898、CV=0.07358951473570409；设定值均值 102.52、标准差 15.377999999999998、CV 0.15）。
 - **3σ 缺陷概率（正态）**：单侧缺陷概率 Z=0.0→0.5、1.0→0.15865525393145696、2.0→0.02275013194817921、3.0→0.0013498980316301035、4.0→3.167124183311998e-05、5.0→2.866515719235352e-07、6.0→9.865877004244794e-10；**两侧缺陷概率** Z=2.0→0.04550026389635842（64 ppm）、Z=3.0→0.002699796063260207（0.6 ppm）、Z=4.0→6.334248366623996e-05（0.001 ppm）。

 - **AHP 一致性**（若用层次分析法择优）：CI = (λmax − n)/(n−1)；CR = CI/RI；**CR < 0.1 通过**（RI 常数表语料未给，见 §9）。
- **判读与决策**：CV 越小数据越集中（离散越小）；CR<0.1 判断矩阵通过一致性检验，否则重调判断。
- **常见错误/反例**：只报平均数不看离散（须用直方图/管制图看）；数据造假；样本量不足；改善前后条件不一致就对比。

## 5. 打法（组合拳）

**打法 A：现场问题说不清、数据也少（"迷茫型"）**
1. 先用**亲和图**把大家零散的说法卡片化、按亲和性归纳 → 产出：主题卡群 + "问题到底是什么"的共识。
2. 若原因互相缠绕，转**关联图**把 1 次/2 次原因与箭头画清，圈出指入最多的主因 → 产出：主因圈选图。
3. 若目标是"怎么达成"，转**系统图**按目的一手段层层展开，并用 重要性×可行性×急迫性×经济性 打分 → 产出：实施手段评价表（总分排序）。
4. 若两组成对因素要定"谁影响谁"，用**矩阵图**计分取前三项；因素多且有数据则用**矩阵数据分析法**求 r 判相关。
5. 计划怕出意外，用**PDPC 法**预想不好结果并预置对策；工期紧用**箭线图**算 tE/tL 找关键路线。
- 每步产出物：图（亲和图/关联图/系统图/矩阵图）+ 一张排序表。全程不追求数字，追求**共识与遗漏补齐**。

**打法 B：要成立 QC 小组做改善（QCC 全流程排期 + 每阶段产出物）**
1. **组圈（P1~P3）**：填组圈登记表 → 成立推行委员会 → 新七大手法 + 统计方法培训 → 产出：章程、名单、培训记录。
2. **选题（D4~D6）**：每人提 2~3 个问题点 → 选题评价矩阵（队能力/急迫性/重要性/效果性，每项满分 10 分）→ 报主管批准 → 注册登记 → 产出：选题检查表、课题决定、登记表。**原则：3 个月左右能解决**。
3. **现状与目标（D7~D9）**：查检表收集 3~6 月数据 → 柏拉图找前 2~3 项 → 目标值 = 现况值+(1−现况值)×改善重点×圈能力 → 产出：现状调查表、排列图、目标柏拉图。
4. **真因（D10~D11）**：鱼骨图/系统图/关联图 → 要因确认计划表逐条验证（可控性、数据支撑）→ 产出：2~3 个真因。
5. **对策（D12~D14）**：对策表按 时间×效果×成本 评分择优 → 实施并记录 → 产出：对策实施计划表、过程记录。
6. **效果与固化（C15~C17）**：改善前后柏拉图/推移图对比，算达标率与进步率；有形成果换算金额、无形成果雷达图 → 标准化（作业标准/流程图）→ 产出：效果确认表、标准作业书。
7. **总结发表（A18~A20）**：汇总记录 → 写成果报告（11 项格式）→ 发表投影片 → 产出：成果报告、发表用投影片。

**打法 C：要做成果发表（报告逐页结构 + 评审要点）**
1. 按 **19 页模板**组织：封面 → 圈组介绍/构架 → 选题评价矩阵 → 选题背景 → 计划甘特图 → 现状调查（只描述不分析）→ 目标设定 → 要因分析与验证 → 对策拟定/实施 → 效果确认（改善前后 + 目标达成 + 无形成果）→ 标准化（原有标准/新标准/编号/负责人）→ 效果维持 → 总结与下步计划。
2. 内容按"**标题化·图表化·数据化**"写，少文字、不用太强专业术语；前言后语要呼应过渡。
3. 对照评分表自查：发表评审 6 项（选题 8~15、原因分析 12~20、对策与实施 12~20、实施效果 2~20、成果发表 8~15、成果特色 6~10）；现场评审 13 项（圈组成 2~5、活动记录 5~12、TQM 培训 3~6、参与度 3~6、数据应用 4~8、对策努力及有效性 5~12、效果维持 4~10、才智发挥 3~7、手法熟练 3~6、QCC 知识 3~6、经历持续 3~7、活动环境 2~5、影响贡献 5~10）。
4. 评审原则：从大处着眼找主要问题、客观有依据、**不在专业技术上钻牛角尖、不只以经济效益评优**。

**打法 D：要把结论落到 SPC 表单与 Excel 图表**
1. 收集 ≥100 个计量值数据（X-R 图按 4 组×25），**不要缩减每组样本数** → 产出：数据表。
2. 算 X̄/R̄，查系数（n=4：A2=0.729、D4=2.282、D3=0、d2=2.059）→ UCLx/LCLx、UCLr/LCLr → 产出：X-R 控制图（SPC表格_02/03）。
3. 算 Cp/Cpk/CPU/CPL/Pp/Ppk/CR 判能力（≥1.33 充足）→ 产出：过程能力证明报告（SPC表格_01）。
4. 按**判读 8 规则**（2/3A、4/5B、6 连串、8 缺 C、9 单侧、14 升降、15C、1 界外）判稳/判异；异常点填"事件日志（人机料法环变化）+原因+纠正措施" → 产出：异常处置记录。
5. 计数值用 P 图（UCL=P̄+3√[P̄(1−P̄)/n]）；分布用直方图（K=1+3.23logN）；用 Excel 模板出图。

## 6. 案例（保留数据）

**案例 1 · 某电子企业 QC 小组「提高总装一次下线合格率」（攻关型）**
- 背景：WE 柜机上半年实际下线合格率 **97.5%**，指标 99.4%（差 2%）。小组 5 人，组长孙胜功，注册编号 1020040602，活动 32 次（2004.6—2005.2）。
- 用了什么：现状调查→柏拉图（侧板不良 375/412 = **91.02%** 居首）→定目标 **99.5%**→树图要因分析→10 条要因逐条验证，确认 4 条要因（安装尺寸偏差、成型模具动模动程较小、定位尺寸不合理、压合后安装角度不到位）→对策（模具动程/定位/角度调整）。
- 改善前后：侧板不良率 91.02%→60.38%→40.57%→31.27%→26.95%→**10.03%**；下线一次合格率 97.5%→**99.5%**（最高 99.63%）；因侧板不良造成的装配不良由占缺陷率 **85.24% 降到 0**。
- 可迁移点：抓单个 91% 的"关键少数"即可达成整体目标。
- 〔出处：迅雷31页〕

**案例 2 · 某制造企业 QCC「改变生产模式提高能率」**
- 背景：多机种生产模式老化；用录像做工程策划/动作分析，区分"必须动作工时"与"非必须动作工时"。
- 用了什么：损失工时柏拉图（平衡率损失 **71S/36.2%**、治具 **51S/26%**、物料摆放 **38S/19.4%**、作业动作 **36S/18.4%**）→鱼骨图（人/治具/物料/方法）→对策（单元化、治具合并、零件盒重排、防欠品电批）。

- 可迁移点：以工程平衡率为能率改善抓手。
- 〔出处：恒毅33页〕

**案例 3 · 某 QCC 圈「端子耗料多」（PC 接插件）**

- 〔出处：戴明圈28页〕

**案例 4 · 某摩托车合资企业「GX 追随性不良改善」**
- 背景：2005 年 12 月"追随性不良"上升幅度大（**0.40%**），影响用户操作性/使用工况；目标降为 **0**。

- 〔出处：嘉陵本田36页〕

**案例 5 · 啄木鸟小组「降低整机生产不良率—FOR」（现场型）**
- 背景：制造总部海外分厂，FOR 约 **1.70%**，与既定 1.50% 目标有差距；目标下降 30%→**1.20%**。

**案例 6 · 医院彩虹圈「提高责任护士床边综合能力合格率」**
- 背景：28 人次考核中 16 人次 ≥90 分，合格率仅 **57%**。

**案例 7 · 精益圈「如何缩短产品交换时间」（第二期）**
