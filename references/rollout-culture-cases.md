# 分册 08-C 持续改善机制与实战案例（推行手册·下）

> **适用场景**：精益改善"推起来一阵风、过三个月就散"；员工只会一道工序、产量一波动就无人可调；财务指标与精益改善"打架"；改善成果没人追踪、没有标准化；提案箱没人投、投了没回音；QC 小组不会选题不会收尾；想知道自己企业离精益企业还差多远——出现"改善不持续、成果不固化、机制不闭环"这类问题时翻本册。触发关键词：多能工、绩效评价、持续改善十三要点、QCC、合理化建议、精益文化、实战案例。
> **语料来源**：`_distill/book-rollout/extract/A7-steps11-13.md`（《精益生产推行手册》第 14–16 章：步骤⑪精益文化/人才培养、步骤⑫绩效评价、步骤⑬全员持续改善）；`_distill/book-rollout/extract/A8-cases.md`（下篇第 17 章 5 个典型实例）。
> **一句话精华**：改善不是靠一次运动，而是靠"文化＋人＋绩效＋机制"四件套固化——如果将精益运营与传统绩效评价混淆在一起，公司将无法成功实现精益转型或持续改善〔p.287 / PDF 300〕；且"对于改变员工的行为，干中学比听说教更有效"〔p.267 / PDF 280〕。

## 2. 概念地基

| 概念 | 定义 → 判据 | 易混淆点（什么不是它） |
|---|---|---|
| **精益文化（三个层次，图 14-1）** | ①人们行为和人造现物（表层观察：持续改善经营活动促进创新发展；现地现物——坚信只有找到问题的根源才能做出正确的决策）②价值观和规范（告诉我们事情为什么这样和应该怎么样；关键是大家共享一些工作方面的核心价值观和信仰）③基本隐性潜在假设（组织无意识的、理所当然的理念，涉及工作目标、相关人员、奖励和惩罚）〔p.261–263 / PDF 274–276〕 | 精益文化不是"精益生产产生于日本文化的土壤，而不是我们的文化"这一说法所暗示的不可移植——"不能复制丰田生产方式，但可以通过吸收丰田的很多原则和价值观，建立自己的生产方式"〔p.261、267 / PDF 274、280〕 |
| **精益文化的构成** | 精益组织文化＝主要团队成员的日常体验和当前的行为。内容包括：①规划—执行—检查—行动（PDCA）②标准化③可视化管理④团队合作⑤自相矛盾的说法⑥热情〔p.261 / PDF 274〕（OCR 编号有乱，原样照录） | 不是墙上标语、宣传口号——文化是"日常体验和当前的行为" |
| **精益生产方式中的企业文化三要点** | ①以人为本、尊重员工（"尊重人"是"尊重人性"的前提）②鼓励员工提出合理化建议③崇尚行动（鼓励员工去干、去试、去体验，在尝试中学习）〔p.265–266 / PDF 278–279〕 | — |
| **OJT（On the Job Training）** | 在职训练/在岗培训：在实际履行职务之中，上司或前辈对于下属或后进者，以有计划或具体的形式进行相关业务指导训练〔p.273 / PDF 286〕。适合于技巧、技术与操作型任务 | 不是"扔到岗位上自己学"——是有计划、具体形式的指导训练 |
| **多能工 / 少人化** | 多能工＝能操作两种或两种以上不同工序的作业人员；具有操作多种机器设备能力的作业人员。少人化＝当产量变化时变更现场作业人数（通过多能工与 U 形生产线配合实现）〔p.274 / PDF 287〕 | 多能工不是"加班顶岗的救火队员"，而是标准能力建设中的一环 |
| **运营绩效 vs 财务绩效** | 传统绩效评价三大缺陷：①不能支持长期决策（财务指标诱导经理目光短浅）；②不能适应实际情况（精益改进后交货周期缩短、报废返工减少、存货周转加快，但从财务角度分析会出现"由于存货减少，单位产品的成本将会增加，公司的毛利可能降低"等截然不同的结果）；③不能用于改进作业（传统财务指标太综合，不能对基层雇员的行为提供有用的指导）〔p.286–287 / PDF 299–300〕 | 精益改进在财务报表上短期"变差"不等于改善失败——必须用非财务指标（首次合格率、按时交货率、进料到出货时间等）作为前导性指针 |
| **改善** | 一种哲学、企业经营理念、企业文化；强调员工的参与，追求更好的手段、方法〔p.301 / PDF 314〕。"'改善，改善，再改善'是丰田公司生产经营的信条"〔p.302 / PDF 315〕 | 不是大投入的技术改造——"更应该重视不花大钱的改善"（十三要点之十） |
| **绩效** | 企业经营管理的效益和效率的总称，以及对企业经营管理者经营管理成效的概括与汇总；可分为获利性绩效和成长性绩效、财务绩效和非财务绩效〔p.285 / PDF 298〕 | — |
| **QC 小组（QCC）** | 生产现场或工作岗位上的员工自愿组织起来，围绕企业经营目标、生产存在的问题，以改进质量、降低消耗，提高人的素质和经济效益为目的，运用质量管理的基本方法和分析改善工具进行改善的小组〔p.306–307 / PDF 319–320〕 | 不是行政指派的攻关组——"自愿参加、自愿结合" |
| **合理化建议制度** | 正式将改善结果吸收和应用于企业的一种制度（丰田称"创造性思考制度"）〔p.313–314 / PDF 326–327〕 | 不是意见箱——非建设性的批评和意见、个人薪金与人事变动不受理 |

## 3. 方法工具六格

### 3.1 工具 14：多能工（培养多能工实现少人化）

- **定义/目的**：多能工＝能操作两种或两种以上不同工序的作业人员〔p.274 / PDF 287〕。通过岗位轮换培养多能工，实现少人化——当产量变化时变更现场作业人数。
- **触发条件**：所有岗位只有一人能独立操作；产量波动需要调配人手；重点岗位、关键技能存在单点依赖。
- **操作步骤**：
  1. **选人（培养对象选择原则）**〔p.275 / PDF 288〕：技能或岗位选择——所有岗位都必须有两人以上能独立操作，所有技能都必须有多人完全掌握；重点加强重点岗位、关键技能的多能工培养。人员选择——优先选择工作态度好、原有技能稳定、工作质量高的员工；重要岗位、关键技能选文化基础好、领悟能力高的员工。
  2. **三阶段岗位轮换（表 14-3）**〔p.275–276 / PDF 288–289〕：
     - 第一阶段（现场管理人员轮换）：基层管理人员亲自作为多能工以身示范，在其所属各工作单位巡回换岗（如组长在各组之间依次轮换）；定期调动计划由车间制定，考虑被调动人员的经历、尚未担任过的工作、本人意愿、对现场工作的影响。
     - 第二阶段（作业人员组内轮换）：每个作业人员在组内各作业岗位间轮换，所属关系、人事关系基本不变；班组长制订作业训练计划，把组内所有作业工序分割为若干作业单位，排出多能工培育计划表。
     - 第三阶段（每天数次轮换）：组内流动可能性增大后，每天数次有计划地让每个作业人员变换所承担的作业，甚至每隔 2～4 个小时就能有计划地在组内全部作业工序中轮换。
  3. **三种培训形式（图 14-7）**〔p.275 / PDF 288〕：岗位轮换（按计划培训时间、进度轮换担任若干种不同工作）；在岗培训（非全职岗位培训，主要适用于现有骨干的多技能培训，一般采用**一周两天、为期两个月**的培训形式）；脱岗培训（安排到企业培训中心或外派外部机构，成本高、技能适应性不足，只有在非常必要时才对重要骨干采用）。具体培训时以前两种形式为主要形式。
  4. **制定多能工培训计划表（图 14-8，5 步）**〔p.276 / PDF 289〕：①调查生产现场员工所必要的技能，记录到多能化计划表横轴上；②把生产现场和作业者姓名记到纵轴上；③评价每个作业者所具有的技术力或技能，使用所规定的记号记录；④制定各作业者的未训练项目，确定培训计划和完成时间；⑤随着训练的进展而增加评价记号。
  5. **实施四要点**〔p.277 / PDF 290〕：①作业简单化（需花长时间才能学会的技能，特别是更换、调整的作业，是多能工培养的一大阻碍，操作应趋于简单化）；②适当指导（对每道工序关键最了解的是现场第一线管理者，多能工培养是基层管理者的重要工作事项）；③标准作业（新手培训着重作业顺序及内容，以书面方式表现，作业指导书、作业要领书、训练要领书准备妥当）；④整体推广（仅在某一个单位内实施有时会引起不平之鸣，最好整个工厂一起实施，由公司高层领导者发布通告；每天班前班后灌输多能工观念，定期举办多能工比武活动）。

#### 3.2.4 团队工作

- **定义/目的**：以小组为中心的组织体系采取的劳动和工作组织方法；团队由在生产中关系较为密切的相邻工序的员工组成，每个团队通常由 **3～8 人**组成，由一名工会成员担任团队领导〔p.279 / PDF 292〕。如小组需要许多技能才能完成所负责的任务，团队成员可包括有关的技术人员和管理人员，形成混合功能型团队。
- **操作步骤（目的六条）**〔p.280 / PDF 293〕：①组织原则主要根据业务的关系来划分（不完全按行政组织），可将成本、品质和交货期等方面的工作职责下放到团队；②决策权、行政权、责任完全统一，高层领导对团队内部决策和活动不干预，形成解决问题应急机制和合作改善工作机制；③培养团队成员维持遵循标准化工作、继续改进所必需的纪律——这是团队工作最重要的职能；④团队成员一专多能，扩大工作范围，使作业人员参与生产的管理工作；⑤提供不断改善工序的良好氛围，形成平等、团结、独立、自主的气氛；⑥充分发挥团队成员的积极性、智慧和创造力。
- **特征六条**〔p.280–281 / PDF 293–294〕：①职责下放，积极参与；②达成共识，共同协作（"团队内的所有工作都是我的"）；③相互尊重和信任（以长期的监督控制为主，避免对每一步工作的核查）；④一专多能，工作充实；⑤信息沟通和共享（通过会议、信息栏、可视化手段等及时交流，向顾客征询意见和建议，向供货商反馈产品问题和改进要求）；⑥管理层支持。
- **团队领导或成员的角色与责任（表 14-5）**〔p.279–280 / PDF 292–293〕：
  - 团队领导者（10 项）：团队规划（每月生产计划）；行政工作（政策、人力、轮班和休假安排和协调、纠正行动）；确认原材料、质量状况和小组领导者的检查；报告/跟踪每天生产的结果；改进项目（生产率、品质、成本、人类工程学等）；协调外面团队的支持；协调工序上下游、重要产品机种变更和重大维修的工作；帮助替代缺席的小组领导者的工作；鼓舞团队士气，发展与交叉训练团队成员；负责团队在安全性方面的绩效。
  - 小组领导者（10 项）：实现生产目标；工序的启动与控制；确保零部件与材料供应到工序；通过例行检查确认品质状况；确保作业人员遵循标准作业；制定快速维修的工作顺序；对团队发出的 ANDON 信号做出反应；帮助缺席者的工作；发展训练与交叉训练团队成员；促进小团队的活动，参与持续改进计划。
  - 团队成员（5 项）：在工作区域维持 6S；根据标准作业文件进行作业；执行例行的小规模维修工作；支持解决问题团队的工作；寻求持续改进的机会。
- **判读与决策**：ANDON（安灯）信号发出后小组领导者必须做出反应——信号无人响应即团队机制失效。

#### 3.2.5 组织和文化变革的五个主要结论（推行精益文化的路线图）

〔p.267–268 / PDF 280–281〕
1. **领导者必须领导**：从 CEO 顶层开始；领导者必须将自己转变成精益改造的领导者；改进依赖于任何时间都能坦率接受当前的形势；培养各层次的领导能力；长期的变革依赖于持续的领导。
2. **变革需要原因和愿景**：员工需要一个变革的原因；需要一个积极的、令人不得不接受的未来愿景；不能复制丰田生产方式，但可以通过吸收丰田的很多原则和价值观，建立自己的生产方式。
3. **员工必须得到培训和支持**：抵触变革是人的本性，可通过强烈关注改变思维的模式；干中学比听说教更有效；员工需要日常支持。
4. **变革需要计划和程序**：组织结构的变革必须支持态度和行为的转变；计划之前必须对精益转化的目的非常清晰、明确；在"局部地区深入实施"与"整个公司广泛推广"之间找到适当平衡；将整个历程分解成便于消化的步骤，任何计划都是试探性的；先建立人力资源支持结构；通过精益指导者的指导具体的改进活动培养员工，然后逐步将责任移交给直线型组织；投资于优质人力价值流。
5. **变革顺利运行与实施评价**：一线员工的参与和所有权；强大的团队能力使得他们可以解决自己的问题；领导用身教代替言传；对一个团队实现其未来目标的能力给予积极的评价。

### 3.3 工具 15：全员持续改善（十三个基本要点）

- **定义/目的**：改善是一种哲学、企业经营理念、企业文化〔p.301 / PDF 314〕。全员持续改善是把改善从"领导的项目"变成"每个人的日常"的机制。改善应遵循 PDCA 循环或 SDCA 循环，以达到维持标准和改进标准的目的〔p.305 / PDF 318〕。
- **触发条件**：出现"阻碍改善的七大问题"〔p.302 / PDF 315〕：①不思进取，安于现状（习惯、惰性）；②工作推过不主动，凡事畏缩和退缩；③责任心差，凡事都图平安；④遇事悲观、裹足不前；⑤置身事外，明哲保身，但求无过；⑥没有危机意识，原地踏步；⑦责难别人，部门隔阂和责任推〔OCR："责任推"疑为"责任推诿"，原样照录〕。
- **操作步骤（改善的目标，7 项）**〔p.302–304 / PDF 315–317〕：
  1. 提高改善意识，实现降低成本的目的——"如丰田每年的改善能节约七千亿日元"。
  2. 最短的交货期，提高顾客满足度——"如丰田公司的平均交货期为 20 天左右，生产线在接到订单后最快 4 天就可以把汽车生产出来"。
  3. 缩短从采购到加工、营销、回收资金的时间——"如丰田公司生产线上的零部件在库时间只有 2.5 小时，而其他厂家的库存时间都不低于 30 天，这样可降低相当于同类厂家占用的资金十几倍"。
  4. 不论经济是否景气，必须确保一定的利润——生产与销售挂钩，不生产多余产品。
  5. 尊重员工人性，运用他们的智慧——理解自愿式的经营方式。
  6. 不是卖出生产的产品，而是生产卖得出去的产品——"卖不出的产品就是最大的浪费"。
  7. 培养最优秀的人才——通过公正的评价和能力培养计划，对员工进行多能工化和对干部员工进行全面人才化的培育。

- **改善的六个阶段及其改善方法（表 16-2）**〔p.305 / PDF 318〕：
  1. **第 1 阶段：改善点的发现**——发现目前存在的问题（生产、质量、成本、安全等）。方法：①准时化（改善的第一大切入点，关键是解决停滞问题）；②自动化；③标准作业（从人作业改善和设备循环时间改善两方面进行）；④少人化（实现省人化）。
  2. **第 2 阶段：现状方法分析**——对现状实事求是分析，不漏任何细小之处。方法：①标准作业（定量地、详细地记录工人自身的作业顺序、标准在制品、机械配置及作业方法等现况）；②要素作业分析（把工作分解成要素作业，对每个要素进行 5W1H 提问）；③IE 的常用方法（流线图分析或线路分析法、动作分析法等）。
  3. **第 3 阶段：得到构思**——关键：①全面观察现场，采用原因追究方式；②连续问 5 个为什么；③相同条件重复作业是追究原因条件；④对问题点按 4M 进行分类以及相互关系明确因果关系；⑤采用动作经济原则、头脑风暴等构思方法。
  4. **第 4 阶段：改善方案制定**——六种方法：①排除（没必要去实施不需要的东西）；②组合变更（分离与组合，寻找更简单的方法）；③合适化（采用更适宜的方法，缩短不必要的步行距离、减少疲劳、充分发挥能力等）；④标准化（作业方法、设备及工具等实行标准化）；⑤同期化（使用多工位作业，使工序内的作业平准化，达到作业流畅）；⑥自动化（将人的工作置换为自动机械的工作）。
  5. **第 5 阶段：改善方案的实施**——两方面准备：①改善说明（向公司有关人员说明改善方案的概要，以得到其他人员的大力协助）；②工人培训（实行多技能培训，向员工传授最优秀的方法）。
  6. **第 6 阶段：改善效果确认**——实施改善方案后，应对其进行确认和评价。
- **改善的内容及注意点（图 16-2）**〔p.306 / PDF 319〕：分部门内容——营销部门要在订货、交货、客户管理以及回收货款上加大力度；设计部门不但要考虑产品的客户要求、产品性能、流行趋势、耐久性能等，还要做到产品在设计时就与高生产效率挂钩；生产部门在产品投产前后组织专门的改善队伍，进行不间断的改善活动并维持改善的结果，并培养改善队伍，使每个员工都得到改善的专业训练；物流部门要调节好安全在库数量，提高搬运效率。注意点：1.尊重员工的积极性，发挥员工的聪明才智；2.创造出全员积极参加改善的良好环境；3.开展持续性循环改善，维持改善的成果；4.在排除各种浪费的同时，还要注意作业负荷和平准化。全员改善重点实施：生产管理、制造和物流部门应配合做好拉动生产，设备部门推动全员设备管理、快速换线换模，质量管理部门推动全面质量管理等；负责精益生产推动部门应根据系统的计划，做好示范线改善的同时，做好重点改善的指导和支持。
- **判读与决策**：对照七大问题逐条自查；十三要点中第 1、2、4 条（领导以身作则、关心下属、容忍失败）是领导行为项，第 9、10、11 条（人人参与、不花钱、马上行动）是员工行为项——两类行为缺一类，改善机制即失衡。
- **常见错误/反例**：以"客户规定"和习以为常为借口不改善（违反要点 8）；搞个人英雄主义（违反要点 9）；只做 P 和 D 不做效果确认（违反第 6 阶段）。
- **出处**：〔p.301–306 / PDF 314–319〕

### 3.4 工具 16：QC 小组（QCC，质量管理小组）

- **定义/目的**：生产现场或工作岗位上的员工自愿组织起来，围绕企业经营目标、生产存在的问题，以改进质量、降低消耗，提高人的素质和经济效益为目的，运用质量管理的基本方法和分析改善工具进行改善的小组〔p.306–307 / PDF 319–320〕。
- **宗旨**：①提高职工素质，激发职工的积极性和创造性；②改进质量、降低消耗，提高经济效益；③建立文明的、心情舒畅的生产〔OCR 语句似不完整，原样照录〕〔p.307 / PDF 320〕。
- **触发条件**：现场存在需要系统查真因的质量/效率问题；已有零散改善但不成体系。
- **操作步骤（QC 小组活动实施流程，图 16-3，主流程 7 步）**〔p.307–310 / PDF 320–323〕：
  1. **组建 QC 改善活动小组**：根据**自愿参加、自愿结合；领导、技术人员和工人三结合**原则组建；形式多样（如"数控车床 1 班 QC 改善活动小组""设备维修 2 班 QC 改善活动小组"）；一般情况下，**以 310 人为宜**〔OCR 存疑：按上下文疑为"3～10 人"，原样保留〕；把有事业心、一定品质改进技能水平和善于团结他人的人选为小组长。在公司内登记并上报组织备案，填写注册登记表；也可在选择活动课题之后进行。
  2. **互相交流、学习改善的专业知识**：成员必须互相理解和信任，通过谈话等交流方式增进友谊；对自己目前的工作岗位所存在的问题提出建议，并一起学习有关 QC 管理知识。
  3. **选择 QC 小组活动课题**（选题范围见下）。
  4. **制定改善的计划和目标**：决定改善的目的、改善的顺序和成员的任务分担等，把具体内容做成活动计划书递交给上级管理人员，得到管理人员的同意认可。
  5. **实行改善活动**：(1) 调查现状——认真做好现状调查，应用不同的 QC 工具（如排列图、直方图等）进行数据的搜集整理，找出现状与用户的需求之间的差距；(2) 分析原因——发动全体组员动脑筋、想办法，通过头脑风暴法集思广益，然后选择适当的 QC 工具（如因果图、排列图等）进行分析，找出问题的主要原因；(3) 制定对策——主要原因确定后，制定相应的措施计划（5W1H 的方法），明确各项问题的具体措施、要达到的目的、由谁来做、何时完成以及检查人是谁；(4) 实施对策——按制定的实施对策实施并在实施过程中进行检查，发现偏差及时进行纠偏；小组长定期或不定期地研究实施情况，随时了解课题进展。子流程各环节间有"持续改善"回路。
  6. **总结并公布成果**：成果的主要内容包括成果名称、概述、选题理由、原因分析、措施计划、实施过程、实施效果、标准化措施、遗留问题、下一步打算，并将改善过程中所体会到的感想、遇到的困难和改善的成果一并公之于众。实行 QC 改善活动小组活动的公司每年都有一次 QC 改善活动的擂台赛〔OCR 原文"播台赛"，形近字〕，总经理亲自主持 QC 报告大会，并颁布总经理奖和奖金。
  7. **自我评价和继续活动**：对本次改善的不足点和学习到的知识、得到的经验进行总结与反省；按 PDCA 循环的结果，针对本次活动中未解决的问题继续改进，也可以重新选择课题，还可以重新组建新的更有针对性的 QC 小组开展新的活动（第 7 步回到第 4 步有"持续改善"大回路）。
- **选题的十一大方面**〔p.309 / PDF 322〕：提高质量；降低成本；设备管理；提高出勤率、工时利用率和劳动生产率，加强定额管理；开发新品，开设新的服务项目；安全生产；治理三废；改善环境；提高顾客（用户）满意率；加强企业内部管理；加强思想政治工作，提高职工素质。
- **选题的 5 个要点**〔p.309 / PDF 322〕：①课题选择必须符合公司方针、生产计划和工作需要，能够切实解决有关生产、工作和管理中的实际问题；②应当以保证和提高工作质量、服务质量作为重点；③选择 QC 小组成员共同关心的比较明显的、经常遇到的、最容易做起的、见效快的、比较关键问题和薄弱环节；④先易后难，注重能够解决的小课题；⑤选择具体课题，一定要有目标值。
- **作用与效果**〔p.307 / PDF 320〕：作用——①充分尊重人的主观能动性，有利于开发智力资源，发挥人的潜能；②有利于实现全员参与管理，提高员工的分析和解决问题能力；③有利于改善人际关系，强化团队意识和质量意识；④有利于改善和加强管理工作，提高管理水平；⑤有利于预防质量问题，并不断地进行改进。效果——①提高质量意识，解决质量问题；②提高效率，提高员工的技能，减少浪费降低成本；③改进工作态度，增加工作满足感；④提高士气，加强沟通与团结；⑤发掘人才，增强归属感，降低人员流失率；⑥创造更新的企业文化。
- **全流程样板案例（内嵌）——某半导体材料公司 QC 小组"降低清洗机点点停"**〔p.310–313 / PDF 323–326〕：
  1. 选题：绘制清洗机六大损失排列图（图 16-4），发现点点停是六大损失中最大的（损失时间 1522 分），决定把改善清洗机点点停作为焦点改善的课题。
  2. 调查现状：发现造成因素有很多（液温低、液面低、溢液等），其中最大的因素是设备槽液面低（图 16-5），课题聚焦到"改善清洗机设备槽液面低"。
  3. 确定目标值：清洗机点点停为 **58.5%**；经小组讨论，力争使其降低到 **15% 以下**。
  4. 寻找主要原因：小组会议头脑风暴找到十几条可能的原因（鱼骨图，图 16-6）；会后进行原因验证（现场观察、询问、调查、检测等手段），排除了大部分原因，确定了真正原因（表 16-4 要因验证表：潜在原因含清洗时被带走太多、不知道每次加多少、没时间点检液面、点检频率标准太低、不知道何时加水、清洗液太容易蒸发、看不清液面、缺自动报警装置、忘记点检液面、水阀门损坏、槽损坏漏水、没有加液标准；"是否真因"列勾选结果 OCR 未读出）。
  5. 制定对策：最终确定了**五个对策**（表 16-5 对策表）——加装自动报警装置（液位过低就蜂鸣报警，提醒加液）；改造水槽末端（回收部分被板带走的水）；更改点检周期（每班一次改为每两小时一次）；加液液位标识/液位可视化（报警液位标识）；加液数量明确化（满液标识）。
  6. 实施：制定完对策之后迅速展开行动，落实对策措施。
  7. 活动效果：持续收集有关数据，几个月以后发现点点停时间确实缩短了（图 16-7 趋势图）；**由于点点停时间降低到 12% 以下，损失减少**。
  8. 巩固措施：经过半年多的运行，活动效果稳定；此后按改进后的工艺编制工艺文件；建立工序质量管理点 2 个，纳入了生产线工序质量管理文件。

### 3.5 工具 17：合理化建议活动

- **定义/目的**：正式将改善结果吸收和应用于企业的一种制度（丰田称"创造性思考制度"）〔p.313–314 / PDF 326–327〕。
- **触发条件**：现场不合理现象多、员工有想法无出口、改善只靠少数骨干。
- **操作步骤（基本步骤 8 步，图 16-8）**〔p.315 / PDF 328〕：
  1. **确定问题**：发现生产过程中存在的问题就及时向现场管理人员汇报并确认；
  2. **调查问题**：必须仔细研究问题的现状，明确问题存在的主因；
  3. **提出方法**：经过调查并确定所要解决的问题之后，现场管理人员应鼓励作业人员思考解决此问题的方法，提出改善的合理化建议；
  4. **汇总建议**：现场管理者必须将解决问题的改善方案或建议汇集起来，与下属人员一起从中选出最令人满意的解决方案；
  5. **提出建议**：由质量管理小组中的任一成员把选出的改善方案抄写在合理化建议专用纸上，投入建议箱中；
  6. **建议实施**：通过设备改造、工艺改良、制度改进等措施，解决已发现的问题；
  7. **效果评价**：检查所采取的措施解决相应问题的程度，评定合理化建议；
  8. **形成标准**：对确有效果的改进措施，要形成标准、规范的方法加以推广实施。
- **受理范围**〔p.314–315 / PDF 327–328〕：**应受理**——经营管理制度的改善；操作、检测或其他一切作业程序或动作程序的改善；工厂布置的改善；治具、模具及工具等的改善；设备自动化、省力化、省人化及省时化的改善；产品品质、服务品质或设计的改善；物料、零件及产品等搬运方法的改善；原物料的节省，废料的降低或利用，以及能源节约等成本费用降低的改善；工作环境的改善和安全卫生的改善等。**不应受理**——非建设性的批评和意见、个人的薪金与人事变动等。
- **开展合理化建议的 5 项原则**〔p.314 / PDF 327〕：①**一般以小项目为主**（只要对确保安全、有利环保、提高质量、降低成本、减少消耗、降低库存、提高效率、改进管理有效的项目都可以提出，易实施、见效快的项目更佳）；②**是一项群众性活动**（要求全员参与、全方位开展）；③**是一项经常性的活动**（不可搞突击；随时发现问题，随时提出建议；各级管理部门要随时准备为实施改善提案提供服务和指导）；④**领导对合理化建议给予特别的关心和支持**（员工想提建议时，直属领导应积极主动地与员工谈话和一起考察现场；上司在审查提案内容时对每一个审查项目都会严格审查，以培养下属人员的改善活动能力和创造性思考的能力）；⑤**要及时奖励**（一定要突出奖励原则，保护员工提出合理化建议的积极性）。
- **丰田审查程序（5 步）**〔p.315–316 / PDF 328–329〕：
  1. **提案汇总**：每个月的第一天，各工厂和各部门收集来自基层的改善建议，汇总至办公室，并登录在"合理化建议提案记录册"上。
  2. **工厂和部门审查**：由工厂各部门的审查委员会先就所有提案进行充分的调查和审议，并确定可以获得 **5000 日元以下**奖金的改善提案；这项工作完成后，再由各工厂的审查委员会及部门的审查委员会进一步审议确定可以获得 **6000 日元以上**奖金的改善提案。
  3. **公司审查**：公司的合理化建议审查委员会的审查工作在每月终进行；公司级的审查一般是就奖金额在 **20000 日元以上**的重要建议的专案审查。
  4. **结果公布**：正式的审查结果要在审查结果一览表及丰田公司发行的报纸上进行广泛宣传。
  5. **奖励表彰**：对提案者给予奖金之外，还给予其他形式的表彰——每月末举行表彰仪式，公司向优秀改善建议的提案者授予奖状；每年度举行对集体单位的表彰大会，向优秀提案小组授予奖状和奖杯。
  - 组织保障：公司设立了专门的"合理化建议审查委员会"，每个工厂和每个部门也都设立了相应行政级别的"合理化建议审查委员会"〔p.315 / PDF 328〕。
- **量化口径（丰田实施成效，数字原样保留）**〔p.315–316 / PDF 328–329〕：丰田于 20 世纪 50 年代初开始"动脑筋创新"的制度，提出"好主意，好产品"的口号。制度五个特点——广泛性、规律性（各级审查委员会**每月**审查）、相关性（提案审查过程中使提案者与专业技术人员保持密切联系）、激励性、持续性。**在公司实施的第一年收到建议 183 条，到后来的 70 年代每年收集建议可达 5 万条**。（语料未覆盖人均提案数、采纳率、实施率数据。）
- **判读与决策**：好的提案制度必须包含：能有效的反映出改善要点的提案用表格；合理及易于操作的评分标准；营造良好的竞争氛围；合理的奖励标准〔p.315 / PDF 328〕。提案长期无审查回音＝制度失效信号。
- **常见错误/反例**：只收提案不审查不实施；把批评意见、薪资人事诉求当提案受理。
- **出处**：〔p.313–316 / PDF 326–329〕

### 3.6 绩效评价体系（步骤⑫：精益生产的绩效和成效管理）

- **定义/目的**：为精益转型配套的评价体系。总原则：绩效评价体系指标内容设计遵循**实用性、先进性，使过程考核与结果相统一**〔p.287–288 / PDF 300–301〕。实用性——必须适应企业自身的实际情况；评价结果能够真正说明企业竞争力的状况和管理上存在的问题；使用方便，尽可能降低评价的成本；过程考核与结果考核相统一——应当考核必要的经营管理结果指标，但更应当强调对于经营管理过程、方式和程序的考核。先进性——评价指标要体现精益管理的各项基本要素，要体现国际先进企业的管理做法和水平。
- **触发条件**：精益改善启动后发现财务指标与改善方向"打架"；改善活动无 KPI、无人追踪；仍在用单纯计件绩效考核。
- **操作步骤（构建思路，两层面）**〔p.288–289 / PDF 301–302〕：
  1. **精益单元层面**：按产品在企业中流经的部门，分为采购单元、生产单元、销售单元、售后服务单元以及财务单元等；这些单元的成本约占全部成本的 **60%～80%**。主要采用非财务指标进行考核，通过编制精益单元绩效报告，将实际成本与预算成本、各项非财务指标实际与预算对比，完成指标的好坏与奖惩挂钩，最终达到成本控制的目标。
  2. **价值流层面**：用来持续改进价值流，并成为一个重要的业务控制机制；每项指标的实际价值远没有**变革的速度和方向**重要；持续改进团队对所有价值流指标的快速和持续改善负责；各价值流的实际绩效指标不同，但所有价值流的绩效指标必须呈现稳步上升的趋势。采用财务指标与非财务相结合的方法——非财务指标优势：作为财务信息的补充；作为财务指标的前导性指针；实现对过程的及时跟踪；对所要评价的指标进行整体评价；对企业未来经营情况进行预测以避免传统评价指标的滞后性；更容易分清部门和员工责任等。
  3. **精益单元层面的指标（图 15-1，已回读图像核对）**〔p.289 / PDF 302〕：

| 精益单元 | 侧注 | 绩效评价指标（原样照录） |
|---|---|---|
| 销售单元 | 精益第一步 | 设置订单处理的时间、单位价值装运成本、装运差错率、按时装运率等指标 |
| 采购单元 | 控制费用的重要环节 | 设定首次合格率、在产品/标准在产品比率、总设备效率、平均原材料成本、平均转换成本等重要指标 |
| 生产单元 | 精益改善核心单元 | 设立如采购费用、储存费用、吊料和废料处理损失、平均单价等衡量指标，用来加强采购单元成本的控制〔原书如此：该行"用来加强采购单元成本的控制"置于生产单元行，语义归属存疑，原样照录〕 |

| 售后服务单元 | 价值流最后一个环节 | 设置平均维修成本、客户满意度、首次合格率、满足客户需求的反应速度等指标 |

  4. **价值流层面非财务指标（5 项）**〔p.290–291 / PDF 303–304〕：①**首次合格率**（产品生产过程一次合格数量除以产品生产总数量所得或加权平均所得；价值流层次的首次合格率应该等于各单元层首次合格率的**乘积**）；②**按时交货率**（从配货中心到达客户指定地点的准时交货率）；③**进料到出货时间**（从购买原材料到产品加工完毕并向客户发货所经历的时间；包含在同一价值流内的全部存货与平均批次装货量相除之商）；④**改善成效**（用改善前后的效果来评价，包括进行中的项目改善数，成本、生产率等管理项目的变化趋势）；⑤**提高员工士气与技能**。
  5. **价值流层面财务指标（6 项，表 15-1）**〔p.290 / PDF 303〕：存货价值（属于该价值流的存货的期末成本，即存货的账面价值；存货价值的变化可以成为反映企业精益改进的一个重要指标）；原材料成本（期间内公司耗费的原材料的价值）；转换成本（包括期间内运营价值流所产生的费用；精益改进初期，公司必须对重要的支持成本进行分摊，以说明运营价值流的真实成本）；平均总成本（价值流循环一周的总成本 ÷ 这段期间内发给客户的产品数量）；人均销售额（价值流循环一周，平均到每个雇员的销售量/额；兼职或临时工可按工时换算为全职）；价值流利润（实际发生的产品收入减去同样按照价值流计算的材料成本、人工成本和其他成本后的余额）。
  6. **实施生产体系评价的八个步骤（图 15-2）**〔p.291 / PDF 304〕：①根据公司章程推进领导小组审核其是否符合战略方向；②对推进精益生产方式绩效项目进行评估；③决定精益生产方式绩效评价项目；④取得高层管理对绩效评价项目的支持承诺和合理投入；⑤计算原始测量数据，决定各个评价项目的起点；⑥选择每个评价项目的指标；⑦公布评价项目和指标并使其可视化；⑧继续测量评价项目和指标并公布结果。
  7. **闭环绩效管理"四步法"（图 15-3）**〔p.294 / PDF 307〕：①**绩效体系**（确定与公司战略目标相关的驱动因素；找出适合公司监控和管理业绩的关键业务指标 KPI）；②**设定目标**（为每个 KPI 设定业务目标；把目标落实到相应的负责人身上）；③**结果管理**（根据得到的业绩结果进行判评，以便下一步提高和推广；评定员工的表现，给予合适的奖励或者惩处）；④**监控**（监控业绩执行情况；根据监控所发现问题，进行业绩会议研讨，提出改善方案并组织实施）。绩效管理体系建设是一个动态的、不断完善的过程，任何一个优秀的绩效管理流程都应是一个闭环，实现绩效管理的螺旋式上升。
  8. **建立精益绩效管理体系的三个要点**〔p.293–294 / PDF 306–307〕：①将指标和目标分解的层级清晰地勾勒出来，使每个员工都能看到自己对部门及最终对公司业绩的贡献路径；分解层级要可视化展示、易于及时更新；②以绩效考核形式量化资源，在企业内部建立成本考评关系；通过自上而下、自下而上多次磨合，将核算单位指标分解细化到加工班组等岗位及个人；对每一份的成本耗用进行分析考评，控制不合理支出，杜绝报废、浪费；③将实际业绩的图表展示在生产一线，用作主管与员工每天沟通的媒介；当目标出现偏离时通过日常的绩效监督可以获得早期的响应时间；鼓励员工主动挖掘问题并倡导自主地、有创造性地提出解决方案。
  9. **追踪与考核机制**〔p.294–295 / PDF 307–308〕：改善活动的绩效需要追踪与考核，绩效可通过相应 KPI 呈现，例如：生产的前置时间缩短，质量合格率的提升，停线时间缩短，设备故障率下降，库存量减少，人员数的降低等。追踪形式（除活动者主动追踪外，TPS 推动部采用）：定期的改善活动发表会；定期的成果检讨会；TPS 推动部门相关人员到现场实际观察，确认改善的效果。高层主管也要定期走进现场实地了解，并对改善活动给予评价。必须建立相应的评估制度，如**周评估、月评估**，并将评估结果予以公示；同时采用一系列的薪酬及非薪酬激励手段进行结果管理。

- **常见错误/反例**：将精益运营与传统绩效评价混淆在一起→操作人员和监督人员无法同时实现两者的要求（接受精益培训时被要求关注节拍时间、满足客户需求，传统绩效评价指标却要求提高生产效率）〔p.287 / PDF 300〕；传统的单纯计件绩效考核制度→已无法支持精益生产的持续实施〔p.293 / PDF 306〕。

## 5. 打法（组合拳）：步骤⑪–⑬ 如何把改善固化——文化＋人＋绩效＋机制四件套

### 5.1 总路线：四件套缺一不可

推行步骤⑪–⑬ 的本质，是把前面步骤产生的改善成果**固化**下来：

- **文化（步骤⑪上）**：精益文化三层次落地——从领导者以身作则开始（十三要点之 1、2），通过常规文化活动固化：定期发行改善亮点海报，进行精益生产推动成果报告会，评选优秀推动工作者、优秀精益生产推动主管，推动有感征文，宣传标语，每日或每周改善新闻等〔p.268 / PDF 281〕。丰田精益文化的养成经过五十多年时间，通过几代人的传承，全员的认知〔p.268 / PDF 281〕——预示文化项不能速成，必须一开始就启动。
- **人（步骤⑪下）**：多能工三阶段轮换＋OJT/TWI＋5 能级职业生涯＋团队工作（3～8 人、职责下放、ANDON 响应）——让人有能力、有通道、有组织地承接改善。
- **绩效（步骤⑫）**：弃用传统财务评价，建精益单元（非财务）＋价值流（财务＋非财务）两层面指标；四步法闭环（绩效体系→设定目标→结果管理→监控）；周评估、月评估并公示。
- **机制（步骤⑬）**：十三要点定行为规范，QCC 七步定小组改善流程，合理化建议 8 步＋分层审查定个体提案通道——三条通道并行，覆盖"班组课题/个人提案/跨部门攻关"。

### 5.2 场景一：改善"推起来一阵风、过三个月就散"

工具组合顺序：十三要点（定领导行为）→ 改善六阶段（第 6 阶段效果确认）→ 标准化（要点 12 之"改善的第一步就在于标准化"）→ 追踪考核（KPI＋发表会＋周/月评估公示）。产出物：改善效果确认记录、新标准文件（工艺文件/作业标准）、月度评估公示表。
关键动作：按追踪与考核机制，TPS 推动部采用定期的改善活动发表会、定期的成果检讨会、到现场实际观察确认改善效果；高层主管定期走进现场实地了解并对改善活动给予评价〔p.294–295 / PDF 307–308〕。

### 5.3 场景二：员工只会一道工序，产量波动无人可调

工具组合顺序：培养对象选择原则（全岗位两人以上能独立操作）→ 三阶段岗位轮换（先管理干部示范，再组内轮换，最后每天数次）→ 多能工培训计划表（表 14-4 格式排目标与完成日期）→ 实施四要点（作业简单化/适当指导/标准作业/整体推广）→ 与 5 能级职业生涯联动（点数晋级）。产出物：多能工培训计划表、作业指导书/作业要领书/训练要领书、能级认定记录。
注意：在岗培训形式用"一周两天、为期两个月"培训骨干；脱岗培训只在非常必要时对重要骨干采用〔p.275 / PDF 288〕。

### 5.4 场景三：财务指标与精益改善"打架"，老板动摇

工具组合顺序：先讲清三大缺陷（存货减少→单位产品成本增加、毛利可能降低是精益改善的正常财务表现）→ 按八步骤建立评价项目并可视化 → 精益单元非财务指标考核（首次合格率、按时交货率、进料到出货时间）→ 价值流财务指标看趋势（存货价值变化作为反映精益改进的重要指标）→ 四步法闭环运转。产出物：评价项目与指标清单（可视化）、精益单元绩效报告、价值流绩效趋势图。
关键判断：各价值流的实际绩效指标不同，但所有价值流的绩效指标必须呈现**稳步上升的趋势**——"每项指标的实际价值远没有变革的速度和方向重要"〔p.288–289 / PDF 301–302〕。

### 5.5 场景四：提案箱没人投、QC 小组有名无实

工具组合顺序：受理范围与 5 项原则公示（明确什么收、什么不收）→ 8 步活动流程落到班组（现场管理者主导前 4 步）→ 丰田式分层审查（部门审小额、公司审大额，每月固定审查日）→ 及时奖励＋每月末表彰仪式＋年度集体表彰 → 未解决问题回流 QCC 选题。产出物：合理化建议提案记录册、审查结果一览表、表彰记录。
判据：提案件数按月统计并纳入绩效评价指标（表 15-2"提案管理"：员工提案件数、实施的防错个数、策划方案的个数）〔p.292 / PDF 305〕。

### 6.1 实例一：在国外各类企业实行精益生产的成功经验（表 17-1 汇总）

**出处**：〔p.319–321 / PDF 332–334〕（表 17-1 及续表，图像已核对）

**性质**：多家国外企业精益推行经验汇总表（企业类型分：工具类企业、汽车及零部件行业），无单一企业完整改善过程，按原表逐条照录。

**背景与经验（原表照录）**：
1. **某德国工具类企业**（工具类企业）：1921 年在德国法兰克福奠下基业，在德国、日本、美国和中国都设有自己的公司，全球员工超过 7500 人；产品包括 10 大类 200 多种小家电产品（电动剃须刀、电动口腔护理产品、脱毛器、食品加工器、熨斗、护发设备和计算器）。经验（2005～2006 年）：Braun 巴塞罗那熨斗和搅拌机生产；在巴塞罗那工厂实施精益生产；产品成本分析；马达生产线的 TPM 和 SMED；**组装线的重新设计，生产率提高 42%**。〔p.319 / PDF 332〕
2. **实耐宝**（工具类企业）：1920 年成立，产品线覆盖手动工具、电/气动工具、工具车、切割工具及汽车诊断维修设备及软件等，是世界最大专业工具及设备制造商之一。经验（2003～2004 年）：在三家手持工具工厂（Vitoria、Aranguiz and Irún-西班牙）实施精益生产；战略展开；价值流分析和提高（生产、仓库和间接部门）；持续改善领导人培训、持续改善项目的实施；闪电改善、5S、SMED、连续流、防呆法等。〔p.319 / PDF 332〕
3. **某德系车企**（汽车及零部件行业）：2004 年——持续改善部门的价值流图和精益工具的培训；在多家工厂实施精益工具来降低组装返工率、缩短交货期。〔p.320 / PDF 333〕
4. **道依茨 DEUTZ**：世界领先的独立燃气及柴油发动机生产商。2007 年——车削发动机组件；新产品生产的物流规划；工厂布局设计；物流战略；仓储方式；辅助性的看板管理（与主生产线同步）。〔p.320 / PDF 333〕
5. **某汽车零部件企业**：全球领先的汽车与汽车电子零部件及系统技术供应商。2003～2005 年——汽车零部件；计划模型定义；SMED 实施（从 600 吨到 1200 吨的注塑机）；**缩短约 60% 的换型时间；缩短 30% 交货期及减少在制品 30%**。〔p.320 / PDF 333〕
6. **IRIZAR**：西班牙最大的客车制造企业，年生产量欧洲排名第三。2007～2008 年——公交车生产；14 种新产品的工业化流程；生产布局；物料管理；超长零件管理；产品设计改善。〔p.320 / PDF 333〕
7. **GESTAMP**：西班牙著名汽车零配件制造企业，在全球 14 个国家设有多家工厂，拥有热成型技术，主要生产车身结构件和底盘部件及总成，是多家国际主流车企的全球供应商。2003～2004 年——汽车零部件；精益生产和 6σ 在冲压、焊接和成型车间的导入与实施（原 OCR 作"68"，图像核对为 6σ）；致力于降低成本的战略展开；精益领导人的培训（干中学的方法以及改善活动的管理）；闪电改善、5S、重新组织维护流程、降低焊接车间的物料消耗，在冲压和成型车间消除短停机时间（提供 OEE）等。〔p.320 / PDF 333〕
8. **MGIZCOUTIER**：集团总部位于法国罗纳-阿尔卑斯大区，为全球著名汽车零部件企业，仅欧洲就有 14 个生产厂，海外子公司遍布全球 17 个国家。1999 年——定义并执行最优化物流模式；新工厂的流水线设计；仓库设计。（续表）持续改善下两个工厂的质量和生产率的改善；实际的改善项目；建立衡量体系的学习班（采集数据、分析数据、最终报表和图形，即 TPM 中的 OEE）；设计管理面板的学习班（对效率质量和改善计划进行目视管理）；同一集团公司闪电改善：缩短包装线的准备时间，团队＝4 个作业员＋1 个辅助人员＋1 个主管（BB）＋1 个质量工程师＋2 个维修人员；SMED：时间分析、外部时间内部和时间划分、新方法设计、控制方法和物料准备标准；5S：整理、整顿、清扫、清洁、素养等。〔p.320–321 / PDF 333–334〕

**可迁移启示**：跨行业推行精益的切入点按行业不同——家电聚焦组装线重设计，工具业聚焦战略展开＋价值流全覆盖，汽车零部件聚焦 SMED 与库存/交期双降；"培训＋闪电改善＋领导人育成"是共同动作。

### 6.2 实例二：天津某电气企业定制产品的拉动式生产系统（本章篇幅最大案例）

**出处**：〔p.321–339 / PDF 334–352〕

**背景**：该企业为全球 500 强集团在华合资公司（2008 年 8 月 22 日成立，是集团在中国建立的第 26 家公司），为配电行业提供中压产品，产品为 12～40.5kV 中压开关柜。公司有 3Uni 柜〔OCR 存疑：疑为某柜型名，原文如此〕、12kV、40.5kV **三大类开关柜产品，9 个产品族**；厂内有 **4 条不同的主装配线、一条低压箱预装配线和两条钣金与铜排的机加工生产线**。开关柜属定制式生产，几乎客户每笔订单都不相同，每笔订单都需重新电气与机械结构设计、绘制工艺图纸、与设计院和客户方确认、维护供应商价格信息、采购原材料、机加工和装配。订单多样少量。2010 年电力市场刚复苏，全国几千家电力企业激烈竞争，质量、价格和交期每一个因素都在竞标中占相当比重。

**问题（改善前量化现状）**：
- 交付周期：一次开关柜从设计到装配完发货，改善前大致 **7～9 周**；环网柜 UniSwitch 交付周期 **3 周甚至一个月**；客户期望的环网柜交货期从 **14 天甚至 1 天**不等；**同行业最大竞争对手交付期为 2 周**。〔p.323 / PDF 336〕
- 现场：典型批量作业，线上有一长列十几台柜子，先装配所有柜壳、统一装顶部单元再进行下面作业；轨道四周摆满物料；生产线对面 **300 多平方米**物料集结区，钣金生产线东侧还有 **300 多平方米**自制物料区；物料隶属哪个订单不得而知，只有生产物料员和领班凭经验能找到；仓库物料员按订单 BOM 放料、无摆放顺序，生产线没有工位。〔p.325 / PDF 338〕
- 一个 10 台左右的小订单正常情况下要 **3～4 天**才可完成。〔p.325 / PDF 338〕
- 异常：除最简单的 C 柜和 F 柜以外，**生产线上每天的异常平均都在 3 个小时以上**；异常出现时领班"救火"，相关管理者反应慢。〔p.325 / PDF 338〕
- Uni 产品有近 1000 种物料（标准化章节作 **1001 种构成物料**），供应商交货期从 1 周到 1 个月不等——原材料供应无法满足客户 1～2 周甚至 1 天的交货期。〔p.324、p.331–332 / PDF 337、344–345〕

**做法（分点）**：
1. **变革团队与目标（2010 年 8 月底组建）**：无专职改善人员，总经理希望生产运营经理领导变革（其曾任职某欧洲公司中国区变革经理，有 10 多年精益实施经验），邀请质量经理共同担任变革领航员（质量经理有丰富计划与采购经验——物料计划与采购正是公司薄弱环节）；各部门抽出一名有改善意愿且有培养前途的工程师加入团队；现场项目组有生产线领班和作业员参与，副总经理也加入。
2. **现场目标**：选 Uni 环网柜为改善对象（投产半年后市场需求大幅增长）。公司制订目标：**效率提升 60%、半年内产能增长 100%、生产周期从 4 天降低到 1 天**。
3. **流程目标**：通过严格流程控制和快速异常解决，**将一次开关柜的交付周期降低到 6 周，环网柜交期降低到 2 周以下**。

### 6.3 实例三：某公司开展精细化管理

**出处**：〔p.339–346 / PDF 352–359〕

**背景**：某大型中外合资汽车制造企业（2003 年成立）〔OCR 存疑：品牌名"阿库德/公民/城市"疑为音译，原文如此〕。公司成立之初就确立全面推进精细化管理的宗旨，推进集中于五个方面：现场可视化管理、JIT 精益生产、TPM 全员设备管理、自动化质量防错、动作改善与作业标准化。

**问题**：本案例原书未给出改善前量化症状（语料未覆盖）；仅给出设备现状：冲压车间拥有多条全自动冲压生产线，采用全球领先的一体化伺服式冲压机；焊装车间二十条生产线中近一半为全自动生产线，共使用近 200 台自动化机械手，**自动化程度高达 60%**。〔p.343 / PDF 356〕

**做法（分点，按原书六节顺序）**：
1. **可视化助力现场全方位精细化管理**：管理内容标准化（不同层次管理内容设计成标准化表格，管理人员用不同颜色笔填写数值）→ 张贴管理看板 → 每月第一周、每周第一天及每天早上，现场主管及班组长拿小红印章逐个检查确认管辖范围改善活动进展；各级领导都有自己的现场管理看板，一些员工帽子上挂"全员参与"小标签；不同管理项目设不同看板（5S 看板、TPM 看板、标准精益改善看板、改善提案看板、小组活动看板、生产进度看板、质量分析看板）；生产看板含生产可动率曲线、停线时间、直行率曲线等；质量看板含不合格项目分类统计表、重点品质课题对策状况表、品质不良处置书等。
2. **拉动式生产与看板系统实现零库存**：拉动链条——市场拉动总装→总装拉动涂装→涂装拉动焊装→车身生产拉动零部件生产，各环节生产指令直接由后工序下达。厂内所有加工车间做到"在必要的时间，将必要数量的零部件，送往必要的加工地点"；所有车型接订单生产、同一流水线多车型轮流组装；拉动式"零部件成套供应模式"——每一个物料架紧随一辆等待装配的车身，物料架可移动，不多送不少送、不早送不晚送；总装工人在物料架和车身同步流动的平台上装配，连转身取物料的时间都省了。企业间：几十家主要零配件供应商围绕该公司建厂，实施"门对门"拉动式供应。看板：生产计划下达给最后的组装线，在指定时间生产指定数量的指定车型，组装线依次向前一道工序领取零部件。
3. **U 形单元式生产布局提升柔性**：生产线改造成 U 形单元式布局，迅速转换零部件种类；设备小型化、速度快、品质稳定、故障率低；多能工越来越多，一人多技能为培训重点，一人多机操作、一人多工序操作使人员配置弹性化。
4. **安灯等自动化防错法**：每工人身边一根拉线连安灯；不同问题配不同提示音乐（设备故障/品质问题/需要流动工）；异常不能在节拍时间内处理完，生产线自动停止（固定位置停止线）——不把不良品流到下工位，本工序内确保品质；车身电阻焊用电流监测技术（电流过大焊点击穿、不足虚焊，电流异常时控制器立即停止工作并报警）。
5. **作业优化**：①作业简化——把现场作业划分成生产加工与物料搬运两部分，搬运由专职"水蜘蛛"进行，岗位操作工只负责装配，不用寻找拿取物料；待组装汽车放在台车上，工人站在台车上作业（区别于传统流水线旁边步行边作业）。②作业标准化——严格训练督导（抓螺帽一下就是五个；检查漆面要求每秒看几米就必须看几米；门板检查要求分三次看完就必须三次看完）——"通过严格的训练和辅导，员工们都训练有素，精确度和机器人差不多"〔p.345 / PDF 358〕。③生产线装置改善——产线联结点使用吊装机械，充分利用立体空间且避免地面固定式机械故障中断生产。
6. **"创意提案"活动带动全员参与**：流程（图 17-26）——提案人发现问题→现状调查、确定真因→填写《创意提案书》→部门评审/审批部门批准→制定改善方案与实施计划（与提案人共同讨论实施方法）→实施→确认改善效果→评比、奖励；个人完不成可协作，本部门无法完成填写《改善委托书》交公司改善小组协助完成。推进要点——①全员参与，结合岗位特点提创意性改善性提案；②**奖励已实施完成的提案，仅建议未实施不予奖励**，要求尽量自己实施；③团队提案两种情形（提前组建"创意小组"讨论；个人提创意但无法完成实施时协商组建"改善小组"共同完成）。

**结果**：原书未给出本案例量化改善前后对比数据（语料未覆盖）；仅可考的过程性陈述：通过管理看板能看到车间设备故障率不断降低、生产成本不断降低、劳动生产率不断提高；追求"零库存"管理目标——如果厂区内交通干道堵塞半个小时，工厂生产线就要面临零配件供给不继而停产（侧面反映库存水平之低）。〔p.339、341 / PDF 352、354〕

**可迁移启示**：本案例是"体系型"案例——可视化（管理标准化表格＋分层看板＋印章巡查）是把精细化固化下来的载体；拉动从厂内延伸到"门对门"供应链是零库存的组织保障；提案制度"奖励已实施"是与丰田"提案权＋实施责任"不同的口径设计。

### 6.4 实例四：自行车产业联盟成功推动 TPS，协同合作创造双赢成果

**出处**：〔p.346–349 / PDF 359–362〕

**背景**：中国台湾自行车业年产量由每年约 1000 万辆下跌到每年仅 388 万辆，**降幅超过 60%**；主要生产企业多为中小型工厂；有优秀的研发人才、制造实力强，只是缺乏整合及生产系统的优化。由巨大、美利达等企业决心联手推动 TPS，中卫发展中心主导、某汽车厂提供技术支援，与 A-Team TPS 推动小组组成 TPS 辅导团队；A-Team 厂商希望建立及时化、少量多样、多频度物流搬运的生产架构，以生产高品质、高附加价值自行车；**2003 年起全面展开 TPS 推动**。

**问题（改善前量化现状）**：
- 原流水线作业：工位之间经常堆积、作业不平衡、人员效率低下；**工位间库存 2000 辆**。〔p.347 / PDF 360〕
- 原大批量生产：大量库存、管理不易、无法满足客户多样化需求。〔p.347 / PDF 360〕
- 制程间很多库存，生产前置时间（L/T）较长。〔p.348 / PDF 361〕
- 生产指示：按企划部指示生产，中间库存量大、停线次数多，各工序按自己的周期生产、习惯准备大量库存。〔p.348 / PDF 361〕
- 中心厂与供应商协作：零件厂制程 L/T 太长，中心厂需给零部件供应商 **3 个月的预测订单数量及 21 天的准确订单量，并于 6 天前下指示交货**；整车厂订单变动频率高，零件厂商多以库存应对。〔p.348 / PDF 361〕

**做法（分点）**：
1. **三年推进主线**：第一年＝现场协同管理和改善（降成本、提效率）；第二年＝TPS 推进到研发机制（研发更新颖、更高附加值自行车）；第三年＝积极推动市场营销、建立品牌形象。
2. **辅导活动模式**：每月定期到各厂实地指导（活动小组报告上回执行情况→顾问提出质疑→到现场实地掌握了解→回会议室意见交流、指示待执行事项），强调现场指导及工厂种子人才育成；辅导以半年为一期，期末成果发表会，会后中卫中心召集巨大、美利达及 TPS 推动小组检讨并提出后续措施；配套 TPS 教育训练课程、到绩优的零部件供应商工厂实地观摩、经营高层赴日本参观丰田及零部件供应商。
3. **削减库存和在制品**：推动一个流生产方式。
4. **生产批量**：建立少人化生产方式及推动一人完结工程，改为小型单元生产线，按照需求的种类和数量生产；多机种混合生产的发泡制程（人的速度跟不上机器、现场特别忙乱）改成几条小型生产线。
5. **制程间连接**：设置安灯（ANDON）及实行定量不定时的物流配送系统。
6. **生产指示**：推动后补充生产架构，按客户实际需求生产；供料采用定时定量、成套物料搬运；后工序按先进先出顺序加工；用安灯对异常快速反应以减少停线损失。
7. **中心厂与零部件供应商间**：建构 **1—1—10 的交货机制**——每天下单、每天交一次货，今天下的单即为 10 天后需要交的零件；经双方确实遵守执行。

**结果（全部数字原样照录，原书未给出百分比者只列前后值）**：
- 一个流：**作业面积减少 40%，生产效率提升 15%，消除了工位间 2000 辆的库存**。〔p.347 / PDF 360〕

### 6.5 实例五：基于精益生产的汽车门分装线改善

**出处**：〔p.349–354 / PDF 362–367〕

**背景**：某车型四门装配相对较复杂、不方便在车身上直接装配，故在总装车间开辟单独门分装线。**共 7 个工位（01–07）**，左、右两个门线升降机用于物流人员送料；以四门为一个传输单元，载体是车门抱架。整个门分装线单独开辟在车间内一个**距地面约 2.5m 的长方形空间内，面积约 154m²**。〔p.349 / PDF 362〕

**问题（改善前量化现状）**：
1. **零件数量多**：标准件共 **50 种**（其中 48 种左右门线共用），先以一定数量存放在小塑料盒里，小料盒再分 **11 个小批量**由物流人员运送到线边对应固定货架管理；线边有 **91 种非标准件，占所有物料的 64.5%**。小规模集中管理的缺点：①使用频率低，平均 1 次/每天（推算：一盒 500 个标准件 B、A 工位每门需 5 个→一盒装 100 个门；节拍 3 分钟/门、每班实际 400 分钟→每班约 135 个门→每个操作员工每天只需取小料盒一次）；②标准件占用大量线边面积——**平均每个固定货架占地 2105m²，11 个固定货架占面积 2215m²**〔OCR 存疑：原书即印作此数，疑漏小数点，参照后文"平均每个货架占地约 2m²"，不擅改〕；③物料操控困难——物流人员需对 11 个分散点管理，面临输送批量与线边库存数量的矛盾。〔p.349–351 / PDF 362–364〕
2. **操作者无效走动多**：每个工位操作者装配时需在工位和线边零件库存货架之间反复走动取件。〔p.351 / PDF 364〕
3. **用地面积受限**：有固定货架 26（25）个、移动货架 26（25）个，平均每个货架占地约 2m²，**货架总占地面积 104m²，占整个门分装线面积的 67.5%**。〔p.351 / PDF 364〕

**做法（分点，精益思想指导下两大项）**：
1. **标准件超市**：（1）扩大集中管理规模——将 11 个分散点的小规模集中管理调整为 **2 个点**的大规模集中管理，50 种标准件按工位分两批，**将原来 5 盒的库存量降低为 2 盒**；（2）集中点位置——尽量使取件距离最低，门分装线首右侧设集中点 1（放 1～4 工位标准件），线尾左侧设集中点 2（放 5～7 工位标准件）；（3）新货架——只制作两个新货架，共四层，每层放 7 种标准件、每种两盒，正面投料、最下层回收空料盒；（4）目视化——每个标准件盒打标签，注明标准件种类和外观图。
2. **非标准件打包形成同步单件流动**：91 种零件中有 **84 种（占 93%）是单件配比**（装配一个门只需相应一个零件），可在进入生产线前集中排序、放置在特定容器内打包，随门在线上单件流动，各工位按需取件。三步（打包→排序→单件流动）：（1）确定打包零件清单——体积小且不易碰伤擦伤的零件被打包，对 91 种零件一一分析；（2）确定排序方式——打包载体为特定结构无盖箱体（可用零件废弃包装箱自制，几乎无额外改善成本），摆放原则"**工位靠前的零件在上，工位靠后的零件在下**"，左右工位零件分开打包，一个车门抱具对应两个打包箱；（3）单件流动——每个打包箱靠近抱具一侧装两个挂钩，工位 01 操作员挂上打包箱随车门移动，第 07 工位取下空箱，经右边升降机回收。
   - 关键判断："如果将零件集中起来但是没有顺序，操作人员可能需要花费很多时间来寻找本工位装配需要的零件，其结果可能比改善前更差。"〔p.352 / PDF 365〕

**结果（全部数字原样照录）**：
1. 零件的线边库存数量大大降低，**由原来的 14712 件降低到 4673 件**。〔p.353 / PDF 366〕
2. 操作者无效走动降低：改善前操作需要**往返 13 次**才能完成，改善后**只需移动 6 次**完成相同工作。〔p.353 / PDF 366〕
3. 节约用地面积：线边固定货架由 26（25）个降低到 **3 个**，移动货架由 26（25）个降低到 **22 个**，托盘由 16 个减少到 **10 个**；每个货架占地约 2m²，**面积上大约节约了 50m²**。〔p.353 / PDF 366〕
4. 成本降低：平均每个货架（移动或固定）成本 **1700 元/m²**，生产用地 **1500 元/m²**〔原书单位如此〕；货架减少 25 个，节约成本 **42500 元**；生产用地减少 50m²，节约 **75000 元**；**合计 117500 元**；另在物料操控方便、装配流畅、生产库存降低等方面带来成本的大幅度降低。〔p.353 / PDF 366〕

**可迁移启示**：原书明示思路——改善对象是"人和线边零件之间的关系"（受定置管理启发），瓶颈是"批量的规模和实际情况不能很好结合"，故对策是调整集中管理的程度（超市化）＋按单件配比打包同步流动，且载体用废弃包装箱自制、"并不需要很大的额外改善成本"。
**OCR 风险标注**："2105m²/2215m²"两处已回读图像 p0364 核对，原书确实如此印刷（疑排版漏小数点），照录并标注；改善结果数字（14712/4673、13/6、1700/1500、42500/75000/117500）与图像一致。
