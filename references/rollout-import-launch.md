## 2. 概念地基

### 2.1 精益生产由来三阶段与两次革命

| 生产方式 | 要点 | 出处 |
|---|---|---|
| ① 单件小批生产方式 | 直接来自客户需求、灵活应变、小作坊管理简单，但产量极低、效率低下 | 〔p.3 / PDF 016〕 |
| ② 大批量生产方式 | 某美系车企规定每个零件统一计量标准获完全互换性，一名装配工平均工作周期由 **514 分钟**下降到 **2.8 分钟**；1913 年某美系车企在底特律建成世界第一条流水线；二战后某美系车企总裁以 5 个车型系列+事业部制融合规模经济与范围经济 | 〔p.4 / PDF 017〕 |
| ③ 精益生产方式 | 20 世纪 50 年代丰田在"日本制造业生产效率只为美国的 **1/8～1/9**"、无力全面引进美国成套设备的约束下创立；**1983** 年 MIT 的 IMVP 计划开始"精益组装线"研究（狭义精益），**2001** 年进入价值流管理（广义精益）；**"精益生产"管理传入中国为 1994 年** | 〔p.5–8、p.7–8 / PDF 018–021、020–021〕 |

- 两次革命：单件→大批量 = **工业界第一次革命**；大批量→精益 = **工业界第二次革命**。〔p.3 / PDF 016〕
- TPS 时间线：1962 年正式命名 Toyota Production System（TPS），1974 年丰田对外正式公布。〔p.7 / PDF 020〕
- 狭义精益 = 以 TPS 奠基者为代表的丰田准时生产制（美国学者称）；广义精益 = 以某直销电脑企业与某零售连锁企业为代表的美国公司精益生产。〔p.8 / PDF 021〕
- 精益生产定义判据："精"＝精良、精确、精美（少而精，只在适当时间生产必要数量的市场急需产品）；"益"＝利益、效率；**精益生产就是及时制造，消灭故障，消除一切浪费，向零缺陷、零库存进军**。〔p.9 / PDF 022〕

### 2.2 经营思想三分法（导入期说服高层的判据）

| 经营思想 | 公式 | 判读 |
|---|---|---|
| 成本主义 | 销售价格=成本+利润 | 成本意识弱，消极适应市场，终会被市场拖垮 |
| 售价主义 | 利润=销售价格-成本 | 成本意识一般，卖方市场十分有限 |
| **利润主义（精益采用）** | 成本=售价-利润 | 成本意识强，必须从企业内部将人工、设备使用等管理成本作为改善对象，彻底消除浪费 |

〔p.11 / PDF 024〕

### 2.3 四大类 14 项管理原则（丰田模式，宣贯教材与高层自查框架）

杰弗里·莱克总结（表 1-3），可作为导入期"建立精益理念"的宣贯教材与高层自查框架。〔p.13–14 / PDF 026–027〕

| 类别 | 原则（逐项） |
|---|---|
| **第一类：长期理念** | 原则1：管理决策以长期理念为基础，即使因此牺牲短期财务目标也在所不惜。 |
| **第二类：正确的流程方能产生优异成果** | 原则2：建立无间断的操作流程以使问题浮现。原则3：实施拉动式生产制度以避免生产过剩。原则4：使生产均衡化。原则5：建立立即暂停以解决问题、从一开始就重视质量管理的文化。原则6：工作的标准化是持续改善与授权员工的基础。原则7：运用视觉管理使问题无处隐藏。原则8：使用可靠的、已经过充分测试的技术以协助员工及生产流程。 |
| **第三类：发展员工与事业伙伴，为组织创造价值** | 原则9：把彻底了解且拥护公司理念的员工培养成为领导者，使他们能教导、影响其他员工。原则10：培养与发展信奉公司理念的杰出人才与团队。原则11：重视事业伙伴与供货商网络，激励并助其改善。 |
| **第四类：持续解决根本问题是企业不断学习的驱动力** | 原则12：亲临现场查看以彻底了解现场情况。原则13：不急于决策，以共识为基础，彻底考虑所有可能的选择，并快速执行决策。原则14：通过不断反省与持续改善以变成学习型组织。 |

配套宣贯素材（同区间）：
- **传统管理思想 vs 精益理念 7 方面对照**（表 3-3）：①客户价值（生产者决定→以客户价值为中心持续消除浪费）②生产系统（推动式→拉动式，计划只下达到最后工序，靠看板实现指令）③组织结构（金字塔集权→按流程重构的扁平团队，赋予岗位业务决策权）④生产方式（少品种大批量在制品堆积→多品种一个流、工序间在制品接近于零）⑤人员管理（制度考核奖罚训斥→人性化管理、多能工、提案制度、自主管理、少人化）⑥企业目标（被动完成废品率库存量指标→不断追求"零缺陷""零库存""零事故""零故障"）⑦企业文化（按产量计件、个人主义泛滥→团队精神、激励机制、人因工程改善工作环境）。〔p.33 / PDF 046〕
- **管理者 5 方面精益变革自训清单**（表 3-2）：①经营战略与经营管理并举；②现场员工的引导和激励（基层团队自主管理）；③充分授权（给最基层的团队权力）；④尊重和服务现场（价值流＝从原材料到成品再到回款的增值活动连接；支持部门应给直接增值部门服务）；⑤开放的问题意识（员工按新管理流程有序运行并创造性持续改善+激励机制变革＝精益变革的动力源泉）。〔p.32 / PDF 045〕
- **精益思想五大原则**：价值→价值流→流动→需求拉动→完美（尽善尽美）；目标＝以最小的资源投入创造出尽可能多的价值。〔p.12–13 / PDF 025–026〕

### 2.4 精益生产系统结构（向高层讲"精益全景"的一页纸框架）

- **两大支柱**：① JIT 拉动式生产体系（看板管理）→支撑"降低成本"（人力支出最少、物流浪费最小、少人化）；② 自働化体系→支撑"增加销售收入"（品质保证、提高技术应变能力保证交货期）。自働化体系下挂：自働化/防错法、全面质量管理、并行工程、团队工作；JIT 体系下挂均衡生产，均衡生产下挂：流线化生产、小批量生产、标准作业、快速切换、全面生产维护（TPM）、多能工。左侧竖轴＝经济性（"不断暴露问题，不断改善"）；右侧竖轴＝适应性（"尊重人才，发挥人的作用"）。顶部＝全公司整体利润增加；底部两层基础＝价值流管理、全员参加的改善和合理化活动（IE）→企业教育、开发人力资源、6S、目视管理。〔p.24–25 / PDF 037–038〕
- **系统目标体系**：总体目标＝增加全公司整体性利润；基本目标 2 个＝降低公司整体成本、快速应对市场；子目标 5 个＝①"七零"管理②尊重人性③准时生产④高柔性生产机制⑤模块化与并行设计法。子目标不能实现则总体目标无法实现。〔p.21、p.24 / PDF 034、037〕
- **"七零"目标**：零库存、零切换、零浪费、零不良、零故障、零停滞、零事故。〔p.22 / PDF 035〕
- **系统结构 13 项要素清单**：6S活动、目视管理、价值流、IE持续改善、快速切换、团队工作、全面生产维护（TPM）、自働化、品质保证（全面质量管理+QC小组活动）、并行工程、流线化（单元生产）、均衡化生产、拉动式的准时化生产（Push Pull-JIT）。〔p.25–28 / PDF 038–041〕
- **常用改善工具三类**（图 2-4，选型底稿）：①基础工具＝6S管理、目视管理、标准作业（SOP）、工业工程（IE）、价值流图（VSM）、全面生产维护（TPM）；②生产准时化工具＝准时化生产（JIT）、快速切换（SMED）、看板管理（Kanban）、节拍时间（Tack-time，原书印法）、一个流生产、均衡化生产；③自働化工具＝防错（PokaYoke）、全面质量管理（TQM）、持续改善（KaiZerl，原书印法）、按灯法。〔p.28 / PDF 041〕〔OCR 存疑：Tack-time/KaiZerl 按原图照录，通行拼法为 Takt-time/Kaizen〕
- **六大特点**：①一切为用户着想，用户纳入产品开发过程；②实施一个流，采用准时生产方式和看板管理；③以"人"为中心，部分权力下放；④以"精简"为手段，组织机构精简化、团队工作组、并行设计；⑤准时供货、最小库存、与供货商利益共享；⑥追求精益求精，零废品、零库存、品种多样化。〔p.9–10 / PDF 022–023〕
- **生产现场七大浪费对策表**（表 2-1，按精益目标组织，试点切入时的对策库）：

| 精益目标 | 现状要点 | 节约措施要点 | 技巧与工具 |
|---|---|---|---|
| 零浪费 | 节俭意识淡薄；产能不均衡；批量太大；动作浪费 | 制度培养节俭意识；整体能力协调；考虑动作经济原则 | 拉动式生产彻底暴露问题；价值流图及分析 |
| 零库存 | 过多原材料/在制品/产成品；线外多余仓库 | 库存管理信息系统；均衡化生产；提高物料及时供应能力 | 快速换模；小批量生产；生产计划标准化 |
| 零切换 | 换线换模时间长；上道延误下道等待 | 快速换模、小批量生产；协调上下工序 | 经济批量；一个流；标准化作业 |
| 零不良 | 人为失误；设备不稳定；未按标准作业 | 提高操作技能；改善制程能力；标准化管理 | "零缺陷"运动；自働化；全员质量改善 |
| 零事故 | 安全意识淡薄；忙于赶货忽视安全 | 执行安全规章制度；每周固定一天为安全活动日 | 安全教育；6S活动；危险预知训练 |
| 零故障 | 缺料停机；设备意外故障；加班与待料一样多 | 库存管理信息系统；总体计划分解为岗位作业计划 | 效率管理；TPM；初期清扫与自主维护；防错法 |
| 零停滞 | 交货期长、延迟交货多；顾客投诉多 | 总体计划分解到责任岗位；诊断作业生产线减少不必要工序 | 一个流、均衡化生产；布局改善；设备小型化、专用化 |

〔p.22–23 / PDF 035–036〕

### 2.5 导入四节（第三章整体框架，导入期的四个环节）

**导入总流程**：市场压力→危机感（传递全员）→建立精益理念（管理者 5 方面自训+理念宣贯）→参观学习（先国内后日本）→高层决策（纳入战略规划）。责任人：企业高层管理者为主角，企业管理部门为推动者。〔p.29–36 / PDF 042–049〕

| 环节 | 目的 | 核心动作 | 关键判据 | 出处 |
|---|---|---|---|---|
| **导入之一：在市场压力下增强危机感** | 在企业内部营造危机氛围并传递给所有员工 | ①用表 3-1 问题清单盘点企业自身（6 类 33 条，见 §6 工具用法）；②把压力传递给高层、中层、基层管理人员及一线员工；③特别强调最高管理层的危机意识 | "企业管理层的危机意识和紧迫感是实施精益生产方式的前提，而及时暴露被掩盖的问题或危机则是精益生产方式的基本原则" | 〔p.29–31 / PDF 042–044〕 |
| **导入之二：建立精益理念** | 消除对精益生产认识上的误区 | 管理者（特别是高层）按表 3-2 五方面训练自己的行为习惯；用表 3-3 七方面对照宣贯理念精髓；高层对员工行为设定期望、和员工对话了解其对变革的感受 | "理念的变革要比生产现场的改善难上好几十倍" | 〔p.31–33 / PDF 044–046〕 |
| **导入之三：参观学习** | 借鉴国内外先行企业，向管理要效益 | 两级路线：第一步到国内本土先行企业（两家国内汽车集团等）参观；第二步待实施到一定水平再去日本丰田等标杆企业参观 | 找出差距、理清改善思路，在人员管理和生产现场管理方面进行有成效的改进 | 〔p.34 / PDF 047〕 |
| **导入之四：高层决策** | 使精益转型成为决策者的意志、企业的统一目标和行动 | ①将实施精益纳入企业战略规划；②企业管理部门利用各种机会向高层建议；③组织中高层参观精益实施成功工厂；④让其他部门管理人员向高层汇报所见所闻；⑤推荐高层参加现场管理专家讲座 | "企业高层领导对精益的理解、决心和承诺，决定着精益生产模式实施的成败" | 〔p.35–36 / PDF 048–049〕 |

- 危机感建立技巧（原文列举）：①在公开场合向员工灌输危机意识；②采取象征性行动传递危机信息；③用电视新闻演示破产后的情景；④不断使员工建立危机感，从而产生全面参与改善的热情。〔p.30–31 / PDF 043–044〕
- 三阶段六类危机（图 3-1，危机叙事素材库）：刚建立与起步阶段＝竞争领导权的危机+拥有自主权的危机；发展到一定规模阶段＝官僚作风和团队老化的危机+与竞争对手抢占市场的危机；走向成熟阶段＝金融危机冲击+自然灾害及其他危机。〔p.31 / PDF 044〕
- 常见阻力：企业领导者对问题"不闻不问"；员工以抗拒变化的心态对待变革；员工甚至管理人员对企业存在的问题熟视无睹；认为精益只是生产技术、是生产部门的工作与其他部门无关；有的企业实施了精益但效果并不理想。〔p.31–32 / PDF 044–045〕

## 3. 方法工具六格（推行步骤①②③，每步一张六格卡）

### 3.1 推行步骤① 全面诊断、项目规划、确定目标（+组建精益团队）

- **目的**：导入决策作出后、导入之前，激发改善驱动力、寻找改善切入点和重点改善项目、建立可量化的精益生产衡量指标。〔p.039 / PDF 052〕
- **输入**：①企业当前经营数据与现场状况；②客户需求；③诊断团队（必须让中高层管理人员参与，特别是负责生产、研发、供应、财务的中高层，以激发其变革热情并避免后续规划执行脱节）。〔p.039–040 / PDF 052–053〕
- **动作**：
  1. **选诊断方式**（表 4-1 三选一）：①咨询机构专家组方式——诊断结果更专业，但若中高层没参与会导致规划和执行脱节且费用很高；②精益专家与中高层共同诊断——更客观、费用较少，是当下许多公司普遍采用的有效方式；③企业中高层自己诊断——费用低、效果一般、有局限性，问题确定不深入。〔p.039–040 / PDF 052–053〕
  2. **价值流图分析诊断**：以最终客户的观点定义价值，从客户需求出发绘制核心业务过程和管理流程的价值流，发现阻碍物流和信息流的问题点，找产生七大浪费的根源，分析归类再加以量化。〔p.040 / PDF 053〕
  3. **按表 4-2 七大诊断项目逐项检查**（诊断项目→诊断内容→诊断指标）：
     | 诊断项目 | 诊断内容 | 诊断指标（问题点） |
     |---|---|---|
     | 公司战略及组织结构 | 明确发展战略及经营目标 | 是否有 3～5 年公司发展战略；经营结果是否评价 |
     | 公司战略及组织结构 | 组织结构实施扁平化 | 是否为二级生产厂及职能机构 |

     | 生产制造过程管理 | 交货期 | 准时交货率、生产前置期 |
     | 生产制造过程管理 | 安全无事故 | 年事故记录、保险费用、损失小时数 |

     | 生产制造过程管理 | 物料库存 | 断料、囤料〔OCR 存疑：原 OCR 作"国料"〕、库存量情况 |

  4. **编写诊断报告并发布**：经过几个月诊断后编写诊断报告（诊断过程、问题与差距、建议改进方案）给高层管理者；召开班组长以上骨干参加的诊断结果发布会，统一思想认识。〔p.041 / PDF 054〕
  5. **召开专题研讨会**（图 4-1）：会前准备 4 项＝①诊断报告中的公司改进目标和方案；②分解制定各部门、车间级改进目标、项目和指标；③绘制现有流程价值流现状图；④参会人员精益知识培训。研讨会程序 7 步＝①识别顾客需求及支持或创造价值的流程；②遵循现场现物现实原则分析现状流程图细节；③头脑风暴提出改进愿景；④绘制价值流未来图；⑤执行未来愿景的计划（完成日期、负责人、流程评估指标）；⑥评估测量绩效，每周更新"精益状况布告栏"；⑦会后继续持续改进。会后管理层每月检查布告栏，公布和表扬执行团队成果。〔p.041–042 / PDF 054–055〕
  6. **项目规划三步**（表 4-3）：步骤 1 总体规划——以客户价值为出发点，先与股东、员工、重要客户、供应商沟通建立精益愿景，再由高层领导进行广泛精益教育培训；步骤 2 具体规划实施——以点带面、分阶段实施，每一阶段从试点区域开始：**从推行 6S 管理开始，建立全面生产维护 TPM，然后实施准时化生产 JIT，开展合理化建议及课题改善活动，建立精益质量保证体系，最后进行阶段性评价，确定效果后推广**；步骤 3 建立项目管理机制——专家对项目可行性初审→项目组编制标准化操作手册并落实→专家对各单位调研评估、验收评审、推广经验。〔p.043 / PDF 056〕
  7. **确定目标**：按 SMART 原则（S—具体明确的：工作职责、工作量、达成日期、责任人、资源需求；M—可量化；A—可接受；R—可达成；T—完成时间限制）；总目标逐级分解，下一级目标与上一级一致；三级目标口径——公司级 KPI＝质量的高可靠性、缩短交货周期、准时交货率、成本（周转天数）、柔韧性与灵活性；车间级＝目视管理迅速发现处理异常、按产量变动高效调整人员配置、标准作业、全部工序形成没有浪费的流动、建立工序内质量不良/部件材料不良/设备故障/短暂停顿/小故障的对策和预防对策；员工级＝按 6S 规定做好工位及周边物料放置、日常 6S 到位、执行标准作业消除动作浪费、一专多能化、改善合理化建议多、改善提案和团队小组活动。〔p.044–045 / PDF 057–058〕
  8. **组建精益团队**（图 4-3 六环节）：制定精益团队职责（全面规划项目、制定/审核/发布/执行/检查/处理精益标准、组织现场持续改进）→确定成员条件（①充分认识和理解精益生产的意义和价值；②积极参与努力学习的心态；③相当的实际工作能力及指挥协调能力）→选聘负责人（具备良好指挥协调能力的中高层管理者）→招聘成员（来自一线、积极支持参与项目且具备相关知识）→安排工作任务→实行报告机制（向主要负责人报告进展及成效）。组建原则：跨部门经理和工程师共同组成的项目团队，开始时也可由外部咨询顾问和自己的员工共同组成；**人才机制＝抽调加轮训**——从各部门抽调有实际经验的员工在精益部门轮训，顾问指导下系统培训，轮训结束回原岗位，循环往复，既保证团队有现场经验又为各部门输送精益人才。〔p.045–046 / PDF 058–059〕
- **输出**：诊断报告、改进目标与方案、价值流现状图/未来图、"精益状况布告栏"、公司/部门/车间三级目标体系、组建完毕的精益团队。
- **量化口径**：诊断指标清单见上表 4-2（指标名原样保留；**公式与好线/坏线基准语料未覆盖**）；部门定量数字化目标示例＝改善和解决问题的件数、人均合理化建议件数〔p.044 / PDF 057〕；图 4-2 推行目标框架 9 项＝均衡化生产、拉动式生产、自働化生产、一个流生产、实现少人化、准时化供应、建立质保体系、合理化建议、培养多能工（书题为"10 项目标"，OCR 抽出 9 项，第 10 项是否为图面文字无法断定，语料未覆盖）〔p.044 / PDF 057〕。
- **常见失败**：选专家组诊断但中高层不参与→规划和执行脱节且费用高；自己诊断→问题确定不深入，给以后规划和执行带来更多麻烦；诊断报告不用事实和数据说话；目标只定公司级不分解；团队简单从各车间部门抽人（不做轮训）→缺乏系统精益知识。

### 3.2 推行步骤② 高层领导重视和支持、宣传培训

- **目的**：让精益改革获得最高领导力的支持并始终如一；通过宣传培训让全体员工真正认识精益生产的重要性。〔p.047–049 / PDF 060–062〕
- **输入**：步骤①的诊断报告与目标体系；公司最高领导的时间与注意力；宣传培训预算与渠道。
- **动作**：
  1. **高层 4 项动作**：①**对精益改革作出承诺**——把信息明确传达给组织内部每个员工，明确改善目标（"老板亲自主导和老板授权某人来主导的意义是完全不同的"）；②**推进管理变革**——最高领导带头并培训中层领导自上而下灌输精益思想，亲自组建精益团队，引进具有精益实践经验的中高级管理人员，**对不坚决和执行不力的管理人员必须坚决撤换**，评估和清理过去已推行的管理制度/系统软件/奖励政策（与精益原则矛盾的坚决去除，可兼容的改造，局部精益活动上升到企业范围基本构架）；③**亲自参与改善**——经常到现场，亲自参与改善，当好教练，在改善中培养团队；④**高度关注和肯定**——积极参与样板车间参观活动，在各种场合表达对改善成果的赞许。〔p.047–048 / PDF 060–061〕
  2. **广泛宣传**：各级管理人员团结一致（总经理、经理、车间主任、班组长密切配合）；通过标语口号、条幅、看板、内部报刊、广播电视媒体、网站、精益管理活动等渠道宣传基本知识、实施内容、领导讲话、员工体会、改善成果。按表 5-1 五类方法执行：①征集编写精益制造的标语口号（8 条示例：精益生产是打造世界一流企业的必由之路／全员参与，精益求精，持续改进／追求"七个零"，实现利润最大化／高效生产、提升品质、降低成本／强化管理，消除浪费，点滴开始／诚心待人，增强信心、忠于职业／融洽气氛，规范工作，迈向完美／追求卓越，尽善尽美）；②制作条幅和宣传看板（横幅挂外围栏/大门/大堂，宣传画镜框装裱挂显眼位置，精益宣传板报）；③组织较重大的精益管理活动（成果发布会、誓师大会〔OCR 存疑：原 OCR 作"暂师"〕、精益生产知识竞赛）；④利用内部报刊（各部门或分厂轮流主办精益专题报刊，印制员工工作手册、故事与案例集、书籍）；⑤利用广播电视媒体与网站（精益动漫片、精益宣传网站、电子资料库、播放成功经验）。〔p.048–049 / PDF 061–062〕
  3. **培训教育（分层）**（图 5-1）：**管理人员及骨干**＝①聘请外部讲师；②公司高层领导全程参加；③组织理论和实际操作考试；④优良部门和个人给予奖励；⑤合格后才能上岗。**员工**＝①全体员工参加课堂式培训；②每位员工都需参加至少一个改善项目；③通过会议与员工沟通；④互联网或内部网络阅读、内部杂志、电视录像等方式展示。〔p.050 / PDF 063〕
  4. **按阶段选培训内容**（表 5-2 四类项目）：①员工精益手册培训（经营环境的变化；推进精益生产的必要性；如何在企业内推进变革；推进精益生产目标、计划；实施精益生产规定）；②精益生产的思想和基本知识（丰田生产方式产生及管理理念；精益生产思想及其发展；精益生产在国内外运用成效；精益生产系统结构；精益企业的运营管理系统）；③系统改善和现场改善的方法（一个流生产；快速转换（SMED）；标准作业；看板管理；防错防呆法；QC 方法；全面生产维护（TPM）；在岗培训（OJT）；E 方法〔OCR 存疑：疑为方法名缩写残缺，语义不明〕）；④评价改善效果（绩效评价体系及其指标；激励措施）。〔p.050–051 / PDF 063–064〕
  5. **骨干后续培训机制**：进入稳定期后定期对精益骨干进行理念深入培训锤炼，由精益推进室负责制订长期滚动培训计划并组织实施；培训内容以实践案例分析为主；可请知名咨询公司资深咨询师、成功实施精益生产企业的精益专家培训；建立长期的、动态的能力建设体系。〔p.050 / PDF 063〕
  6. **一线员工岗位技能培训**：培训分理论和实践两部分，加强核心技术和技能培养；根据行业特点进行一专多能培训——使员工得到更多职业发展机会、促进团队合作、帮助企业应对客户需求波动、增加发现问题的机会、促进持续改善。〔p.051 / PDF 064〕
- **输出**：高层的公开承诺与撤换/清理决定；全员可见的宣传阵地（标语/条幅/看板/报刊/网站）；通过考试上岗的管理骨干名单；分阶段培训计划与实施记录。
- **量化口径**：管理人员培训须**组织理论和实际操作考试、合格后才能上岗**；每位员工**至少参加一个改善项目**〔p.050 / PDF 063〕；高层参与的固定频次原书未给出（语料未覆盖）。
- **常见失败**：老板只授权不亲自主导；对不坚决和执行不力的管理人员放任；只宣传不培训、或只训骨干不训全员；培训不考试、考试不合格照常上岗；把培训当一次性活动（无滚动培训计划）。

### 3.3 推行步骤③ 推进组织、制度和试点切入

- **目的**：建立推动精益生产的组织与制度保证，以样板区试点切入，在车间第一线取得效果后再全面实施。〔p.053–060 / PDF 066–073〕
- **输入**：步骤①的团队与目标、步骤②的高层承诺与授权；制造、工程、质量、人力资源、财务、供应各单位主管；被选定的样板车间/生产线。
- **动作**：
  1. **确立推进组织**：有的叫"精益生产委员会"，有的叫"改善组织"；**推动组织的最高职位必须由企业或区域最高主管来担任**（一般总经理任负责人，有的企业把工厂负责的副总经理列为负责人），并由最高主管**授权于精益生产办公室**；组织必须包含制造、工程、质量、人力资源、财务、供应等多单位，将所有单位主管纳入组织活动；在最高主管与各部门主管的组织间建立推动事务组，进行总体规划及实际执行跟催，以及精益生产训练、精益文化的建立。〔p.053 / PDF 066〕
  2. **分三层**（图 6-1）：经营决策层／管制执行层／作业层，**经营决策层必须出任推动事务领导**；高层领导＝定出目标、描绘理想蓝图、建立奋进动力、分配资源并实现目标；中层主管＝亲临现场进行管理并决策；四大精益团队＝品管（制定品质标准、解决品质问题）、工程（产品工程标准及开发设计、新产品制造流程）、生产（生产计划和交货计划、物流仓储控制与改善）、人资（员工激励和晋升制度、多能工鉴定）、财务（推动投资和奖励审核、成果核算）；精益办公室＝主导推动事务规划、执行现场改善。〔p.054 / PDF 067〕
  3. **配备推进室人员并明确五项工作**（图 6-2）：推进室主管由制造、工程、质量、人力资源、财务、供应部门主管担任；团队成员来自生产主管、组长、线长、IE、生产技术、物流、技术工艺、研发、财务、人力资源等。五项工作＝①**规划协调**（导入制度、组织和实施计划建立；精益方法培训与说明；制定正确方向并规划；全面沟通协调；掌控精益工作进度及整体达成情况）；②**项目推动**（推进指导现场改善；合理化建议改善活动；U 型生产线项目；标准工时项目；直接与间接人力价值评价项目）；③**管控优化**（生产管理系统；人力评估系统；精益生产管理指标）；④**人才培养**（多能工培养；短期人员训练营；内部自主研讨；外派人员培养；精益专业人才训练）；⑤**举办活动**（精益生产活动宣传；精益生产交流大会）。〔p.054–055 / PDF 067–068〕
  4. **四项日常工作**：①全员参与（最高主管定出目标、优化资源分配；制造主管制订规划和实施方案并分步实施；精益顾问全力指导；全体员工参与，由强制劳动变成自动自发行为）；②成立强有力的推行小组——可由 **6～12 人**组成，来自品质、制造、工程、质量、人资、供应及其他领域，成员应具有耐心、持之以恒；③建立日常改善机制——通过生产现场**晨会和晚会**进行改善工作分配和总结（现场主管主持、所有团队成员参与，检讨当天改善进度及成果、确定明天改善工作内容和方向），同时**至少每周进行一次 1～2 小时的集中会议总结报告会**（部门主管和推进室人员参会），会议结束后去现场立刻进行改善，效果更好；④深入现场指导——部门主管和推进室成员分组深入现场，对进度进行管控，在现场快速解决问题。〔p.054–056 / PDF 067–069〕
  5. **推进计划与跨部门问题跟踪**：推进计划包括系统的实施计划、年度计划和月度计划，按 PDCA 方式记录；现场改善中**一周内无法解决的跨部门问题**须制订改善行动计划（字段＝**问题描述、完成时间、负责人及帮助需求**）；**每月由精益生产推动室主任召开改善行动跟踪会**，对所有未完成项目与负责人一起回顾并通报结果。月度管理会（汇报会/协调会）板块＝跟踪讲评重点工作、精益工作交流、精益现场检查、车间精益工作排名、存在问题及对策、工作亮点。〔p.056–057 / PDF 069–070〕
  6. **制度保证**：①KPI 管理机制——按推进的不同阶段制定对应 KPI 管理项目；每一推进阶段结束由推进室最高主管及各制造主管等组成验证团队进行阶段成果验证；**每月由推进室协同财务部门进行 KPI 指标达成公布、评比排名**，作为年底绩优单位评选依据，以海报形式在所有公告栏、内部刊物及网站公布；②绩效考评制度——建立完整的推动跟催评比及绩效考评制度（具体内容见原书第十五章，本册语料未覆盖）。〔p.058 / PDF 071〕
  7. **试点切入·样板区选点 3 标准**：①试点的产品要符合系列化、通用化、标准化、模块化要求；②加工工序较多，属流水线生产，人工作业率较低，实施精益生产方式后效果明显；③作为试点的班组人员政治素质、业务素质（包括 IE 素质）要高。**样板区首要任务是设法快速地展现成果**，给领导和员工以必胜的信心。〔p.059 / PDF 072〕
  8. **开展样板区的程序**（图 6-4，7 步）：①选择具有代表性的车间（生产线）——大家对改善的效果认同和接受，并给其他部门提供样板和参考；②选择硬件条件差的区域或生产线——短期的精益活动将创造出令人信服的效果；③选择负责人行动力强的车间或部门——保证样板区短期内取得效果；④快速有效地进行样板区的 6S 活动——通过整理、整顿和清扫 3 项活动改变现场面貌；⑤样板区 6S 活动成果的运用——为公司全面开展创造条件、积累经验；⑥示范线精益改善（IE、标准化等方法）推进——为公司全面开展打下基础；⑦非样板区可以自行组织推进并全面推广——非样板区及部门的实施计划书批准后公司备案，以便精益推进室监督指导、按整体进度实施。〔p.060 / PDF 073〕
  9. **示范线改善实施 6 步**：①选择流水作业的线并认真确认改善前状态——包括成品及使用零件清单、现状平面布置图、现状物与情报流程图、现行各工程 C/T 时间调查、线边库存状况调查、送货频率及数量；②制定各种技术标准——制定标准作业指导书、标准作业票，需对工人操作多次现场写实、重新制定工时定额（**不包括机动时间**），再确定生产节拍、制品定额、工艺规程、质量标准、设备维修标准和物料供应标准；③建立各种管理制度——建立监督考核制度（对生产工人、流水线、车间、科室分别制定考核标准）；建立新的工资分配制度——根据工人作业率、劳动强度、技术复杂程度将岗位分类、岗位不同工资不同，实行向一线倾斜、向多机操作倾斜；④流水线与工作地布置——流水线调整为"U"型以实现多品种混流生产；工序间运输工具改为滑道；对关键工序操作设计研制防失误装置；制作工位器具箱、架、板（工具箱、刀具集配箱、铁屑挡板、积油盘、波形脚踏板）；设立生产线停止指示灯或指示板、生产管理板、安全标志及宣传标志；对运输零件、毛坏和成品的车辆规定各自行驶路线，通过路标和不同颜色区分；⑤试运行——现场布置、标准、制度完成后开始试运行，采用 IE、标准化等方法进行生产线改善，遵循循序渐进原则、落实每个事情的责任人，多运用头脑风暴方法；改善小组负责人每日对改善进度进行确认；即时做好成果统计和成果发布；⑥总结推广——试点线成功后及时总结经验，向其他生产线、其他车间、非生产部门（如供应、设计部门等）全面推广；因地制宜找出突破口，创造出具有自己特色的精益生产方式。〔p.059–061 / PDF 072–074〕
- **输出**：三层推进组织+精益办公室+推行小组（6～12 人）；推进计划（系统/年度/月度）与改善行动计划表；月度 KPI 公示与排名；样板区与示范线的改善成果。
- **量化口径**：推行小组 **6～12 人**；**至少每周一次 1～2 小时集中会议总结报告会**；**每月改善行动跟踪会**（由推动室主任召开）；**每月 KPI 达成公布与评比排名**；示范线改善在 6S 取得初步成果后选择一条生产线进行（精益生产实施开始 **3～6 个月**，有的企业把示范线改善叫做"对象线改善"或"小范围改善"）〔p.055–056、p.059 / PDF 068–069、072〕；精益团队本身人数定额语料未覆盖。
- **常见失败**：推进办公室负责人不是最高主管（总经理挂名副手主导）→跟催无力；推进室人员不全（缺财务/人资/供应）→跨部门问题无人接；制度只有 KPI 无月度公布排名；样板区选硬件条件好的区域（看不出反差）；示范线不做改善前状态确认（无 C/T、线边库存数据）就动手改；试点成功后不总结推广。

## 5. 打法组合拳：「导入到试点启动」的时序打法（本册核心资产）

**总纲**：导入四节（危机感→理念→参观→高层决策）→步骤①（诊断→规划→目标→团队）→步骤②（高层支持→宣传→培训）→步骤③（组织→制度→试点），九拍串成一条时间线。原则：**前一拍的产出物是后一拍的输入，前一拍判据不达成不进后一拍**。

**第一拍：危机感（导入之一）**
- 动作：用表 3-1 问题清单（6 类 33 条：制造现场 7 条／制造过程 12 条／产品质量 4 条／现场安全 4 条／员工素质与能力 3 条／管理者与管理氛围 3 条）盘点企业自身，认清"这些问题都是企业当前亟须解决的问题"；对照图 3-1 按企业发展阶段选危机叙事素材；在公开场合灌输危机意识、采取象征性行动、用电视新闻演示破产后的情景；把压力传递给高层、中层、基层管理人员及一线员工。〔p.29–31、p.29–30 / PDF 043–044、042–043〕
- 产出物：完成自查的问题清单+全员可见的危机氛围。
- 过关判据：企业最高管理层建立危机意识（"对企业来说每天都有危机"）；管理层危机意识和紧迫感成立（这是实施精益生产方式的前提）。

**第二拍：理念（导入之二）**
- 动作：高层按表 3-2 五方面自训行为习惯；用表 3-3 传统管理思想 vs 精益理念 7 方面对照表做宣贯讲义底稿；高层对员工行为设定期望、和员工对话了解其对变革的感受（包括任何挫折与怀疑）、鼓励员工设法解决自己所提出的问题。〔p.31–33 / PDF 044–046〕
- 产出物：管理层自训记录+理念宣贯讲义（可直接用 14 项原则全文做教材，见 §2.3）。
- 过关判据：员工不再"以抗拒变化的心态对待变革"；认识误区（精益只是生产部门的工作等）被正面回应。

**第三拍：参观（导入之三）**
- 动作：第一步到国内本土先行企业参观（两家国内汽车集团等，学推行中的经验和教训，更符合中国国情）；第二步待实施到一定水平再去日本丰田等标杆企业。参观时对照丰田现场 6 项做法清单看细节（6S 五区域划分与生产看板／人性化管理"事故只能发生一次"／关爱员工降低劳动强度／全员合理化建议／生产调查组秒表测动作+看板显示灯拉绳停线／团队协作及时解决突发事件，见 §6 案例5）。〔p.34–35 / PDF 047–048〕
- 产出物：参观纪要+差距清单+改善思路。
- 过关判据：找出差距、理清改善思路，在人员管理和生产现场管理方面形成有成效的改进设想。

**第四拍：高层决策（导入之四）**
- 动作：企业管理部门利用各种机会向高层建议；组织中高层参观精益实施成功工厂；让其他部门管理人员向高层汇报所见所闻；推荐高层参加现场管理专家讲座；最终**将实施精益纳入企业的战略规划**。〔p.35–36 / PDF 048–049〕
- 产出物：纳入战略规划的决议=企业的统一目标和行动。
- 过关判据：高层对精益原则和精益实践"有完全而持久的坚定的信念"；高层领导对精益的理解、决心和承诺到位（此为成败决定项）。

**第五拍：全面诊断（步骤①上半）**
- 动作：选诊断方式（推荐"精益专家与中高层共同诊断"）→组建含生产、研发、供应、财务中高层的诊断团队→价值流图分析诊断+按表 4-2 七大诊断项目逐项检查（耗时"几个月"）→编写诊断报告→召开班组长以上骨干参加的诊断结果发布会→召开专题研讨会（会前 4 项准备、程序 7 步，见 §3.1）。〔p.039–042 / PDF 052–055〕
- 产出物：诊断报告、价值流现状图/未来图、统一思想后的骨干队伍、"精益状况布告栏"。
- 过关判据：报告用事实和数据反映目前状况并提出适合企业实际的改进方案；骨干思想和认识统一。

**第六拍：规划与目标（步骤①下半）**
- 动作：项目规划三步（总体规划→具体规划实施：从 6S 开始→TPM→JIT→合理化建议及课题改善→精益质量保证体系→阶段性评价后推广；建立项目管理机制）→按 SMART 定目标→总目标逐级分解（公司级 KPI／车间级／员工级三级口径，见 §3.1）→按图 4-3 六环节组建精益团队（抽调加轮训机制）。〔p.043–046 / PDF 056–059〕
- 产出物：项目总体规划书、SMART 化的三级目标体系、跨部门精益团队及轮训机制。
- 过关判据：下一级目标与上一级一致；团队负责人为具备良好指挥协调能力的中高层管理者。

**第七拍：高层支持+宣传+培训（步骤②，与第六拍紧咬）**
- 动作：高层做 4 项动作（承诺→变革〔含撤换不坚决者、清理矛盾旧制度〕→亲自参与改善→高度关注肯定）；铺五类宣传渠道（标语/条幅看板/重大活动/内部报刊/广电网站）；分层培训（管理人员及骨干：外部讲师+高层全程参加+考试合格才能上岗；员工：课堂培训+每人至少参加一个改善项目）；按表 5-2 四类项目选培训内容；建骨干滚动培训计划。〔p.047–051 / PDF 060–064〕
- 产出物：高层承诺宣达记录、宣传阵地、考试合格名单、每人一个改善项目的参与安排。
- 过关判据：高层"始终如一地坚持"并经常到现场；培训决定精益项目成败——骨干考试不合格不上岗。

**第八拍：组织与制度（步骤③上半）**
- 动作：建三层推进组织（最高职位由最高主管担任，授权精益生产办公室）→配推进室人员（四大系统主管+多职能成员）→明确推进室五项工作→四项日常（全员参与／推行小组 6～12 人／晨会晚会+每周一次 1～2 小时集中会议／深入现场指导）→排系统/年度/月度推进计划（PDCA 记录）→建 KPI 管理机制（每月协同财务公布、评比排名、海报公示）。〔p.053–058 / PDF 066–071〕
- 产出物：组织架构图与职责分工、推行小组名单、月度 KPI 公示、改善行动计划表（问题描述、完成时间、负责人及帮助需求）。
- 过关判据：跨部门问题每月有跟踪会回顾；KPI 每月有公布排名。

**第九拍：试点切入（步骤③下半）**
- 动作：按选点 3 标准指定样板区（产品系列化通用化标准化模块化／工序多、流水线生产、人工作业率较低、改善后效果明显／班组人员素质含 IE 素质要高）→按 7 步程序开展样板区（代表性车间→可选硬件条件差区域→行动力强的负责人→快速 6S→成果运用→示范线精益改善→非样板区备案自行推进）→示范线改善 6 步（确认改善前状态含 C/T 与线边库存→制定技术标准〔工时定额不包括机动时间〕→建立管理与工资制度→U 型线布置与防失误装置→试运行〔每日确认进度、即时成果发布〕→总结推广）。〔p.058–061 / PDF 071–074〕
- 产出物：样板区快速成果（给领导和员工必胜信心）、示范线成为名副其实的精益生产样板线、总结推广计划。
- 过关判据：样板区首要任务达成——快速展现成果；在车间第一线取得效果后再开始全面实施精益（"就会吸引其他部门的兴趣并促成整个精益项目的实施"）。

**月度排程基准（衔接表 6-1，详见 §6 案例4）**：第 1 月设立精益推行机构+管理人员启动培训→第 2～3 月全面宣传培训和试点区+全面 6S 改善→第 3～7 月标准操作（部件装配）与快速转换（部件加工）→第 5～10 月标准操作（总装配/测试/包装）→第 7～9 月全员生产维护+价值流图析→第 9～12 月看板系统、自働化体系、准时生产运行、事务性流程改善。〔p.057 / PDF 070〕

### 案例1 丰田生产方式的产生（TPS 起源）〔p.5–7 / PDF 018–020〕
- **背景**：20 世纪 50 年代日本经济萧条、缺少资金，日本制造业生产效率只为美国制造业的 1/8～1/9。1950 年丰田公司总裁对某美系车企底特律轿车厂进行为期 3 个月的细致考察——该厂日产量达 7000 辆，而丰田从 1937 年创立到 1950 年总产量仅 2650 辆，日本没有可能全面引进美国成套设备生产汽车。
- **发现**：该美系车企用一组冲床专门生产某一种特定零件，忽视检修或待料停工、出现大量半成品和成品库存，产品转型缓慢；丰田公司继任领导与 TPS 奠基者研究得出结论——大批量生产方式不适用于日本。
- **做法（四位奠基人）**：①丰田佐吉——1902 年发明自动纺织机，一名工人同时看管多台机器、设备故障自动报警停机（自働化前身）；②丰田公司创始人——提出只在下道工序需要时上道工序才生产（准时化基础）；③TPS 奠基者——参观美国超市货品信息通过看板展示并及时补给的系统获启发，发明拉动式生产系统并开发看板等一系列工具；④戴明——丰田邀请戴明指导，实践 PDCA 循环和统计质量管理思想，创造性设计按灯（ANDON）系统——减少大量返修时间、需要返修的半成品及时被发现、实际停线时间越来越少。
- **结果**：1962 年正式命名 TPS，1974 年对外公布；1973 年石油危机后丰田在经济负增长下获得高于其他公司且与年俱增的盈利；2007 年 Q1 全球销售 235 万辆、季度销售额首次超过某美系车企。
- **可迁移点**：在资源、资金不足和多样化需求的市场条件下，从本国社会文化背景出发设计制度，而不是照搬成套设备。

### 案例3 某电梯装潢公司交货期延误（全面诊断→精益解法）〔p.041–043 / PDF 054–056〕
- **背景**：该公司 20 世纪 70 年代还是江南乡镇企业，2005 年已发展为大型民营集团公司；产品技术国内领先、订单纷至沓来，生产难以应付，销售人员只能到装配车间现场催交货物，经常迟交、客户不满；特聘请企业管理公司进行生产管理咨询。
- **诊断发现 5 问题**：①销售与生产计划部门沟通少，下单时间紧迫；②生产计划只有粗框条，没有按交货时间分解到每个产品每道工序的完成时间；③员工干好干坏一个样，车间、班组、工序之间配合作业能力差；④产品质量不能保证，不合格品在车间内和厂区通道上到处可见；⑤生产现场和车间外通道里堆着 **400 多万元**没有发出的产品。
- **做法（三步）**：常规对策是增加库存；精益生产通过压缩在制品库存来压缩等待时间→迅速压缩生产周期→最终实现削减库存而缩短交货期。①分析交货期与生产周期的关系（调查存货数量和生产节拍：生产提前期、生产切换时间、加工工艺本身需要的时间、生产能力、已经投入的任务数量、一天内工作时间的长短等）；②采用"单元生产线"——先建一条新型单元生产线总结经验再全厂推广：机器设备、人员、加工工具按工艺顺序流水化布局；多能化培训使一位作业员能从头到尾把一个产品生产完成；压缩转移批量达成一个流、减少在制品、消灭周转库存；③采用精益工具——快速转换（SMED）、标准作业、看板管理、全面生产维护（TPM）、QC 方法、自働化方法等。
- **结果数据**：改善后的量化成果语料未覆盖（文本止于"达到令人满意的最直接的效果"）。
- **可迁移点**：交货期延误类问题诊断先查"销售—计划沟通、计划分解粒度、考核与配合、质量、库存"五个方面；解法主轴与"加库存"的常规对策相反。

### 案例5 丰田准时化生产的经验（表 3-4，参观学习"看什么"清单）〔p.34–35 / PDF 047–048〕
1. **实施全面 6S 管理**："6S管理是生产管理的基础，还是生产管理的全部"；车间分 5 个区域（汽车装配流水线区、装配零部件存放区、装配人员工作区、零部件搬运人员走动区、参观人员走动区）；流水线上每一台车前部粘一张 A4 纸大的生产看板，标明本台车需安装何种规格零部件、何种材质或颜色内饰，搬运员按顺序准确送达、装配工按看板指令准确安装。
2. **实现人性化管理**：反对用惩罚的方法管理员工——员工犯错误时，高层管理者先反省领导者自身的错误；树立"事故只能发生一次"思想，对每次事故彻底分析、找出原因、拿出多种预防和解决方案、选定最佳方案，再出台相应管理制度并严格执行。
3. **关爱员工，全力降低劳动强度**：食堂和卫生间达到五星级卫生标准；所有笨重的或有危险的工作一律实现机械化；装配线设计安装许多机械手，实行无车门安装工艺。
4. **全员参与合理化建议活动**：每年收到员工合理化提案达几十万件——建立和完善合理化建议制度及评价执行体系；提倡改善从小事做起（"做好身边的小事，就能产生惊人的效果"）；推广改善后的效果并实行标准化；对改善者提供物质和技术支持，表扬、奖励甚至提升；领导重视，持之以恒。
5. **杜绝一切浪费，降低成本**：成立生产调查组，把生产每个环节、员工每个动作用秒表计算出来，把每一个动作浪费做到可视化再持续改进；现场走廊安装看板和写有各工位号的显示灯，显示计划产量和实际完成情况；各工位上方设一根绳子，出现质量问题时员工一拉绳子整条生产线暂停，用彩色指示灯发现问题所在、最短时间解决。
6. **团队协作及时解决突发事件**：一线设备操作工人发现产品或设备突发问题时有权自行停止生产，当班班长及相关人员很快出现、立即采取措施共同解决，防止次品重复出现。
- **可迁移点**：作参观学习的"看什么"清单（衔接导入之三），以及导入后现场对标模板。

### 案例6 中国精益先驱：某汽车集团〔p.19、p.34 / PDF 032、047〕
- **背景与做法**：20 世纪 80 年代中期，某汽车集团公司因生产成本高、劳动生产率低、设备老化、产品资金断档陷入困境，高层领导下决心，派出以厂长为首的专家小组赴日本考察学习汽车工业管理经验。更早的 20 世纪 70 年代，TPS 奠基者曾两次到某汽车集团讲学；丰田生产方式引入中国至今已 30 多年。
- **先行企业名单（参观对象参考）**：三家国内汽车、钢铁企业为中国精益生产的先驱；20 世纪 90 年代国内日资、中日合资、美资企业全面实施的有三家日资制造企业；国内企业有某钢铁企业、某汽车企业、某家电企业、某电子企业、某工程机械企业。〔p.19、p.34 / PDF 032、047〕
- **可迁移点**：参观学习两级路线中"第一步国内先行企业"的具体名单来源；同时也是一个反面对照——引入早（30 多年）但除先驱外未普及，迟于中国启动的美国企业热心学习、执着实践、发展并超越日本（见 §7 反例）。

## 7. 反例清单

| 错误做法 | 后果 | 正确做法 | 出处 |
|---|---|---|---|
| 采用咨询机构专家组诊断但中高层管理人员不参与 | 专家组对具体情况不十分了解，导致后面规划和执行脱节，且诊断费用很高 | 采用精益专家与中高层共同诊断方式 | 〔p.039–040 / PDF 052–053〕 |
| 企业中高层自己单独诊断 | 费用低但效果一般，诊断不全面、有局限性，问题确定不深入，反给以后规划和执行带来更多麻烦 | 让中高层参与、借助精益专家的共同诊断方式 | 〔p.040 / PDF 053〕 |
| 为缩短交货期而增加库存 | 库存掩盖等待时间，交货期并未真正缩短 | 压缩在制品库存→压缩生产周期→削减库存而缩短交货期 | 〔p.042 / PDF 055〕 |
| 老板授权某人来主导精益（而非亲自主导） | 意义完全不同，推动力弱 | 最高领导力支持、始终如一坚持、亲自参与（丰田公司创始人下"即使辞职也要把改革进行到底"的决心支持 TPS 奠基者改革） | 〔p.047 / PDF 060〕 |
| 对不坚决和执行不力的管理人员放任 | 精益变革难以推进 | 必须坚决撤换；同时清理与精益原则矛盾的旧制度 | 〔p.048 / PDF 061〕 |
| 过去开展过 6S、IE 活动但效果不显著后直接铺开精益项目 | 员工对精益项目产生怀疑甚至抵触情绪 | 先从样板区试点，短期内取得良好成效，使员工充满信心 | 〔p.059 / PDF 072〕 |
