   方法论细节一律回到 01–08 册；01–08 册没有的，明确说"语料未覆盖"。

   按目录惯例**不做中性化**（与 01–08 册正文的中性化口径不同）——它们只表示资料出处，
   不代表任何评价；本册自撰的综述段落（§1）按 01–08 册口径中性化。

## 1. 全库主题知识地图（806 条的综合归纳）

> 以下 14 个主题域由 8 份切片的片内综合归并而成，括号内为该域条目量级（含重复版本；
> 该库基础课件存在大量同内容多版本，引用时按标题区分）。

### 1.1 5S/6S 与目视化·定置（约 60 条）
全库最大的知识簇。共识：5S 不是环境美化，而是防错、提效、暴露浪费的手段；落地靠
"高层承诺 → 推行组织 → 行动计划 → 执行标准/点检评分 → 评核坚持"的闭环，用目视化
（区域线标准、看板、色标、红单、形迹管理）把异常变"一目了然"。代表条目：5S 执行标准
（办公室篇）、5S 点检评分标准、5S 图例集、关田法三十步骤、某酒店工作车/仓库定置案例。
→ 方法论本体见 **03a 分册**（5S 六步 + 红牌 + 定置率 + 100 分表）。

### 1.2 基础工业工程 IE（约 50 条）
同一教材系列分章递进（工作研究、程序分析、动作分析、时间研究、现场管理、IE 信息化），
加某大型代工企业 IE 培训、IE 知识点汇总、工位器具讲义与制度等。标准工时已形成完整制度链：
定义（泰勒公平日工作量）→ 制定（秒表/MOD 21 动素/PTS）→ 评定 → 控制 → 应用
（成本核算、定员、排线、奖金）。→ 见 **01/03b/05b 分册**。

### 1.3 TPS 体系与精益思想基础（约 50 条）
TPS 系列教材按"体系与基本思想 → 准时化 → 自働化 → 改善 → IE 手法 → 省人化 →
流水作业分析"分章；丰田屋结构（QCD 目标 + JIT/自働化两支柱）反复出现；精益思想/精益
概述类课件高度同质（源头均指向 TPS 与 MIT 国际汽车项目），存在大量冗余版本。
→ 见 **01 分册**。

### 1.4 JIT·拉动·看板（约 45 条）
最完整的工具族：看板定义/种类（生产/信号/领取/外注）/数量计算/八大先决条件 →
2-Bin 双箱、采购件拉、普通拉、二级拉动（EPS+WMS）等场景变体 → "后工序领取、前工序
补充、只生产被领走的量"普适原则；多条目指出 ERP 难以实现拉动的根源在计划推动逻辑。
→ 见 **02a 分册**（含看板张数公式）。

### 1.5 流线化·单件流·节拍·SMED（约 20 条）
孤岛布局 → 搬运浪费与批量拉长周期；"节拍 → 线平衡 → 瓶颈改善 → 连续流"路径；
SMED 内/外作业分离与事前准备法则作为小批量一个流的支点。→ 见 **02a 分册**。

### 1.6 TPM·设备管理（约 35 条）
TPM 定义五要点、八大支柱、自主保全七步（含诊断表族）、个别改善专项、推进铁则；
"设备故障不是突然发生的"教育资料与野猪磨牙寓言强调日常点检先于故障；WCM 以
WCM=LM+TQM+TPM+SCM+EI 整合并配 QC 支柱七步骤与审核评估。→ 见 **04a 分册**。

### 1.7 质量管理·SPC·质量成本·供应商（约 45 条）
SPC 统计基础（抽样、两类错误）、防错 Poka-yoke、单元生产、线平衡构成工序内质量保证层；
质量成本四类费用（预防/鉴定/内损/外损）核算链条 + QC 小组活动表单；进料检验—供应商
评价/考核/现场评审—合格名单的来料管控链。→ 见 **05a/06/07 分册**。

### 1.8 结构化问题解决（约 35 条）
A3 报告为通用载体：十余个跨行业案例（制造业与酒店服务业）均按"明确问题 → 把握现状 →
设定目标 → 找出真因 → 建立对策 → 实施/验证/推广"展开，目标全部量化；配合鱼骨图、
5Why、PDCA、DMAIC、QCC。→ 见 **03a（A3/TBP）/05a（8D）/07（QCC）分册**。

### 1.9 六西格玛与统计（约 12 条）
DMAIC 教学链：项目定义（CTQ/SIPOC/狩野模型）→ 基础统计 → 图形分析 → MSA 测量系统
分析（Gage R&R 数据可信性）。→ 见 **06/07 分册**（SPC/Cpk 全套公式在 06 册）。

### 1.10 生产计划·供应链（约 18 条）
两条技术路线：APS 同步优化引擎（系统工具）vs PMC 订单评审/周计划/物料控制（组织流程）；
物料 ABC 分类、搬运分析、滞料废料处置的全生命周期表单。→ 见 **04b 分册**。

### 1.11 班组长与基层管理（约 45 条）
条目数最多的单点岗位：一日作业标准（交接/早会/巡检/4M1E 变化点/总结）、班前会技巧、
报联商四讲、IE/QC 手法在班组的应用、班组手册 8 要素，形成"日常标准动作 + 沟通机制 +
改善技能"框架。→ 见 **05b 分册**。

### 1.12 精益数字化·智能制造（约 28 条）
2020 年代主线："精益为体、数字化为用"，精益生产是智能化的基础。载体：VSM/MOM/
灯塔工厂/三年规划/数字化看板/精益 MES/数据中台/精益云；多条目主张相互赋能而非替代。
→ 见 **04c 分册**。
