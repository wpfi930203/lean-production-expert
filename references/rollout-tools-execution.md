# 分册 08-B 推行工具实战：步骤④–⑩（推行手册·中）

> **适用场景**：正在按《精益生产推行手册》的推行步骤④–⑩逐段落地精益，需要知道"第几步用什么工具、具体怎么操作、数字达到多少才算过关"时翻本册。触发关键词：目视管理、6S、IE、TPM、价值流、一个流、少人化、防错、ANDON、均衡化、线平衡、SMED、看板数量计算、TQM/QC七大方法/6σ、标准作业。
> **语料来源**：`_distill\book-rollout\extract\A3-step4-basics.md`（第7章·步骤④）、`A4-steps5-6.md`（第8–9章·步骤⑤⑥）、`A5-steps7-8.md`（第10–11章·步骤⑦⑧）、`A6-steps9-10.md`（第12–13章·步骤⑨⑩）。
> **一句话精华**：工具只有放进推行时序里才有效——先基础管理（6S/目视/IE/TPM/VSM）打底，再流线化改布局，然后自働化防不良流出，之后均衡化拉平负荷，最后才上拉式看板；**没有均衡化和快速换模就直接导入看板，将注定失败**〔p.205 / PDF 218〕。
> **与其他分册的分工**：jit / jidoka / tpm-equipment / qc 等分册讲工具"是什么、为什么"；本册讲"在第几步、怎么做、判读阈值是多少"，公式全部逐字照抄原书。

## 2. 概念地基

| 概念 | 判据（怎么算它是它） | 易混淆点 / 什么不是它 |
|---|---|---|
| 推动式 vs 拉动式 | 推动式＝计划下达所有工序、提前超额生产、大批量、在制品多；拉动式＝计划只下达最后一道组装工序、后序向前指令、小批量、少量存货〔p.202–203 / PDF 215–216〕 | 拉动不是"少备点料"，是"只生产销售出去的产品和数量"；拉动异常影响几乎全部工序（无缓冲库存），管理压力更大 |
| 内作业 vs 外作业 | 内作业（线内）＝机器停工时才能完成的切换动作（如工装夹具切换）；外作业（线外）＝机器正常运转时就能完成的事前/事后动作（如准备工具、放置台准备）〔p.186 / PDF 199〕 | SMED 的核心不是"手快"，而是先把内作业转成外作业；"所有外作业都不包括在换模操作内"〔p.187 / PDF 200〕 |
| 自働化 vs 自動化 | 自働化（带人字旁，Jidoka）＝机器自己感知异常、根据自身判断及时自动停止、不把不合格品送往下一道工序、用光和声音通知异常；一般自動化＝出现异常需有人停机否则连续运行、继续生产不合格品〔表9-2，p.136 / PDF 149〕 | 无检测的全自动阶段是陷阱："工人可以走开，但比半手工工作成本高，而且无人检测质量"〔p.139 / PDF 152〕 |
| 标准作业 vs 作业标准 vs SOP vs IE | 标准作业＝以人的动作为中心、规定节拍时间/作业顺序/标准持有量三要素的作业方法指南；作业标准＝各工序为产出设计者所希望功能而规定的技术标准、作业方法和管理条件（温度/时间/压力、刀具条件、QC 工程表等）；SOP（标准作业程序）＝确定作业顺序和周期时间、表示总加工时间（含人机作业与行走时间）〔p.245–246 / PDF 258–259〕；IE 是"推行精益生产不可缺少的核心工具之一"，精益生产是 IE 的延伸和发展〔p.85–86 / PDF 098–099〕 | 标准作业根据"人的活动"而不是机械运转而定；三者常被混用但载体不同：标准作业→组合表/作业卡，作业标准→要领书/技术条件 |
| 大切换 vs 小切换 | 大切换＝不同系列不同产品型号之间切换（内容多、工艺基准变化大、工时消耗大）；小切换＝同一系列内切换〔p.185–186 / PDF 198–199〕 | 减少切换次数的重点是"最大限度减少大切换，避免二次切换"〔p.188 / PDF 201〕 |
| 两类等待时间 | 第一类＝生产过程非均衡化使不同批量零件之间产生的等待→对症：生产线均衡化；第二类＝运输批量过大引起的同一批量零件之间的等待→对症：小批量运输、同步化〔p.119 / PDF 132〕 | 只做均衡化不做小批量搬运、或只做小搬运不做均衡化，都缩短不了总等待 |
| 目视管理三级标准 | 初级＝有表示、能明白现在状态；中级＝谁都能判断良否；高级＝连管理方法（异常处理流程、故障报告书、记入者/时间）都列明〔p.66 / PDF 079〕 | 只贴标语不列异常处理方法，永远停在初级 |
| 6S 的定位 | 6S 是企业推行精益生产的最基础工作，其实施水平决定 TPM、JIT、六西格玛及 ISO 等项目能否顺利实施〔p.69 / PDF 082〕 | 6S 不是"打扫卫生"：清扫须升级到污染源对策，清洁＝干净、高效、安全的状态并制度化 |

## 3. 方法工具六格

### 3.1 工具1 目视管理（步骤④·精益工具之一）

- **定义/目的**：利用视觉进行管理的科学方法，以公开化、透明化和视觉信号显示为特征；快速传递信息，将潜在问题和浪费显现出来，是精益生产推行的重要基础工具〔p.63 / PDF 076〕。
- **触发条件**：推行精益生产需要快速畅通的信息流时；现场状态（目标/质量/物料/设备/环境）需要"谁都看得见"时。
- **操作步骤**：①按应用范围表（表7-2）逐类落地：目标流程管理（指标推移图、操作程序/作业要点提示）、质量管理（不良状态识别分色或用道具、品质异常提示、特性值文字标识）、物料管理（采购数量标识、物品卡、极限高度标识）、设备管理（点检表、画线定位、看板标识状态）、现场环境管理（油漆/胶带画分界线、分色涂色、图文字安全提示、状态标识、垃圾分色分类）〔p.66 / PDF 079〕。②统一规划、统一标准，分步实施、分项实施，严格规定、赏罚分明。③参照划线规范把"宽度+线型+颜色+用途"四要素定死（主通道线 120mm 黄实线、次通道线 50mm 白实线、作业/原材料/半成品区域线 100mm 黄实线、机台/小物品四角定位线 50mm 白色、不合格品/废品/危化品/警戒线 50mm 红细实线、危险区域线/配电柜/突出物 50mm 黄黑斑马线）〔p.67 / PDF 080〕。④通道 5 条要求：尽量避免转弯、交叉处直角、通道上不可停留存放物品、保持地面干净、安全出口有标示且畅通〔p.68 / PDF 081〕。⑤放置规范：物料装载不超高（与物料筐平齐）、在制品/产成品/不良品（返修品）/报废品物料筐不能混合使用、装载物料按指定区域放置；放置高度一般限度为 80 厘米；货架与搬运工具四角定位〔p.68 / PDF 081〕。⑥标识规范：区域标识、种类标识、名称标识、数量标识；工具架标识牌字段＝车间班组·工具架＋责任人＋四层分类（第一层图纸量具/第二层用品工具/第三层待加工零件/第四层已加工零件）〔图7-3，p.68 / PDF 081〕。⑦安全目视规范：安全色红蓝黄绿对应警告、禁止、指令、提示；危险部位警示标志 3 类＝黑黄斑马线（老虎斑）、防触电警示、作业危险警示（防挤压、摔伤警示）〔p.68–69 / PDF 081–082〕。
- **量化口径与公式**：三级标准递进（初/中/高级，见概念地基）；划线规范"宽度+线型+颜色+用途"四要素表（某机电公司实例，表7-3）：

| 类型 | 宽度 | 线型 | 颜色 | 使用物品 |
|---|---|---|---|---|
| 主通道线 | 120mm | 实线 | 黄色 | 共用 |
| 次通道线 | 50mm | 实线 | 白色 | 推车 |
| 作业区/原材料/半成品区域线 | 100mm | 实线 | 黄色 | 移动式物品 |
| 成品/检验区域线 | 100mm | 实线 | 黄色 | 固定式物品 |

〔p.67 / PDF 080，图像回读核对〕
- **判读与决策**：任何一张看板/标示若"新人看不懂、异常无处理方法"，按高级标准补齐处理流程与记入者；通道上发现停留/存放物品、油污立即整改（通道 5 条要求）。
- **常见失败**：只做宣传不做标准（无统一线宽/颜色标准）；对事又对人（正确做法：出现问题协助当事人查原因，"千万不要说任何伤害感情的话"〔p.66–67 / PDF 079–080〕）；布告通告栏被闲置。
- **出处**：〔p.63–69 / PDF 076–082〕

### 3.2 工具2 6S 管理（步骤④·精益工具之二）

- **定义/目的**：整理（SEIRI）、整顿（SEITON）、清扫（SEISO）、清洁（SEIKETSU）、素养（SHITSUKE，原书拼作 SHITSKE〔OCR 存疑〕）、安全（safety）；目的＝改善生产生活环境、提高效率品质、形成自主改善机制〔p.69–70 / PDF 082–083〕。
- **触发条件**：企业推行精益生产的最基础工作启动时；后继 TPM/JIT/6σ 项目推不动、现场脏乱差时。
- **操作步骤**（标准化推进 12 步，图7-9）：①6S 活动策划→②企业诊断（记录现状、基准、实施日期和人员）→③高层领导支持理解→④建立推进组织（推行委员会**每个月召开一次会议**＋事务办公室＋项目专员＋技术小组＋各部门执行团队）→⑤编制推行计划→⑥宣传教育→⑦确定样板区并实施（样板区四判据：代表性部门、高层认同、责任人改善意识强、**7～30 天短期见效**）→⑧样板区成果发布→⑨全公司全面展开（动员大会 8 步，全员宣誓）→⑩现场评比与考核（**每个月至少进行两次 6S 考核**；公司级、工厂级、班组级、员工级四级检查体系）→⑪修订完善 6S 标准化体系文件→⑫建立改善提案激励机制〔p.78–83 / PDF 091–096〕。
  - 各 S 技巧：整理＝红牌作战（红牌字段：分类 9 类/名称/编号/数量/理由 6 项/责任车间/措施 6 项/张贴日/改善期限/填表人）＋定点摄影（同位置同高度同方向连续摄影，每周每车间选定**两个**不达标区域摄影公布）＋寻宝活动；整顿＝三要素＋三定；清扫＝油漆大战＋点检表＋洗澡运动；清洁＝标准化＋QC 手法＋目标管理；素养＝晨会＋合理化建议＋QCC；安全＝目视管理＋点检表＋作业标准化〔p.70–77 / PDF 083–090〕。
  - 各 S 推进重点（表7-4 摘要）：1S 整理——制定"必需品/非必需品"判别基准→全面检查处置（货架、工具箱、墙脚、窗台上的样品零件杂物）→按使用频度定日常用量与放置位置→每日自我循环整理；2S 整顿——三要素（场所/方法/标识）→三定（定点/定类/定量，按机能或种类区分便于拿取和先进先出）→划线定位→规定场所放置并标识；3S 清扫——建立清扫责任区决定方法→例行清扫→**调查污染源予以杜绝或隔离**（溢漏处密封封起来）→建立清扫标准习惯化并检查；4S 清洁——制定专门手册教育推进组织→明确清洁状态（干净、高效、安全）→环境色彩化→制定检查规定领导带头巡查→奖惩制度考评；5S 素养——继续推动前 5S→共同遵守的员工规则规范→礼仪守则→教育训练（新进人员强化 6S）→目视管理月/红牌作战月→精神提升活动（晨会、礼貌运动）→征文活动；6S 安全——现场安全因素识别→建立安全生产管理制度→应急预案→员工安全着装→安全标志警示标线→安全培训→现场检查排除隐患→明快有序安全的环境〔p.70–71 / PDF 083–084〕。

### 3.3 工具3 IE 工业工程（步骤④·精益工具之三）

- **定义/目的**：最有效活用人力资源和其他生产资源的技术；核心是降低成本、提高质量和生产率；方法研究和作业测定是最广泛的基础工具〔p.85–86 / PDF 098–099〕。
- **触发条件**：局部改善（方法研究）、作业标准和时间设定（作业测定）时；人机配合差、交期延迟、动作浪费多时。
- **操作步骤**：
  1. 程序分析：用五种记录符号（○加工/→搬运/□数量检查/◇质量检查/▽储存/D 停滞）记录全过程，按四种方法选择〔表7-10、7-11，p.87–89 / PDF 100–102〕：
    - 产品工艺分析：多人多台机器制造同一产品的工艺过程；调查加工、搬运、检查、停滞情况并制订改善方案；适用于任何产品加工。
    - 作业流程分析：一人通过不同机械在几个作业区加工多个产品；易发现作业者多余动作，但"必须紧随作业者方可观察其行动"。
    - 联合作业分析：一人多机/多人一机/多人共同作业；理顺人与机械、人与人时间关系，消除设备空转浪费、使人和机器作业负荷均衡。
    - 业务流程分析：跨部门多人连续业务；加快信息传递、业务标准化、去除多余表单文件。
  2. 联合作业分析五步：现状调查→绘制现状流程表→制订改善方案→绘制理想作业流程表→改善方案标准化〔p.89–90 / PDF 102–103〕。算例：13.5 分钟作业中人机各 62.9% 时间空转/等待（表 7-12），把等待机器加工的 5 分钟填入上一零件整修检查放置（2 分）＋下一零件准备（1.8 分）→周期缩至 8.5 分钟，设备利用率 100%、人员效率 96.5%〔OCR 存疑：正文一处作"原来 12.5 分钟"，与表合计 13.5 分钟矛盾，原样保留〕。
  3. 作业测定：作业循环时间＝设备加工时间＋人工辅助时间＋等待时间；标准时间构成＝观察时间×评比因数（→正常时间）＋私事/疲劳/程序/特别/政策五类宽放；测定方法五种（时间分析法、连续观测法、瞬时观测法、预定时间标准法、标准资料法——语料仅列名）〔p.91–92 / PDF 104–105〕。标准时间用途：确定工作量、编制生产成本计划、制定工作标准、改进工作。
  4. 动作分析四步：观察记录动作（分解成动作要素）→动作价值分析（按贡献分类发现浪费）→消除浪费优化动作（无价值要素尽量消除，有价值要素做得更轻松更快更好）→重新编排岗位作业；18 种动素（伸手 TE/握取/移物 TL/放手 RL/装配/使用/拆卸 DA/寻找 SH/选择 ST/定位/预定位 PP/检验/持住/发现/计划 PN/迟延 UD/故延 AD/休息）分 A/B/C 三类（分类边界 OCR 丢失〔OCR 存疑〕）；改善三法＝动作优化（合并动作要素、多用左手、利用重力动力、消除反重力作业）/改善作业场所（材料工具放面前固定位置、按作业顺序摆放、两手同时作业、作业领域越小越好）/夹具与工装化（一个动作控制机器、两手同时作业的夹具、用适当工具消除某些动素）〔p.93–95 / PDF 106–108〕。
- **量化口径与公式**（逐字照抄）：
  - 有效运转率＝有效作业时间/总投入时间×100% ＝（总投入工时－非作业时间）/总投入工时×100%
  - 切换率＝总切换时间/总投入时间×100%
  - 切换效率＝1－切换率
  - 综合有效运转率＝有效运转率×(1－切换率)
  - 算例：有效运转率＝838÷960×100%＝**87.29%**；切换率＝1625÷(16×26×60)×100%＝**6.5%**；切换效率＝1－6.5%＝**93.5%**〔p.92–93 / PDF 105–106〕
  - 宽放率：私事宽放一般 5%；疲劳宽放轻作业 5%～10%、重作业 20%～30%、特重作业 30%～60%〔p.91 / PDF 104〕
- **判读与决策**：非作业时间按"计划内（班前会/点检/工间休息）＋计划外（设备故障/调整/待料/质量问题）"结构化记账，哪块大先改哪块；人机等待显性化后用平行时间条重排。
- **常见失败**：只优化局部不研究全过程；改善方案不标准化（"因作业人员的流动而导致好的作业方法流失"〔p.90 / PDF 103〕）；瓶颈工序人员安排做非增值搬运。
- **出处**：〔p.85–95 / PDF 098–108〕

### 3.6 工具6 一个流（步骤⑤·精益工具之六）

- **定义/目的**：将作业场地、人员、设备合理配置，零件一个一个地依次经过各工序加工、移动，始终不停滞、不堆积、不超越，按节拍一个一个地流动〔p.116 / PDF 129〕；应对多品种、小批量、短交期，压缩库存和交货期。9 项优点：最短生产周期；减少存货和在制品（每工序最多一个在制品或成品）；占用生产面积小；容易适应市场与计划变更；交货期最短生产效率高；及时发现问题并彻底迅速解决（一旦工序中断整条线即刻停线）；有利于显著提升产品质量（每个作业员都是质量监控者）；不需要高性能大型化设备、减少投资；减少管理成本〔p.117–118 / PDF 130–131〕。
- **触发条件**：在制品堆积、批量等待大、不良难以即时发现、交期长时。
- **操作步骤**（推行 12 步，图8-6）：①总体动员及培训→②成立示范改善小组（生产管理、工程、品管、IE 骨干组成）→③选定示范生产线（订单质量较稳定的产品；建立 KPI：LeadTime、WIP、人均产能、良率、损失工时）→④现状调查分析→⑤设定生产节拍→⑥决定设备、人员的数量→⑦布置一个流的生产线（按制程顺序排列设备，设备小型化、滑轮化、专用化）→⑧配置作业人员（每人的制程人力时间总和与生产节拍完全一致；需多能工）→⑨单件流动（先小批量过渡；建立"一工序中断，整条线停线"机制）→⑩维持管理与改善（用控制图长期推移管理）→⑪标准化及水平展开→⑫迈向无人化生产〔p.130–131 / PDF 143–144〕。
  - 八大条件：单件流动、按加工顺序排列设备、按节拍同步生产（标签 OCR 缺失，据内容补注〔OCR 存疑〕）、站立式走动作业、培养多能工、机器设备小型化、U 形化布置（"入出一致"）、作业标准化〔表8-7，p.130 / PDF 143〕。
  - 布置演进：机群式→直线式→U 形（出口入口尽可能靠近；第一道与最后一道工序同一作业员操作；多工序操作步行距离最短；按需求增减人数）。四种传统布置的缺陷：一人一机＝机床加工时只能站在旁边等候，白白浪费大部分工时；鸟笼式＝减少待机时间但增加该作业人员单位时间生产数量，必然过量生产；孤岛式＝作业人员相互隔离、整体未减少运输时间和费用、免不了过量生产、柔性化问题未解决；直线式＝不便于把各线零星工时集中利用、也不便于整数调整作业人员人数〔p.120–122 / PDF 133–135〕。
  - 搬运改善 5 方向（表8-4）：①搬运距离——单元布局、避免逆搬运；②一次搬运量——小批量转移甚至单件流为目标（U 形线缩短搬运距离解决小批量搬运次数过多的浪费；输送带解决库存和搬运时间的矛盾）；③搬运容器——便于装卸，决定活性系数与搬运数量；④搬运人——**瓶颈工序段的人员若安排从事非增值的搬运活动将直接影响到产能，应优先其他人员**；⑤搬运方式——自动化程度高的方式，但须同时考虑投资回报率与空间配置〔p.126 / PDF 139〕。
  - 生产物流合理化 5 要求：连续性、平行性、节奏性、比例性（零部件数量在各工序间保持比例）、适应性（多品种小批量的应变能力）；配货场离生产线尽可能近（零件包装分散、送货频次多）〔p.128–129 / PDF 141–142〕。
- **量化口径与公式**：10 个批量加工周期 LT：批量生产 150 秒 vs 一个流 60 秒；20 个批量：300 秒 vs 110 秒〔表8-1，p.118 / PDF 131〕。U 形线用人数例：12 台机床组成 U 形线，生产周期 1 分钟时每 3 台机床 1 人、需 4 名；周期 1.5 分钟时看管 5 台、需 2.4 人→因没有 0.4 人故安排 3 名，整数减少 1 名〔p.122–123 / PDF 135–136〕。物流时间占比：物品加工型加工时间仅占 10%～20%、物流活动占 80%～90%〔p.127 / PDF 140〕。搬运活性系数 0～4（零星散放地面=0→袋装箱内=1→栈板=2→手推车/卡车=3→输送机=4），设计尽量取高活性状态〔p.125 / PDF 138〕。
- **判读与决策**：单盒/单盘/单片小批量先行，逐步过渡到单件；试跑出现等待堆料→回第 4 步重看作业分配；同步化使"不合格品立刻被相邻工序发现"〔p.120 / PDF 133〕。
- **常见失败**：只搬设备不改作业顺序；布置成鸟笼式（过量生产）、孤岛式（柔性未解决）、直线式（不便整数调整人数）；「一人一机」效率太低。
- **出处**：〔p.115–131 / PDF 128–144〕

### 3.7 工具7 少人化（步骤⑤·精益工具之七）

- **定义/目的**：按照每月生产量的变动弹性地增减各条生产线作业员人数，通过排除多余人员实现成本降低〔p.132 / PDF 145〕。
- **触发条件**：需求波动下人员减不下来、各线人数固定无法调配时。
- **操作步骤**：三项工作内容——①减少工序作业人员数量（省人化）：作业改善（决定作业规则、重新分配作业量、标明放置场所）＋设备改进引进；②自由调节各作业人员的作业范围：U 形布置单件流水＋岗位定期轮换培养多能工；③能进行工作中的相互配合：工位紧密相连＋混流生产＋掌握调整全部工序人员。三种实施方法：设备的同一节拍连接方式（同一节拍两条线相连重新分配人员）、产品的多品种混流方式（专用线通用化混流化，追求整数人工数）、人员的不同节拍综合配置方式（线内外综合配置）。前提："首先需要对设备合理地布置和设计，采用一个流生产方式；其次，要培养操作多种工序能力的多能工；最后，要经常修改、审核作业标准"〔p.132–133 / PDF 145–146〕。
- **量化口径与公式**：少人化 vs 省人化——省人化（减少工序作业人员数量）是少人化的子项；省力化＝把人应做的工作的一部分转换成机器操作〔p.133、136 / PDF 146、149〕。
- **判读与决策**：需求下降时按整数人工数重排；U 形线"出口和入口在同一位置，只需一位作业人员就能同时处理，按需求量变化增减单元内作业人员数"〔p.122 / PDF 135〕。
- **常见失败**：无 U 形布置与多能工就谈少人化；把"省力化"当"少人化"（机器代替了人但人没减下来）；作业标准长期不修订导致无法弹性调岗。
- **出处**：〔p.132–133 / PDF 145–146〕

### 3.8 工具8 防错法 + ANDON（步骤⑥·精益工具之八＋自働化三技术）

- **定义/目的**：防错法（POKA-YOKE，又称愚巧法、防呆法，新乡重夫创立）＝在作业过程中采用自动作用、报警、标识、分辨手段，防止人为错误导致不良发生、流出，防止设备破损及故障发生；ANDON（安灯）＝异常时授权作业员迅速告知大家的指示灯系统；两者都是自働化"异常检测→自动停机→异常报警"三技术的载体〔p.142、145、152 / PDF 155、158、165〕。
- **触发条件**：不良反复发生且靠人自检拦不住；异常发现慢、不良流到后工序；设备无人监视时产出次品。
- **操作步骤**：
  1. 自働化推进四步（按人与机器关系）：工序分析（算清多少工作由人/机器完成，绘产品程序流程图）→机械化（部分手工作业转机器）→自働化（全部交由机器，人可离开但无法检测不良）→自働化（机器自动检测差错，自动更正或停机，铃声/信号灯通知）〔p.138–139 / PDF 151–152〕。推进 4 条：分离人的工作和机器的工作→制定加工或品质的标准→发生异常机器自动停止→采取纠正措施防止再发生〔p.139–140 / PDF 152–153〕。
  2. 异常检测装置两类：接触式（限位开关和电眼，检查产品形状、尺寸与正常情况的差异）四种方式——定数式检测（需拧的螺丝少拧一个，压板就不能移动）、提醒式检测（刀片 15000 次报废、操作到 13000 次蜂鸣器响）、标准动作异常检测（规定作业动作出错时检测异常）、颜色的反射光线检测；记录式检测装置——把作业人员每个操作自动记录下来，漏操作自动发信号提醒补上（例：丰田车体焊接工序自动记录每台车体焊点数目，与规定数目不同时自动接通蜂鸣器报警）〔p.142–144 / PDF 155–157〕。
  3. 自働化停机两条路径：接触式自动停机装置（丰田装配线相邻工位交界处设停机踏板，作业人员超出作业区域接触即停线；工具挂上方轨道、越过定点接触停机开关装配线停下）＋人为停止生产线（每个工位设生产线停止开关；前道工序生产出不合格制品或全部作业不能按标准作业顺序执行时，作业人员有权也有责任按动）；共同要求：停机后现场管理人员和维修技术人员马上到达出事地点，和作业人员一起查清故障原因并采取改善措施〔p.144 / PDF 157〕。
  4. ANDON 系统：四类——请求零部件的传呼 ANDON、通知装配异常的异常 ANDON、显示机器设备运转的运转 ANDON、确认作业进度的进度 ANDON；系统构成＝触发器（按钮、绳子）＋信号灯/信号灯看板（注明生产线编号、人员姓名、电话号码）；丰田规定每位作业员发现异常都可触发，触发后整条生产线停下直到问题解决；主要功能四大方面——设备管理（设备运行管理、设备呼叫）、生产和统计（维修呼叫管理、生产运行信息、ANDON 上位管理、工位作业管理）、质量管理（质量呼叫、质量异常管理）、现场信息管理（物料呼叫、公共信息管理、广播系统、语音呼叫、信息可视管理）〔p.145–147 / PDF 158–160〕。集中生产状态报告体系（表9-8，光和声组合信号装置）：修理＝亮灯；停止＝亮灯和声音；工序切换＝亮灯和声音（正常灯表示切换中）；缺货＝亮灯和声音（零部件和产品箱供给指示）；呼叫＝亮灯和声音（正常灯表示呼叫事项处理中）〔p.152 / PDF 165〕。
  5. ANDON 工作流程：传感器探测故障自动点灯，或操作者拉吊绳/遥控激活→信息经工位信号灯、ANDON 看板、广播发布→班组长立即与操作者确定问题→能解决则重新拉绳恢复；不能解决经集中呼叫台呼叫现场负责人〔p.147 / PDF 160〕。定位停止三步：**停止、呼叫、等待**；管理人员评估——能在生产周期内解决则继续运转同时解决，不能则生产周期完成后停线；丰田实例：组装线分段中间 **7～10 分钟**缓冲，黄灯亮后 7～10 分钟解决不掉，红灯亮〔p.148–149 / PDF 161–162〕。
  6. 生产线级实施要点（某工厂实例，图9-5）：安全自働化 4 条（全员安全教育、作业标准化、彻底 6S、提高员工素质）；工具自働化 6 条（工具专用化、道具小设备自动化、确定位置、作业完回复原位、成组化、异常确定停止位置）；工序自働化 10 条（自动夹具→自动加工→自动输送→自动停止→自动复原位置→自动弹出→自动运送→自动测定→自动安装→自动启动）〔p.142–143 / PDF 155–156〕。简易自働化（LCIA）基本条件 5 条：异常时快速自动检查和停止、结构简单价钱便宜、无需专业技术人员即可配套购买、适合产品制造和组装、可自由移动和动作变更〔p.141 / PDF 154〕。
  7. 防错实施八步：明确防错对象→识别和描述（指派队员跟踪缺陷/红牌条件）→因果图定根本原因→确定改善目标（多方案）→比较评价定方案与计划→确定防错装置类型→创建装置并测试效果→标准化和日常管理〔图9-14，p.159 / PDF 172〕。
  8. 防错装置选型：识别（形状/颜色/标签/储存场所）、报警（微型开关/限制开关/计数器）、检出（治具的针/限位器/形状）、连动检出传递、自动检出；检测项目对应装置——压力（压敏开关）、温度（热电偶/温控开关）、电流（断路器/继电器）、振动（传感器）、循环（计数器）、时间（延时继电器）、信息（蜂鸣器/指示灯/闪光灯）〔p.157–158 / PDF 170–171〕。
- **量化口径与公式**：人为差错占错误总量 **77.8%**（人为差错五种：未执行职能/执行分外职能/错误执行/程序或时间错误/执行不全面）〔p.154 / PDF 167〕；提醒式检测阈值例：刀片 15000 次报废，操作到 **13000 次**时蜂鸣器响〔p.143 / PDF 156〕；ANDON 三色：绿＝正常，黄＝紧急问题需管理者在规定时间内处理完毕否则红灯亮，红＝严重问题已停线（具体时限数值语料未覆盖）〔p.145 / PDF 158〕；节拍控制例：生产节拍 3 分钟，3 分钟内没有生产出产品则红色信号灯亮起并发声〔p.150 / PDF 163〕；长生产线配色：绿底白字＝正常运行、黄底白字＝呼叫（有音乐）、红底白字＝停止（蜂鸣器）、白底黑字＝生产完成；停止理由栏：无工作、满量、异常、缺料、紧急停止、生产完成〔图9-8，p.147–148 / PDF 160–161〕；进度 ANDON 均匀分为**十等分**〔p.148 / PDF 161〕。
- **判读与决策**：黄灯→班组长到场；红灯→整条线该区段停止；作业人员发现异常"都有权也有责任"按停线开关〔p.144 / PDF 157〕；防错四要点——树立正确观念、正确安装（一定要适合原设备各项功能）、正确使用（培训操作者）、第 4 条展开内容（语料未覆盖）〔p.153–154 / PDF 166–167〕。
- **常见失败**：停在无检测的全自动阶段；防错工具安装不当造成作业障碍或危险；ANDON 变成摆设（触发后无人响应）；只报警不防再发生。
- **出处**：〔p.135–160 / PDF 148–173〕

### 3.9 工具9 均衡化 + 线平衡（步骤⑦·精益工具之九）

- **定义/目的**：均衡化＝总量均衡（每时段总产量波动最小）＋品种均衡（单位期间产品组合平均化），是 JIT 的必要条件、拉动式生产的前提；线平衡＝消除工序间能力不平衡造成的工时损失〔p.163、166、177 / PDF 176、179、190〕。
- **触发条件**：各工序忙闲不均、瓶颈卡产能；批量生产导致前工序负荷波动；准备混流/拉动之前。
- **操作步骤**：
  1. 渐进均衡化 7 步（图10-6）：①PQ 分析选择产品（种类少量大→均衡化；种类多量少差异大→按订单生产；中间→按库存平抑波动）→②分析近三年营销历史数据定基础均衡量（确立营销峰值点、测算平均销售量、确立连续波动概率）→③ABC 分类决定生产批量（以 10、100 的倍数等容易辨识的单位构成）→④制作均衡化计划周期表（A 类尽可能每天生产、B 类以周为单位每循环 3 日～1 周、C 类统筹安排）→⑤安排每天产品投入顺序计划（轮排图，可增设自由位补救延迟）→⑥突发情况更正（统计连续突发订单频率与极限产能，本周完成订单同时补充库存）→⑦异常情况跟踪（持续观察存货变化、大订单频率、生产过程稳定性）〔p.171–173 / PDF 184–186〕。算例：日需 1800 件，6 种产品按 50:15:15:6:2:2 轮排，最小批量每循环 200 个、一天 9 次循环，**生产节拍＝8×60×60 秒/1800＝16 秒**；圆盘分 9 等份（可划 10 格，最后一格自由位）〔p.173 / PDF 186〕。ABC 分档例：A 类占总产量 56%（合计 1000、日均 1000，以 500 为最小批量）、B 类 33%（合计 600，以 200 为最小批量）、C 类 11%（合计 200，以 40 为最小批量），保持每天 1800 件〔表10-7、10-8，p.172 / PDF 185〕。

  4. 工具：生产均衡柜（3 排 23 列空格，每列代表 20 分钟批量时间，8 小时 24 个 20 分钟其中 1 个为换班时间；推演规则——生产管理员从成品超市提货拿出盒里的看板，按标示产品放入对应格子，即安排好下一个 4 小时运货需要的生产计划；物料操作员每隔 20 分钟取出看板交给操作员照看板生产；成品超市盒标字段＝产品型号、盒子容量 30 件、超市储位、生产单元位置）〔p.174 / PDF 187〕。多周期化改善：小批量均衡计划中 70%～80% 的产量是小批量多周期化对象；把 1 周 1 个周期改为 1 日 4 周期（2 小时 1 个周期），生产准备次数增加到 20 倍——在汽车部件行业 2 小时 1 周期是非常快的时间〔p.175–176 / PDF 188–189〕。
- **量化口径与公式**（逐字照抄）：
  - 生产线平衡率＝实际作业所需时间总和/作业时间总和＝∑Ti/Ci×N（Ti—各作业资源加工时间；Ci—瓶颈工序单位产品产出时间；N—作业资源数总和）
  - 生产线平衡损失率＝（非加工时间总和）/作业时间总和＝∑LTi/（生产节拍×N）＝1−生产线平衡率
  - **判读基准：平衡损失率在 5%～15% 以内是可以接受的，否则就要进行改善**〔p.179 / PDF 192；OCR 作"5%15%"，区间符号丢失〔OCR 存疑〕〕
  - Pitch Time：决定生产线作业周期的工序时间是最长工序的时间〔p.177 / PDF 190〕
  - 五工序算例：循环时间 20/17/29/23/19 秒→瓶颈 C 工序 29 秒→线平衡率＝(20+17+29+23+19)/(5×29)×100%＝**74.48%**，损失率＝**25.52%**；正文另给损失 9/11/4/10 秒、损失率 **23.45%**——两套数字系原书正文与表格自相矛盾，均原样保留〔OCR 存疑〕〔p.178–179 / PDF 191–192〕

- **常见失败**：后道工序集中连续装配同一产品（前工序闲忙不均、靠库存硬扛）；只均衡总量不均衡品种；把均衡化理解为"平均主义"。

### 3.10 工具10 SMED 快速换线换模（步骤⑦·精益工具之十）

- **定义/目的**：SMED（Single Minute Exchange of Die，单个分钟换模，新乡重夫 1969 年提出）＝从卸下原有模具到换上下一个产品模具后上线制造直到完成良品为止的时间压缩到 10 分钟以下；目标递进：9 分 59 秒以内（十分钟内换模法）→59 秒→一触（onetouch）/一按键（1 分钟内）换模换线〔p.185、191–192 / PDF 198、204–205〕。机型切换四大内容：生产准备（切换用具/人员安排、前型号材料撤离、数据统计、现场整理、新型号技术资料工具）、材料切换（正确准备新材料、撤离前型号材料、彻底清线）、模夹切换（模具刀具导向夹具按产品形状尺寸结构切换）、标准切换（技术标准、工艺条件、作业程序随型号切换）；其中最主要的是模夹切换和标准切换〔图10-18，p.186–187 / PDF 199–200〕。
- **触发条件**：多品种小批量做不起来、换一次型停线过久、OEE 被切换吃掉时；均衡化第 3 前提"实施快速换线"未达成时〔图10-4，p.169 / PDF 182〕。
- **操作步骤**（6 步，图10-20）：①成立快速换线换模小组→②换线换模作业分析（VTR 录像跟踪，用换模分析对策表、换线换模实绩表找耗时多的作业）→③内外作业分离和消除无用作业（检查表、功能检查、改进部件和工具运输）→④将内作业转化为外作业（预先准备、操作条件、功能标准化、部件集成化；示例：要彻底研究目前"内换模"作业的机能与目的，考察可否转换成"外换模"）→⑤缩短内作业时间（并行操作、功能性夹具、消除调整作业、功能标准化、IE 手法；示例：特制滚动导轨导销以免除对中找正、特殊螺栓、模具快夹装置快速固定）→⑥缩短外作业时间（彻底 3S、改进储存管理、作业标准书、教育训练；示例：常用工具靠近设备、排除寻找物料、不使用螺钉紧固）〔p.190–191 / PDF 203–204〕。
  - 换模改善基本步骤（8 步，图10-21）：换模准备→停机，卸下及搬出生产完成的模具→搬入下批生产模具至模盘内→决定位置锁上模具→交换材料→试加工调整→试产品质合格进行量产→善后〔p.191 / PDF 204〕。
  - "五个零"实施步骤（10 条）：设定目标（最低在一个节拍以内完成）→VTR 定点摄影→集合改革小组→零步行（录像至少看 5 次）→零换模换线作业（把问题变成准备和后整理作业）→零螺栓→零直列排列作业（一个人并列作业）→零调整（将一切调整作业识别出来）→制定改革计划→实践、评价和推广〔图10-22，p.192 / PDF 205〕。
  - 九大技巧要点：排除准备浪费（模具放置场所位置管理、模具台/专用车事先备妥放在机器旁、常用工具/作业标准单/加工条件表事先备妥、事前做好机能确认）；事前充分准备（简单切换由作业者做、关键复杂切换由专业人员或班组长做，"手动脚勿动"）；**不要变动标准**（硬件切换完成后的调整时间占整个切换时间的 **50%～70%**；用样板、块规、限位块代替刻度或仪表读数）；并行作业（一人改两人同时共同进行，最好先制作步骤表）；标准化（机能性标准化只标准化换模需要的部位，方法"决定尺寸位置→定心→锁紧→抓取"；冲床模高定数化实例：A 型模高 240mm 加 40mm 套合治具统一为 280mm 与 B 型一致，换型不需调整定位高度）；辅助工具板预装模具瞬间卡嵌；尽量不用螺栓（插销、压杆、中介夹具、卡夹式插座、定位板、燕尾槽、轴式凸轮锁定等一次锁紧方式）；快速螺栓/快速夹具（气压液压一次同时锁紧几个点）；排除调整作业〔p.193–196 / PDF 206–209〕。
  - 排除调整三法（表10-17）：①数值设定的定量化——目视读刻度约 0.5mm 精度，更高精度用计量表（dialgauge）、量规（gauge）、规矩块；②虚幻的中心线与基准线的显在化——用 V 座与圆筒形基准座使桌面原点虚拟基准线显现，一次完成定心；③最小公倍数系统——数种作业条件时选具备最小公倍数机构，只切换机能（如限制开关按产品种类设定部位）〔p.196 / PDF 209〕。
  - 切换作业改善重点三面（表10-15）：外作业——场所整理整顿（不寻找/不移动/不乱用）、工装夹具点检、附属设备事前准备、计测器具准备、模具预热、成套安装、统一顺序方法、排除重做（返工）、人员有效合作；内作业——安装容易化、紧固方法与减少紧固器具、模具工装夹具形状机构研讨、共通化互换性、排除调整、工装夹具与设备精度、基准面、计测方法简易化标准化数值化；作业面——并行作业、简化作业、基本作业彻底、保证外作业彻底、不浪费时间〔表10-15，p.189 / PDF 202；OCR 存疑：三列归属按语义复原〕。
- **量化口径与公式**：提高切换效率＝减少切换次数（减少大切换、避免二次切换）＋缩短每次切换时间〔图10-19，p.188 / PDF 201〕；丰田 1000 吨压床：4 小时→6 个月改善至 1.5 小时→再 3 个月降至 **3 分钟内**〔p.185 / PDF 198〕；目视读刻度精度仅约 0.5mm，更高精度用规矩块（Blockgage）〔p.196 / PDF 209〕；切换作业分析表例：切换时间 38 分 35 秒中"去取清单 2 分 30 秒→专用台车、去取工具 1 分 20 秒→专用工具车、合计 22 分 20 秒→作业外部化"〔表10-14，p.189 / PDF 202〕。
- **判读与决策**：先用切换作业记录表逐次记录实绩（例：产品 1→产品 2 28 分 20 秒、2→3 35 分 15 秒、3→4 32 分 35 秒〔表10-13，p.188 / PDF 201〕），再逐条分内/外部作业；示范机组先行，达标后推广到其他机种。
- **常见失败**：不录像凭印象分析；未分离内外作业就拼命加快手上动作；切换后大量调整（违背"不要变动标准"）；螺栓依赖（滑丝、装卸费时）。
- **出处**：〔p.185–199 / PDF 198–212〕

### 3.11 工具11 看板 + 看板数量计算（步骤⑧·精益工具之十一）

- **定义/目的**：看板＝传递信号控制生产的工具（卡片、容器、方格标识、信号灯、彩色乒乓球等形式）；看板管理＝利用看板在各工序、车间、工厂及协作厂之间传送作业命令，保证在必需时间制造必需数量的必需产品；看板数量＝某种零部件的最大存有量〔p.203、207 / PDF 216、220〕。

- **操作步骤**（实施六大步骤，图11-8）：①收集数据（**必须是现状真实数据，绝不能用对未来的期望值代替**；用价值流分析确定看板样板流程）→②计算看板数量→③制定看板运行规则→④全面培训（晨会/专题研讨会、看板情景说明书和作业指导书、实战演练"手把手"——先示范给员工看，然后让员工学着做，最后熟练做）→⑤实施看板管理→⑥持续改善（在拥有较小在制品库存时取出一些看板，出现其他问题由员工协调自主解决；采用更新设备、变更加工顺序、缩短生产提前期等措施仍保证正常生产）〔p.213、222–226 / PDF 226、235–239〕。
  - 八项前提（缺一慎行）：生产的均衡化、缩短更换作业程序时间、后道工序领取方式、不合格产品接近零、机械设备故障无限接近零、全面实施整理整顿（看板方式的起点就是整理整顿）、全面推行人的意识教育、坚持现场问题改善活动〔表11-4，p.205–206 / PDF 218–219〕。

  - 可用切换时间＝可用工作时间−生产需求时间〔式(11-7)〕

### 3.12 工具12 TQM / QC 七大方法 / 6σ（步骤⑨）

- **定义/目的**：TQM＝由顾客需要和期望驱动的管理哲学，以质量为中心、全员参与，长期获得顾客满意；QC 七大方法（日本质量管理学者 1965 年提出）解决现场质量问题；6σ（某通信企业 80 年代创立）＝在提高顾客满意程度的同时降低经营成本的过程革新方法〔p.229、233、235 / PDF 242、246、248〕。
- **触发条件**：步骤④–⑧完成、生产系统趋于稳定后进入品质深化阶段；不良率反复、需要系统化改善机制时。
- **操作步骤**：
  1. TQM 落地框架：三全理念（全面质量/全过程/全员参与）＋四个第一（质量第一/用户第一——"下道工序就是用户"/适用性第一——"避免无限地无偿地超越客户的需求"/长远利益第一）＋四种观点（预防为主/数据说话/**第一次就做对**/最经济原则）＋四个保证（PDCA/QCC/标准化/质量培训）〔表12-1，p.231–232 / PDF 244–245〕。
  2. QC 七法按问题选型（表12-2，定义与应用要点照抄）：
    - 检查表（查检表/点检表）：现场最容易取得有效数据的表格；可用于自主检查（5S 检查表、内部审核表），也可建立标准表格文件（QC 检验记录表、机器保养记录表）。实例：A12 引擎检查表（不良项目：点火角度不良、启动不良、汽门异音等）。
    - 分层法（层别法/分类法/分组法）：按影响质量的不同因素或特点对数据分类找真因；必须和因果图、排列图、直方图等结合应用；分层数据不能过于分散。实例：某厂 5 月 12 日成品抽验不良按时间 8:00/9:00/10:00 分层（小计 29、39、25）。
    - 排列图（柏拉图/重点分析图/ABC 图）：按分类项目占总体比例大小顺序排列并绘累积值；**找到改善重点，针对占 80% 的重点项目采取对策**；效果确认时作改进前后比较。
    - 因果图（鱼骨图/特性要因图）：把可能要因列为次主题再次讨论分析出原因，直至因果关系完全掌握；与查检表、排列图、直方图配合得双重效果；可应用于 5W（OCR 印作"5W（即连问次为什么）"〔OCR 存疑〕，疑为"连问五次为什么"）的源流管理。实例："机加工研磨工时高"按砂轮/人为/设备/方法四类展开要因。
    - 散布图（相关图）：纵轴结果、横轴原因，按点的分布形态判断两变量相互关系；有异常点出现时立即寻找原因而不能人为忽略；作业人员、方法、材料、设备、环境变化时须鉴别数据获得条件。实例：电视机画面质量 vs 使用年限，N=50，X=36.64，S-8.52〔OCR 存疑：按统计惯例应为标准差 s=8.52，照录〕。
    - 直方图：用一定范围在横轴分相等区间、柱形画出测定值出现次数；用于测算过程能力、计算不良率、检测分布形态、制定规格界限。实例：零件尺寸×0.01mm，横轴 73.97–74.03。
    - 管制图（控制图/休哈特图）：用统计方法设置合理控制界线，决定某过程何时需要调整、何时保持原有状态；用于质量诊断（评估过程是否受控）、质量控制、质量改进。实例：溢出量控制图 UCL=45.69，CL=29.86，LCL=14.03；另一图 UCL=58.04，CL=27.44。
    〔表12-2，p.233–234 / PDF 246–247〕
  3. 6σ DMAIC：D 界定（选项目按"有意义的、可管理的、可测量的"；工具：头脑风暴法、亲和图、系统图、流程图、因果图、SIPOC 图、质量成本分析）→M 测量（收集数据→整理数据选评价指标 DPU/DPMO/RTY/过程能力指数，整理方法：排列图、直方图、散布图、过程能力分析、失效模式分析、分层法、调查表、因果图、抽样检验、水平对比法、折线图→验证测量系统确保数据准确可靠）→A 分析（头脑风暴＋因果图梳理分层；常用排列图、散布图、FMEA 确定关键原因；因果图散布图验证结果）→I 改进（提出 PDCA 设想、设定改进目标；方案评价选优；实施时找出关键路径严加控制）→C 控制（改进后过程标准化，用有效检测方法保持成果；文件化、标准化、过程管理及监控；成果报告、项目移交）〔表12-4，p.237–238 / PDF 250–251〕。底层逻辑：确定关键产品质量特性（关键输出变量 y，结果变量/响应变量），测量后寻找关键过程特性（关键输入变量 x，原因变量/自变量），"建立 y 与 x 的函数关系：y=f(x)，通过改善 x 值使 y 得到优化，然后将统计解决方案转化为现实方案"〔OCR 存疑：OCR 印作"y-f（x)"，按上下文修正〕〔p.236–237 / PDF 249–250〕。
- **量化口径与公式**：QC 七大方法"就可以解决 **95%** 的现场质量问题"〔p.233 / PDF 246〕；σ 水平＝规格界限内所包含的 2σ（±σ）的个数；过程平均值与目标值的偏移"平均为 ±1.5σ"；缺陷率表（×10⁻⁴×100%，指数存疑照录；按 ×10⁻⁶ 解读与通行 ppm 值吻合）：σ1 无偏移 317400/偏移 697700；σ2 45400/308733；σ3 2700/66803；σ4 63/6210；σ5 0.57/233；**σ6 0.002/3.4**〔表12-3，p.235 / PDF 248〕。
- **判读与决策**：现场问题先用 QC 七法（成本低见效快），系统性跨流程问题才上 6σ DMAIC；管制图判稳后才能谈标准作业固化。
- **常见失败**：事后把关代替事前预防；无限超越客户需求（质量成本失控）；散布图人为忽略异常点；6σ 只做统计不做"统计解决方案转化为现实方案"。
- **出处**：〔p.229–238 / PDF 242–251〕

### 3.13 工具13 标准作业（步骤⑩·精益工具之十三）

- **定义/目的**：将生产产品的顺序和应遵守的规则规定下来；以人为中心、以没有浪费的操作顺序生产，达到低成本安全地产出良品；"没有标准，便无法区分正常还是异常"；"没有标准化就没有改善，改善的第一步就在于标准化"〔p.239、242 / PDF 252、255〕。种类：按作用对象分程序标准（规范工作方法的标准：作业指导书、工作程序、工序设定、设备管理、管理制度）与规范标准（规定工作成果的标准：图纸规范、产品规格、标准工时、成本预算、管理制度）〔图13-1，p.241 / PDF 254〕。三要素＝节拍时间＋标准作业顺序＋在制品的标准持有量，共同目标＝"用最小限度的作业人员和在制品数量进行所有工序之间的同步生产"〔图13-2，p.243 / PDF 256〕。
- **触发条件**：前九步稳定运行后固化成果时；作业因人而异、异常无法定义时。前提 6 条：作业先达稳定状态（否则"即使暂时标准化了，实际也不会有效执行"）、建设流水生产线、培训多能工、以人的动作为中心、推进平均化生产、作业可不断重复〔p.242 / PDF 255〕。
- **操作步骤**：
  1. 制定 4 步：识别工作步骤（先暴露大浪费，不必关注细节）→记录各步骤花费的时间（工作时间与移动时间分开统计；例：工作时间 31 s、移动时间 26 s）→绘制现场图（工作步骤用折线连接帮助发现浪费；原路返回多则重布现场）→制定标准〔p.248–250 / PDF 261–263〕。
  2. 文件编制顺序：确定循环时间→编制要素山积表→创建标准作业组合→制作标准作业卡→制作标准作业要领书〔p.250 / PDF 263〕。组合表编制 4 条：按工艺要求写实确定作业内容与顺序→对各要素作业测时计入现场测时记录表→填写纯作业时间与走动时间并累加→时间轴上红线垂直画出循环时间位置（每格 1 秒或按实际确定）〔p.253–254 / PDF 266–267〕。要素山积表：摄像记录+秒表测定，深色=走动、斜剖面线=准备、浅色=纯作业，纯作业放最底层以最大限度压缩走动和准备时间〔p.250–251 / PDF 263–264〕。
  3. 三种类型对表（表13-3）：单个品种一个流动生产（机械加工、注塑、冲压、焊接、定量搬运作业；判据：循环时间=节拍时间；表格：工位能力表、标准作业组合表、标准作业卡、要素作业卡）；多品种成组生产（总装、涂技〔OCR 存疑：疑为"涂装"之误，照录〕、焊接、机械装配；判据：循环时间的加权平均=生产节拍；表格：标准作业组合表、工序管理板、作业顺序表、要素作业连接表）；大批量生产（刀具更换、质量检查、换模、搬运等非重复性作业，节拍不能计算；判据：总时间=生产节拍；表格：作业原单位表、山积表）〔p.248 / PDF 261〕。
  4. 七种作业标准书载体（表13-2）：作业指导书（在标准作业卡基础上细化操作要点：作业顺序、周期时间、作业内容、安全品质要点、检验方法、人员走动顺序、在制品存放位置、设备整体布局）；作业要领书（对象是每个工序：机械操作、刀具更换、程序步骤、零件加工、组装的作业顺序）；标准作业卡（标准作业票）（记入节拍时间、标准作业顺序和标准在制品三要素＋质量确认、安全注意；是组长班长检查各作业人员遵守标准作业的检查依据）；工位能力表（按被加工零件记录各设备生产能力，含检查作业、手工作业；字段：周期时间、换模时间、工作名称、作业顺序、产能）；标准作业组合表（记入设备布局、反应时间、生产节拍、作业顺序、作业内容、作业时间、标准待工）；要素山积表（在目视板上搭积木方式拆解重排）；标准手持量（操作者需要哪些工具设备、同时处理多少被加工物）〔p.247 / PDF 260〕。图例约定（标准作业组合表，图13-11）：①水平直线＝纯作业时间；②斜向连接两个动作节点的波浪线＝走动时间；③虚线＝机器自动运行时间；④波浪线斜向上＝作业终止回到起始位置的走动时间〔p.253 / PDF 266〕。
  5. 运转维持：标准作业表必须注明制表/修改日期（"修改日期"长期不变→上级可断定现场没尽全力改善）；每月一次按检查表（12 项：岗位是否有作业标准书、标准书是否有作业重点要点规格注意事项认可印章、内容上是否画有重点符号、是否是作业人员自己制定的、是否有整理编号和制定时间、作业人员是否知道标准作业要点、作业前是否经常翻阅、位置固定是否合适、是否按照标准书操作、修订是否根据实际需要等）检查确认；训练与巡查同步——操作要领备忘录（标准作业顺序中各项作业重点）＋操作指导备忘录（各生产线加工单元操作细节和产品质量检验）〔p.257–259 / PDF 270–272〕。
- **量化口径与公式**（逐字照抄）：
  - 实际工作时间=（计划作业时间-计划作业外的时间）×工作率；算例：362 分=（8 小时×60 分-0.9 小时×60 分）×0.85〔p.243 / PDF 256〕
  - 生产数量=顾客需求数量÷（1−产品不合格率）；算例：309 个=300 个÷（1-0.03）〔OCR 存疑：OCR 把运算符印作"-"，按数值 300/0.97≈309 判断应为"÷"〕〔p.243 / PDF 256〕
  - 节拍时间=实际 1 天可工作时间÷1 天的生产数量；算例：70 秒=362 分×60 秒÷309 个〔OCR 存疑：同上〕〔p.243–244 / PDF 256–257〕
  - 作业人力=总周期时间/节拍时间；本例安排 3 个作业员（分别完成第 1、2～3、4～5 工站）〔p.252 / PDF 265〕
  - 单个产品总周期时间=产品工序中所有工站的周期时间的加和（含人工时间与机器时间）〔p.252 / PDF 265〕
- **判读与决策**：节拍 70 秒→"每 70 秒钟看到 1 件产品生产出来。如果每 2 分钟移走 1 件产品，就会知道下游出了问题，就必须快速采取对策"〔p.244 / PDF 257〕；标准持有量"以保证操作工艺为原则，同时要尽量少"〔p.252 / PDF 265〕；用"观察标准作业表→现场现物找异常→改善→修订标准书→自主检查→反馈"循环持续修订〔图13-13，p.256 / PDF 269〕。
- **常见失败**：作业未稳定就标准化（无效执行）；只制定不训练、只训练不巡查（"标准化作业实施成功的关键是有效的训练和巡查"）；要求员工机械遵守标准而不主动改善；修改日期长期不变。
- **出处**：〔p.239–259 / PDF 252–272〕

## 5. 打法组合拳：步骤④–⑩ 推行时序

推行主线：**先基础管理 → 流线化 → 自働化 → 均衡化 → 拉动 → 品质 → 标准作业**。每步完成判据与进入下一步的前置条件如下（依据各章原文）。

### 步骤④ 基础管理（工具1–5）
- **主用工具**：目视管理（让状态看得见）→6S（12 步标准化推进，样板区 7～30 天见效）→IE（程序分析/联合作业分析/动作分析/标准时间）→TPM（12 步三阶段，自主保全+专业保全）→VSM（六步法，改进全过程）。
- **顺序逻辑**：6S 是其他精益项目的前提；目视管理提供信息流基础；IE 供给标准工时与浪费显性化；TPM 把设备故障压向零；VSM 找全过程改善点并为步骤⑧"判断哪个流程最适合实施看板"预作准备〔p.69、86、105、213 / PDF 082、099、118、226〕。
- **产出物**：划线/标识规范、6S 检查评分表与四级检查记录、红牌与整改清单、标准时间与工时运用效率三指标台账、TPM 管理体系手册+程序文件+考评表、OPL 单点课库、现状/未来价值流图+行动计划。
- **完成判据**：6S 每月至少两次考核、四级检查体系运行；IE 产出标准时间与工时运用效率三指标（有效运转率/切换率/切换效率）；TPM 考评表（设备故障率低于 2% 等）周评月评；VSM 现状图+未来图+行动计划完成，季度审核机制建立。
- **进入⑤的前置条件**：现场基准（划线/标识/清扫）稳定、设备故障受控、标准时间可用。

### 步骤⑤ 流线化生产（工具6–7）
- **主用工具**：一个流 12 步推行（示范线先行，KPI＝LeadTime、WIP、人均产能、良率、损失工时）；少人化（U 形布置+多能工+作业标准常修）。
- **顺序逻辑**：机群式→直线→U 形三级演进；一个流八大条件中"按节拍同步""U 形化""多能工"直接为少人化铺垫。
- **产出物**：示范线改善报告（生产流程图、布置方式、稼动率、瓶颈、制程时间调查）、节拍与设备/人员数量计算表、U 形布置图、多能工训练记录、控制图长期推移记录。
- **完成判据**：示范线按节拍单件流动、在制品接近零；作业员制程人力时间总和与生产节拍一致；多能工可轮岗。
- **进入⑥的前置条件**：生产线已按产品为中心的"单元式"布置，加工一件移动一件基本实现。

### 步骤⑥ 自働化与防错（工具8）
- **主用工具**：自働化四步（工序分析→机械化→自働化→带检测自働化）；异常检测/停机/报警三技术；ANDON 四类+定位停止；防错八步。
- **顺序逻辑**：先分离人的工作和机器的工作，再给机器装上"检测—停机—报警"的智能；ANDON 与定位停止让异常即时暴露。
- **产出物**：产品程序流程图（人/机器工作百分比）、检测与停机装置清单、ANDON 看板与信号规则、定位停止规则、防错装置台账与测试记录。
- **完成判据**：异常时作业人员都能控制生产线停止与重新起动；机器自动检测并停机；防错装置经八步验证有效并纳入日常管理。
- **进入⑦的前置条件**：不良不流向后工序（这是步骤⑧看板前提 4"不合格产品接近零"的来源）；设备异常停机受控（对应看板前提 5）。

### 步骤⑦ 均衡化生产（工具9–10）
- **主用工具**：渐进均衡化 7 步（PQ 分析→历史数据→ABC 批量→周期表→轮排图→突发更正→异常跟踪）；线平衡 7 步+改善六法；SMED 6 步+九大技巧+五个零。
- **顺序逻辑**：均衡化是 JIT 的必要条件、拉动式生产的前提；而混流的前提是快速换模（前提 3"专业设备通用化"、前提 4"实施快速换线"）——所以线平衡与 SMED 必须在均衡化阶段一并完成。
- **产出物**：P/Q 分析图、ABC 分类与均衡化计划周期表、轮排图（含自由位）、生产均衡柜与看板插口设计、线平衡棒形图与平衡率/损失率计算表、切换作业记录表与切换作业分析表、换模标准单。
- **完成判据**：总量与品种双均衡（每天各品种按比例轮番生产）；平衡损失率进入 5%～15% 可接受区间；换模时间进入分钟级（十分钟内换模→59 秒→一按键）。
- **进入⑧的前置条件**：均衡化+快速换模+后工序领取方式+品质稳定+整理整顿——即看板八项前提中至少前五项已达成（**没有这些前提直接导入看板将注定失败**）。

### 步骤⑧ 拉动式生产与看板（工具11）
- **主用工具**：实施拉动看板六步骤（收集数据→计算看板数量→制定运行规则→全面培训→实施→持续改善）；看板六原则；式(11-1)～(11-13)。
- **产出物**：数据汇总记录表（须真实、有区分度）、看板计算五表（收集数据表→可用切换时间→生产批量→缓冲库存量→看板计算表）、各类看板版面（工序内/工序间/信号/外协/特快/临时）、看板运行规则任务分解表（含完成日期）、看板情景说明书与作业指导书。
- **完成判据**：看板运行规则（信号含义、看板移动控制人、生产进度控制人、问题解决人、目视管理）成文并作为任务分解到人；每月/每周按真实数据重算看板数；看板数持续递减。
- **进入⑨的前置条件**：拉动系统稳定（异常按黄/红信号受控）、库存按"最大库存量＝缓冲库存量＋生产批量"受控。

### 步骤⑨ 品质管理（工具12）
- **主用工具**：TQM 四个保证（PDCA/QCC/标准化/质量培训）；QC 七大方法（95% 现场问题）；6σ DMAIC（跨流程系统问题）。
- **产出物**：QC 检验记录表、排列图与因果图档案、管制图（UCL/CL/LCL）与判异记录、QCC 活动记录、6σ 项目 SIPOC 图与 DPMO/RTY 指标、过程能力分析。
- **完成判据**：预防为主+数据说话成为机制（检查表/管制图日常运行）；QCC 小组活跃；关键过程能力水平明确（σ 水平可测算）。
- **进入⑩的前置条件**：质量稳定后才能"以稳定的生产制度固化标准"——标准作业前提 1"作业本身要先达到稳定状态"。

### 步骤⑩ 标准作业（工具13）
- **主用工具**：标准作业三要素+四步制定；要素山积表→组合表→作业卡→要领书；作业标准实施情况检查表（每月一次）；"修改日期"判据。
- **产出物**：作业时间统计表、现场图、标准作业工站表、工位能力表、标准作业组合表、标准作业卡、标准作业要领书、作业标准实施情况检查表（每月）、操作要领/指导备忘录。
- **完成判据**：三条线（节拍时间/标准作业顺序/标准持有量）成文；组合表红线标出循环时间；作业人力=总周期时间/节拍时间核算通过；每月检查+训练巡查闭环，标准书"修改日期"经常更新。
- **收束**：回到观察→改善→修订标准的循环，把标准化变成发现问题、激发改善的手段，形成步骤④–⑩的闭环。

## 7. 反例清单

| 错误做法 | 后果 | 正确做法 | 出处 |
|---|---|---|---|
| 没有看板八项前提（均衡化、快速换模、后工序领取、不良接近零、故障接近零、整理整顿、意识教育、现场改善）就导入看板 | **注定失败** | 先完成步骤④–⑦再上拉式看板 | 〔p.205 / PDF 218〕 |
| 车间之间信息孤岛，各自按原计划生产 | 大量库存且间断生产 | 绘 VSM 暴露问题，按 7 问改进物流和信息流 | 〔p.106、112 / PDF 119、125〕 |

| 某段时间集中大量领取某一种零部件 | 前工序负荷波动 | 各工序在时间、品种、数量上均匀领取 | 〔p.207 / PDF 220〕 |
| 作业未稳定就标准化 | 暂时标准化也不会有效执行 | 先消除不稳定根源（质量问题/设备夹具/缺料/等待/安全） | 〔p.242 / PDF 255〕 |

| 样板区不具代表性/高层不认同/长期才见效 | 全面推行受重大影响 | 代表性部门+高层认同+强意识责任人+7～30 天见效 | 〔p.80–81 / PDF 093–094〕 |

| 散布图人为忽略异常点 | 图不能真实反映变量关系 | 找出异常原因前不得剔除；数据条件变化须鉴别 | 〔p.234 / PDF 247〕 |
