## 2. 概念地基

**一句话定位**：SCM＝围绕核心企业，对信息流/物流/资金流控制，从采购原材料到最终用户的整体功能网链，**不仅是物流链、信息链、资金链，还是一条增值链**〔出处：1.供应链管理〕。核心方针转变：从**推动型市场结构（厂商主导、用库存弥补变动、部分最优）**转向**拉动型市场结构（顾客主导、整体最优）**——"部分最优凑集在一起就产生浪费"〔出处：1.供应链管理〕。

| 概念 | 判据（怎么算它是它） | 易混淆点 / 什么不是它 |
|---|---|---|
| 宏观供应链 | 围绕核心企业，把供应商—制造商—分销商—零售商—最终用户连成功能网链 | ≠ 单个工厂内部流程 |
| 企业内部供应链 | 含信息流在内、从原材料到最终用户的商品流通和递送的所有活动（含采购、生产计划、订单加工、库存、运输、仓储、客服） | ≠ 只管仓库 |
| SCM | 通过完善供应链联系把**所有活动整合**的过程，以取得稳定竞争优势 | ≠ 只做物流外包 |
| 物料管理 5R | 适时(Right Time)、适质(Quality)、适量(Quantity)、适价(Price)、适地(Place) | 五者要同时满足，缺一不可 |
| 物料管理精髓 3 不 | 不断料、不呆料、不囤料 | 只盯"不断料"会走向"囤料" |
| 常备性物料 | 长期需用或能通用，通常保库存、采用**存量计划采购** | 不等于高库存 |
| 专用性（批次生产）物料 | 必须有订单才购买，**通常不保库存** | 误当常备料会呆滞 |
| 订货型生产(MTO) | 按用户订单生产，标准化低、效率低、提前期长、库存低、个性化高（如船舶、大型锅炉） | 与备货型对比 |
| 备货型生产(MTS) | 按已有标准产品生产，目的是补库存（如家电、标准件、汽车） | 提前期短、库存高 |
| 面向订单装配(ATO) | 最后阶段用库存通用件装配满足订单，通用件在订货前已备好 | 适合有诸多可选特征、客户不愿等备料的场景 |
| 代表产品 | 结构与工艺相似的多品种中，**产量与劳动量乘积最大**的产品 | 用于成批生产的能力计量 |
| 假定产品 | 结构与工艺差异大的多品种，设统一计量单位 | 用于多品种生产的能力计量 |

## 3. 方法/工具逐项展开

### 3.1 SCM 三大构成要素与内部核心流程

- **定义/目的**：明确供应链由哪几块构成，以及企业内部流程如何与供应链衔接。
- **触发条件**：要梳理供应链职能、划分职责、找协同断点时。
- **操作步骤**：
 - **三大构成要素**（外加一个 REVERSE）：**需求**（客户关系管理/订单管理）+ **计划**（计划与控制/信息交互）+ **物流执行**（仓储/生产/分销/运输）+ **供应**（供应商开发/管理评估）+ **REVERSE**（退货/废弃物/容器返空）。目的：**用户服务水平** 与 **运作成本**。
 - **企业内部供应链核心流程**：开发 → 采购 → 生产 → 物流 → 销售 → 消费，贯穿信息流/物流/资金流；核心内容＝同步采购、供应商早期介入、同步开发与供货、CRM。
- **量化口径**：跨部门协作不良典型症状——过量库存、缺货、计划性差、周期长、需求多变、生产柔性差、客户满意度低、预测不准、物流不畅、积压。
- **判读与决策**：出现"过量库存+缺货"并存 → 属跨部门协作问题，先建内部客户服务与过程评审机制。
- **常见错误/反例**：各部门各管一段、考虑自身利益、缺沟通主动性、程序不完善——"任何部门要有所作为离不开跨部门协作"。
- **出处**：〔出处：1.供应链管理〕

### 3.2 MRP/ERP 通用逻辑 + BOM 六字分层 + 物料编码唯一性

- **定义/目的**：让 ERP/MRP 能正确跑出需求——核心是主生产计划、BOM、库存记录三条数据链正确。
- **触发条件**：ERP 上线/运行出问题、需求跑不准、扣料出错、装配出错时。
- **操作步骤（MRP 五问五答）**：
 1. 要生产什么？→ 主生产计划（MPS）
 2. 要用到什么？→ 物料清单（BOM）
 3. 已经有了什么？→ 库存记录
 4. 还缺什么？→ 物料需求计划（MRP）
 5. 什么时候下达计划？→ 采购计划
- **量化口径（BOM 六字分层原则）**：决定该半成品是否单独分层做 BOM——
 - **产**：是否单独下发生产任务（要下发→分层；中途不入库可简化）
 - **供**：半成品是否直接采购（会直接采购→分层）
 - **销**：半成品是否直接销售（会直接销售→分层）
 - **存**：是否需入库（入库后再领出→分层；直接转下工序→不分层）
 - **虚**：是否用虚拟件（工艺复杂、共用件频繁、图纸原因→用虚拟件）
 - **委**：是否委外（启用车间管理→做工序外协简化分层；不启用→委外处单独分层）
 - **BOM 准确率要达到 98% 以上**；**BOM 应尽量扁平化**——每增加一层 BOM，将增加操作员一倍的工作量；复杂工艺应由**工艺路线**解决而非塞进 BOM。
 - **物料编码唯一性**：每项物料均有唯一物料代码；由**开发部（技术/工程部）主导**编码规则，仓库/采购/生产部门只是使用部门、不能编写编码规则。
- **判读与决策**：ERP 上线难往往是 BOM（产品数据库）不完善；出现扣料差异 → 查 BOM 准确率、编码唯一性、发料与 BOM 扣料是否一致。
- **常见错误/反例**：把工艺加工过程都展开进 BOM（编制使用极复杂）；BOM/编码不唯一或设计部门不及时更新（扣料出错、装配出错、库存增加、交期无法保证）；首次导入 ERP 不做初始教育就选软件——**"始于培训，终于培训，始终培训"**。
- **出处**：〔出处：2.企业资源计划；1.供应链管理〕

### 3.3 生产计划体系（长/中/短期三层）与编制步骤

- **定义/目的**：把战略到车间作业串成一条计划链。
- **触发条件**：要建计划体系、理清各层计划的对应关系时。
- **操作步骤**：
 - **三层体系**：**长期计划**（战略：生产、技术、财务等重大问题规划）→ **中期计划**（生产计划大纲 + 主生产计划 MPS）→ **短期计划**（物料需求计划 MRP + 生产能力需求计划 + 车间作业计划）。
 - **生产计划编制步骤**：①需求预测 ②编制生产计划大纲 ③编制主生产计划 MPS ④粗能力计划 RCCP ⑤MRP 展开物料需求 ⑥能力需求计划 CRP ⑦车间作业计划。
- **量化口径**：
 - 生产计划主要指标：产品品种、产品质量、产品产量、产品产值。
 - 处理非均匀需求的 4 策略：①改变库存水平 ②改变生产率 ③改变工人数量 ④重市场调查与预测开拓新市场。
- **判读与决策**：能力不足→扩大生产能力；能力过剩→利用生产能力。
- **常见错误/反例**：主生产计划与生产作业计划不同步；销售合同签订—技术设计—生产计划下达—采购—入库业务不同步导致缺料或积压。
- **出处**：〔出处：3.生产能力规划〕

### 3.4 MPS 编制 + MRP 展开逻辑 + CRP

- **定义/目的**：MPS 是对生产计划大纲的细化，是展开 MRP 与 CRP 运算的主要依据，起承上启下作用。
- **触发条件**：要把产品出产进度落到周、展开到物料与产能时。
- **操作步骤**：
 - **MPS 编制步骤**：①需求信息准备 ②制定产品出产进度计划草案 ③检查生产能力能否满足需要。
 - **MRP 逻辑处理**：对 MPS、库存文件、BOM 操作，按反工艺顺序倒推，计算每层物料需要量，按提前期推计划投入量（下达订单），直到所有层次算完。
- **量化口径**：
 - MPS 编制注意：现有库存能满足的部分不列入计划；选适当批量与间隔期保证经济性；检查负荷是否急剧波动超/低实有能力；需求笼统的要具体化为品种/型号/规格。
 - MPS 计划时区**不应大于周**；一般以 12 个月为展望期，每过一月增一新计划。
 - **冻结（相对稳定化）**：不同生产类型有 MTS/ATO/MTO 变型。
 - 约束：MPS 生产总量必须等于生产计划大纲确定的总量。
- **判读与决策**：CRP 后能力不够 → 调能力；能力还能调整 → 调整；不能 → 修正 MPS。
- **常见错误/反例**：MPS 时区过大导致低层物料优先级混乱。
- **出处**：〔出处：3.生产能力规划〕

### 3.5 生产能力计算与规划

- **定义/目的**：确定设备、工具、设施、总体劳动力规模形成的综合能力，平衡投资与机会成本。
- **触发条件**：决定扩产/减产、找瓶颈、编产能计划时。
- **操作步骤**：
 1. 需求预测（定性：部门主管集体讨论法、德尔菲法、用户意见征集法；定量：移动平均、指数平滑、季节系数、回归）。
 2. 产能测算（见下公式）。
 3. 负荷平衡：能力不足→扩大生产能力；能力过剩→利用生产能力。
 4. 瓶颈对策：增大瓶颈工序能力（加班、租用设备、转包）；瓶颈前留缓冲库存；依赖前工序的部门重复设置前一部门设备。
- **量化口径**：
 - 单台设备能力 `m ＝ Fe / ti`（Fe＝单台有效工时，ti＝单件工时）
 - 设备组能力 `M ＝ S·m ＝ S·Fe / ti`（S＝设备组台数）；**各工序能力不等时，生产线能力由最小工序能力确定**
 - 人力生产能力 `CP ＝ α·(1+β)·M·T`（α＝出勤率，β＝间接作业率，M＝换算人数，T＝计划期制度工作时间）
 - **代表产品算例**（A50×20、B100×30、C125×40、D25×80）：选 C 为代表产品；折合 C 产量＝50×(20/40)+100×(30/40)+125×(40/40)+25×(80/40)＝25+75+125+50＝**275 台**
 - **假定产品工时定额** `tj ＝(50×20+100×30+125×40+25×80)/300 ＝ 36.67 台时`
 - 设备组能力（5 台、单台年有效 4650h）：代表产品法 `M＝5×4650/40＝581 件`；假定产品法 `M＝5×4650/36.67＝634 件`
 - **整体设备效率算例**：工作效率 97.2% × 质量效率 98% × 利用率 93.75% ＝ **89.3%**
 - **盈亏平衡产量** `Q* ＝ F/(P − V)`；例 2600/(1500−850)＝**4 万件**；另一例 150 元/件、变动成本 100 元/件、固定成本 5000 元、年产 200 件
 - 产能扩张途径：传统＝投资自建；现代＝**兼并、联手**（如某航空制造企业兼并某航空制造企业）
- **判读与决策**：瓶颈工序→临时对策（加班/租用/转包）+ 长期对策（重复设置前工序设备、留缓冲库存）；扩产频率不宜过频也不宜过缓。
- **常见错误/反例**：用能力冗余掩盖瓶颈；不动瓶颈只加非瓶颈设备。设备带病/超负荷运转"拼设备追产量"。
- **出处**：〔出处：3.生产能力规划〕

### 3.6 库存控制方法

- **定义/目的**：在"不呆料、不囤料"的前提下做到"不断料"。
- **触发条件**：库存高/周转慢、老断料、要定订货点与安全库存时。
- **操作步骤（五种方法）**：
 1. **定量订货控制法**：`订货点 ＝ 订货周期内的需求量 × 订货提前期 + 安全库存`。
 2. **定期订货控制法**：固定时间间隔下订单（兼顾 A/B/C 中 A 细项控制与成组订货节省费用）。
 3. **月物料计划**：`物料计划量 ＝ 需求量 + 安全库存 − 现有库存 − 在途量`。
 4. **ABC 分析法**：A 级品种占 15% 但库存成本占 70%~80%；B 级品种占 30%、价值占 15%~25%；C 级货币量占 5% 但品种占 55%。
 5. **安全库存设置**：
 - 预测不准型：`安全库存量 ＝ Z × 标准差`（95% 服务水平 **Z＝1.64**）；算例 σ≈9.35t → 安全库存＝1.64×9.35＝**15.33t**（缺货可能 5%）。
 - 供应商缺货型：`安全库存 ＝ 平均每日需要量 × 安全库存天数`（保险储备天数按平均误期天数确定）。
- **量化口径（ABC 策略）**：
 - A 类：建战略合作伙伴关系、动态盘点、JIT 采购、精心预测；四大方法＝管供（准确及时确保供应）、管用（限额发货、消耗过程跟踪）、管节约（定期处理余料/退料/呆料/帐外料）、信息准（业务操作与信息维护同步）。
 - C 类：适当加大进货批量、减少进货次数。
 - B 类：一般控制。
 - 平均采购间隔天数算例：Σ(每批到货间隔期×数量)/总数量＝2040/260≈**约 8 天**；平均误期天数＝(70×1+80×2)/(70+80)≈**2 天**。
- **判读与决策**：A 类缺料 → 优先保供；C 类频繁小批 → 合并批量减次数；库存积压 → 用"库存原因鱼刺分析"分部门定位。
- **常见错误/反例**：安全库存一刀切、不分类；把 α 安全系数当常态不改善。
- **出处**：〔出处：1.供应链管理〕

### 3.7 采购订单跟催与交期管理

- **定义/目的**：确保供应商按时按量交货，减少缺料。
- **触发条件**：供应商老延期、交期不可控时。
- **操作步骤**：
 - **采购一般流程（12 步）**：搜集信息 → 询价 → 比价议价 → 评估 → 要样 → 决定 → 请购 → 订购 → 协调沟通 → 催交 → 验收 → 付款。
 - **采购批量确定**：按需定量(Lot-for-Lot，适合采购费用比库存费用低)；经济订购批量(EOQ，适合需求较稳定)；周期订购批量(POQ，适合需求多变)。
 - **预防供应商延期 5 招**：①下单后定期电话问进度 ②访问供应商做进度控制 ③发现说做不一致尽快向上报告投诉 ④不断提醒交期责任 ⑤随时准备后备供应商。
- **量化口径**：
 - **物料短缺八大原因**：紧急订单、供货商脱期、超出预算的损耗、产品设计临时改变、库存记录不正确、资金流转问题、人为疏忽、特发事件。
 - **供应商准时交期管理十法**：计划审核法 / 生产会议逼迫法 / 实绩管理法 / 盯人逼迫法 / 分批采购法 / 量购批入法 / 责任赔偿法 / 进度表监控法 / 预警法（**3~5 日管理、出货提示法**）/ 异状报告法。
 - **采购批量算例**（平均每周需求 100 件、提前期 2 周、库存费 0.2 元/件、调整费 90 元/次）：按需定量 总费用＝40×0.2+8×90＝**728 元**；EOQ＝1150×0.2+3×90＝**500 元**；POQ＝880×0.2+3×90＝**446 元**。
 - 采购订货方式：订单订货 / VMI / 计划订货 / ERP 系统需求拉动 / MILK-RUN / LCL 拼箱。
- **判读与决策**：需求稳定 → EOQ；需求多变 → POQ；采购费远低于库存费 → Lot-for-Lot。交付风险高的关键料 → 用预警法（3~5 日）+ 后备供应商。
- **常见错误/反例**：过了交货期订单不自动取消、拖时交货，给库存与库容带来不便。
- **出处**：〔出处：1.供应链管理〕

### 3.8 入厂物流规划步骤（汽车制造业）

- **定义/目的**：规划物料从供应商到线旁的全过程。
- **触发条件**：新建/改扩建工厂要规划入厂物流与线边配送时。
- **操作步骤（8 步）**：
 1. 物料数据与工艺流程分析
 2. 物料获取与供应方式分析（JIT/JIS/看板/供应商寄存/C 类散料）
 3. 入厂物流规划
 4. 包装容器规划
 5. 物料仓储规划
 6. 缓冲区与旁线物料规划
 7. 物料配送信息系统规划
 8. 物流人员岗位职责及 KPI 设置
- **量化口径**：
 - 五个子系统：生产线子系统 / 超市配送子系统 / 物流装备子系统 / 信息子系统 / 标识子系统——**先分解设计、再平衡**。
 - 供应方式决策：针对不同物料采用 **JIT/JIS 供应、看板供应、供应商寄存库存、C 类散料供应**。
 - 运输方式三选：**Milk Run 定常路线法 / Direct 直接法 / Consolidation 联运法**。
 - 时间窗口：主机厂按供应商每日货量、单车装卸标准时间、车次数、站台收货时间与车位数，给每车分配一个或多个到达时间窗口，避免集中到货与排队隐患。
 - 配载：远距离大件配载约 **8 小时用量**、小件约 **1 天量**；近距离大件约 **4 小时量**、小件约 **8 小时量**（可整合到整包装）。
- **判读与决策**：零件多、距离远、货量不均衡 → 用 Milk Run 循环取货；通用件、量稳定 → 用 VMI。
- **常见错误/反例**：不设时间窗口 → 站台集中到货、资源配置虚高、排队安全隐患。
- **出处**：〔出处：1.供应链管理〕

### 3.9 精益物流单元化与单元化器具

- **定义/目的**：把"几千种具体物料"抽象为"种类有限的规范单元"，提高作业效率、保护品质、提高空间利用率、降本。
- **触发条件**：物料包装乱、周转箱不统一、线边拥堵、要上自动化物流时。
- **操作步骤（单元化原则 5 条）**：①器具结构/尺寸/功能必须规范化 ②种类尽可能少 ③减少物流过程器具更换 ④尽可能通用 ⑤支持 5S 与目视化。
- **量化口径（单元化器具规格原样）**：
 - 集装箱：国际 40 英尺 **L12029 × W2350 × H2393**。
 - 托盘：欧洲标准 1200×1000、1200×800；北美 1200×800；中国 1200×1000；日韩 1100×1100；**ISO 物流尺寸链模数 600×400**。
 - 可堆式周转箱（外径）：**A 300×200×148 / B 400×300×148 / C 400×300×280 / D 600×400×280 / H 600×400×148**（内径分别约 250×150×123 / 350×250×123 / 350×250×255 / 550×350×255 / 550×350×123）。
 - 仓库笼规格示例：C-A-3 800×600×640（线径 6.0mm、网目 50×50、自重 31kg、承重 800kg）～ C-S-9 1550×1120×1000（线径 6.4mm、网目 50×100、自重 113kg、承重 2500kg）。
- **判读与决策**：器具种类多 → 先做种类归并；要上立体库/自动化 → 器具尺寸须符合模数（600×400）。
- **常见错误/反例**："管理专业化、器具标准化、作业规范化"是方向——不标准化就无法支撑自动化与 JIT。
- **出处**：〔出处：2.精益物流〕

### 3.10 物流评价指标（线边与仓库）

- **定义/目的**：给线边物流与仓储的"好不好"定量化门槛。
- **触发条件**：要评价/改善线边布置、仓库利用率时。
- **操作步骤**：按 5 个子系统分别设定输入—处理—输出—评价指标。
- **量化口径（原样保留）**：
 - 步行距离：拿取部品往返距离 **< 4 步**
 - 转身角度：拿取部品转身 **< 90°**；弯腰角度 **< 45°**
 - 搬运重量：每次搬运 **< 15kg**
 - 部品露脸率 ＝（面向作业员的部品种数/工位全部部品种数）×100%
 - 线边部品定置率 ＝（部品定置数/全部部品数）×100%
 - 仓库填充率 ＝（实际使用容积/可使用容积）×100%，基准 **35%~40%**
 - 运输填充率（每台车）＝（实际使用容积/可使用容积）×100%，基准 **50%~60%**
 - 装备使用效率 ＝（装备使用时间/制度工作时间）×100%，基准 **> 70%**
 - 标准作业书制定率 ＝（实际制定标准作业书数/应制定标准作业书数）×100%
 - 部品标识实施率 / 工位器具标识实施率
- **判读与决策**：仓库填充率偏低 → 储位规划或器具不匹配；运输填充率偏低 → 配载/拼箱改善；装备使用效率<70% → 装备选型或路线问题。
- **常见错误/反例**：只追求仓库"塞满"（填充率过高反而影响作业）；忽视露脸率/定置率导致找料时间上升。
- **出处**：〔出处：1.供应链管理〕

### 3.11 缓冲区与在线物料期量标准

- **定义/目的**：确定缓冲区该放多少、何时补料、最大库存，避免线边堆积与断料。
- **触发条件**：设缓冲区、定拉动量与拉动线时。
- **操作步骤（5 公式原样）**：
 1. `响应时间 ＝ 物料计划制作时间 + 供应商准备时间 + 运输时间 + 卸货上库位时间 + 配料上线时间`
 2. `安全库存量 ＝ 一个响应时间 × JPH × 单件产品用量 × 计划调整变化安全系数 / 包装量`
 3. `拉动量(装载量) ＝ JPH × 供货周期 / 包装量`
 4. `拉动线 ＝ 安全库存量 + 响应时间 × JPH × 产品用量`
 5. `最大库存量 ＝ 安全库存量 + 拉动量`（JPH＝Jobs Per Hour 每小时产量）
- **量化口径**：缓冲区建立通用件安全库存，不进 BOM 倒冲、直接发往工位；体积大的部品按小时由仓库直送工位；出现线边质量问题由缓冲区补料再办超领；定期盘点缓冲区及在线物料。
- **判读与决策**：库存低于拉动线 → 触发补货；超过最大库存量 → 停拉，查是否计划波动或包装量设错。
- **常见错误/反例**：供应商越远、响应时间越长，却把安全库存设得越小 → 断料。
- **出处**：〔出处：1.供应链管理〕

### 3.12 需求预测方法（定量）

- **定义/目的**：为生产计划提供合理的需求输入。
- **触发条件**：无订单或订单不足、要靠预测排产时。
- **操作步骤**：
 - **定性**：部门主管集体讨论法、德尔菲法、用户意见征集法。
 - **定量**：移动平均法（一次/二次）、指数平滑法（一次/二次）、季节系数（因子）法、回归分析。
- **量化口径**：
 - **二次移动平均算例**（12 期、N＝5）：线性平滑模型 `Yt+T ＝ 80 + 4.5T`；求 5 个月后 → Y12+5＝80+4.5×5＝**102.5 吨**。
 - **二次指数平滑算例**（α＝0.6，木材销售）：S12[1]＝0.6×16+0.4×14.64＝15.46；S12[2]＝0.6×14.64+0.4×15.81＝15.11。
 - **季节系数法**：ft＝xt/x；某副食品公司例 ft＝1.05/0.90/0.84/1.20，X＝210.875；已知 2004Q1 实际 x1＝331 万元，据 `xt ＝ x1·ft/f1` 预测 Q2/Q3/Q4 及全年。
- **判读与决策**：趋势明显 → 二次移动平均/二次指数平滑；有明显季节性 → 季节系数法。
- **常见错误/反例**：需求多变却用单一均值预测；过度依赖预测而不留安全库存。
- **出处**：〔出处：3.生产能力规划〕

### 3.13 库存影响权重指数（找断料/积压责任部门）

- **定义/目的**：把"库存积压/缺料"按部门和因素量化，定位责任与改善重点。
- **触发条件**：库存问题反复、找不到责任归属时。
- **操作步骤**：
 1. 分析影响库存的因素，设为项目；
 2. 统计去年影响库存因素的项目数与部门；
 3. 计算各部门项目数比重，设为权重指数 F0；
 4. 统计今年项目数，按部门汇总；
 5. 计算项目变化程度 ΔF0 与变化指数 `F ＝ F0(1 + ΔF0)`。
- **量化口径**：某企业 2010 年物料积压按部门——采购部 33 项/23.5%、计划部 7 项/5%、销售部 11 项/7%、车间 6 项/4.1%、仓库 5 项/3.5%、技术工艺部 8 项/5.7%、供应商开发部 65 项/46%、质保部 4 项/2.8%；合计 140 项/100%。2011 年合计 89 项，变化指数合计 63.57。
- **判读与决策**：权重最高的部门就是库存问题的第一责任人（该例为供应商开发部 46%）；结合"造成库存积压的原因/缺料原因"两个 16 项清单逐项核对。
- **常见错误/反例**：把库存问题全归给仓库（该例仓库仅 3.5%）。
- **出处**：〔出处：1.供应链管理〕

## 5. 打法（组合拳）

**打法 1：库存高、周转慢、又老断料 → ABC 分类 + 安全库存 + 月物料计划 + 缓冲区期量标准**
- 第 1 步（先分类）：做 ABC 分析——A 品种 15% 占成本 70–80%、C 占货币 5% 但品种 55%。**产出物：ABC 分类表。**
- 第 2 步（分类施策）：A 类建战略伙伴+动态盘点+JIT 采购+精心预测；C 类加大批量减次数；B 类一般控制。**产出物：分类采购策略。**
- 第 3 步（定安全库存）：预测不准型用 Z×标准差（Z＝1.64@95%）；供应商缺货型用平均每日需要量×平均误期天数。**产出物：安全库存标准表。**
- 第 4 步（跑计划）：月物料计划量＝需求量+安全库存−现有库存−在途量；定量订货的订货点＝订货周期内需求量×提前期+安全库存。**产出物：月度物料计划 + 订货点清单。**
- 第 5 步（线边兜底）：缓冲区按 §3.11 五公式定安全库存/拉动量/拉动线与最大库存量。**产出物：缓冲区期量标准表。**
- 判读：仍断料 → 查是不是安全库存一刀切、或响应时间没算全（漏了配料上线时间）。

**打法 2：供应商老延期、催不动 → 跟催流程 + 交期十法 + 采购批量**
- 第 1 步：走采购 12 步流程，重点放在"催交"。**产出物：采购跟催台账。**
- 第 2 步：按物料/供应商用交期十法中的适用法——关键料用预警法（3~5 日管理、出货提示法）+ 异状报告法；量不稳用分批采购法/量购批入法。**产出物：分类跟催策略。**
- 第 3 步：比对我方批量策略——需求稳用 EOQ、需求多变用 POQ、采购费远低于库存费用 Lot-for-Lot。**产出物：批量决策表。**
- 第 4 步：随时备后备供应商；对反复延期走责任赔偿法。**产出物：后备供应商名单。**
- 判读：仍延期 → 回查物料短缺八大原因，逐条排除。

**打法 3：产能不足或过剩 → 产能测算 → 平衡 → 瓶颈对策**
- 第 1 步（算产能）：`M ＝ S·Fe/ti`，多品种用代表产品（产量×劳动量最大者）或假定产品换算法。**产出物：产能测算表。**
- 第 2 步（找瓶颈）：生产线能力由最小工序能力确定，定位瓶颈工序。**产出物：瓶颈工序清单。**
- 第 3 步（短期对策）：瓶颈加加班/租用设备/转包；瓶颈前留缓冲库存；重复设置前工序设备。**产出物：临时产能方案。**
- 第 4 步（长期决策）：在"扩能投资"与"能力不足机会成本"间求平衡；必要时用兼并/联手扩产（如某航空制造企业兼并某航空制造企业）。**产出物：产能规划方案。**
- 判读：加非瓶颈设备 → 白花钱，瓶颈未动则产出不变。

**打法 4：物料断料、说不清责任 → 库存权重指数 + 短缺八因**
- 第 1 步：用 `F ＝ F0(1+ΔF0)` 算各部门权重指数，找第一责任人（某例供应商开发部占 46%）。**产出物：库存权重指数表。**
- 第 2 步：对照"造成库存积压的原因/缺料原因"16 项清单逐项核对。**产出物：原因清单 + 责任部门。**
- 第 3 步：对占比重的原因定改善动作与责任人。**产出物：改善计划。**

## 6. 案例（保留数据）

**案例 1：某航空制造企业兼并某航空制造企业（产能扩张途径）**〔出处：3.生产能力规划〕
- 背景：某航空制造企业需扩产，而某航空制造企业竞争力下降（世界民机份额由 22% 降至兼并前不足 10%）。
- 做法：1996 年 12 月 14 日签署合并协议，某航空制造企业成为某航空制造企业全资子公司。
- 结果：截至 1996 年 12 月 31 日，某航空制造企业与某航空制造企业分别占世界客机市场份额的 64% 和 6%；合并后由三家垄断变为某航空制造企业与空客两强竞争。
- 可迁移点：**现代企业产能扩张途径＝兼并、联手**，区别于传统自建投资。

**案例 2：某企业库存积压按部门权重分析**〔出处：1.供应链管理〕
- 背景：2010 年物料积压按项目统计共 140 项，需定位责任部门。
- 做法：按部门汇总项目数并算权重指数。
- 结果：采购部 33 项/23.5%、供应商开发部 65 项/46%、技术工艺部 8 项/5.7%、销售部 11 项/7%、计划部 7 项/5%、车间 6 项/4.1%、仓库 5 项/3.5%、质保部 4 项/2.8%。2011 年降至 89 项，变化指数 63.57。
- 可迁移点：**库存问题的第一责任常在采购/供应商开发，而非仓库**。

**案例 3：春季/季度需求预测（季节系数法）**〔出处：3.生产能力规划〕
- 背景：某副食品公司 2000–2003 各季度销售额，已知 2004Q1 实际 331 万元。
- 做法：求同季算术平均 xt 与总平均 X，季节系数 ft＝xt/x（1.05/0.90/0.84/1.20），据 `xt＝x1·ft/f1` 预测。
- 结果：可预测 2004 年二、三、四季度及全年销售额。
- 可迁移点：有季节性时用季节系数法，比单一均值更贴近实际。

## 7. 反例清单

| 错误做法 | 后果 | 正确做法 | 出处 |
|---|---|---|---|
| 各部门各管一段、考虑自身利益 | 过量库存与缺货并存、反应慢 | 建内部客户服务与过程评审监督机制、整体最优 | 1.供应链管理 |
| BOM 不唯一/设计部门不及时更新 | 扣料出错、装配出错、库存增加、交期无保证 | 每项物料唯一编码，建 BOM 更改规范与考核制度 | 2.企业资源计划；1.供应链管理 |

## 9. 本册证据缺口

- **"牛鞭效应(Bullwhip Effect)"未在语料中出现**：语料仅在 SCM 背景强调"信息共享""从部分最优到整体最优""推动型转拉动型"，**未出现"牛鞭效应"术语及其专门对策清单**（如缩短提前期、信息共享、减少批量等）。本册不编造，如实标注为未覆盖。
- **"水蜘蛛(Water Spider)"与"超市补货/看板补货"具体操作步骤缺失**：语料有"超市配送子系统""看板拉动""空箱返回""顺序供给"及拉动物料系统 8 环节（零件订购/供应商/包装/运输/接收/临时仓库/物料拉动系统/装配线），但**无"水蜘蛛"一词**，也无补货触发规则的详细展开。
- **退货(Return)流程细节缺失**：三大构成要素中仅出现"REVERSE（退货/废弃物/容器返空）"，**无逆向物流的作业步骤与表单**。
- **ERP 与精益生产关系的直接论述缺失**：语料从 MRP/BOM/PMC 角度讲了 ERP，但**未正面论述"ERP 与 JIT/看板的冲突与协调"**（另见分册 C 从 MES 角度的相关论述）。
- **生产能力规划中的"学习曲线""决策树/线性规划求解"未展开**：语料给出线性规划模型构成与示例方程、盈亏平衡、代表/假定产品换算法，但未展开学习曲线与产能扩张决策树方法。
- **不可用源文件**：本册语料（`7.精益-供应链` 3 份 + `2.企业资源计划`）全部可读，无乱码或空文件。
