# 精益生产专家 · Lean Production Expert

> 一个**精益生产 / TPS 领域**的 AI 助手技能包（可安装到 WorkBuddy 等支持 Skill 的宿主）。
> 它不背名词，而是把「感觉有问题」翻译成「可测量的停滞与损失」，再把损失翻译成工具、动作和年化金额——
> 并在开口之前，先把那些**听起来很对但其实错了的行业常识**拦下来。

## 这是什么

一个**双层结构**的领域专家技能：

| 层 | 内容 | 规模 | 回答什么 |
|---|---|---|---|
| **执行层** | 16 分册：精益系统 / JIT / 自働化 / 方针与日常管理 / TPM / 供应链 / 数字化 / 质量管理 / 现场班组 / QC 七工具新旧 / 推行导入 / 推行工具实战 / 持续改善 | 47.1 万字 | **怎么做** |
| **认知层** | 六轨深度调研（行业大佬 / 工具选型逻辑 / 工作流 / 知识正典 / 信息源 / 术语标准）叠加 **8 本经典著作原文级蒸馏** | 12.5 万字 + 298 万字语料 | **怎么想 / 为什么这么做 / 这说法对吗** |

## 核心能力

1. **先纠错再开方** —— 已核实 **9 处**行业流行谬误（详见下方）
2. **诊断开方** —— 效率 / 交期 / 库存 / 成本 / 质量 / 设备 / 班组 / 供应链 / MES 场景，先问基线数字再给公式阈值与工具组合
3. **VSM 按原典画** —— Rother & Shook《学习观察》现状图四步 + 未来状态 8 问 + 7 条准则
4. **负荷与成熟度诊断** —— 负荷−产能=缺口、Mura→Muri→Muda 传导链、I 型/II 型浪费、四种成熟度评估
5. **心智模型校准** —— 6 个模型，每个附失效场景
6. **选型与反模式拦截** —— 6 棵决策树 + 25 条外行反模式 + 8 条实施失效模式
7. **推行时序** —— 13 步落地路线，含 12 个月排程与前置条件
8. **画图与找资料** —— VSM / 布局 / 流程图路由；课件表单的主题地图

## 最值钱的部分：9 处事实校正

**错误的行业常识比没有常识更危险**——它会让人理直气壮地做错事。

| # | 流传的说法 | 实际 |
|---|---|---|
| 1 | 《新丰田生产方式》是大野耐一写的 | ❌ 作者是**门田安弘** |
| 2 | 大野耐一仍在出书 | ❌ 生卒 **1912-02-29 — 1990-05-28** |
| 3 | 精益五大原则是丰田官方定义 | ❌ 是**沃麦克与琼斯的外部重构**；丰田官方是 JIT + 自働化两根柱 |
| 4 | 丰田 14 项原则是丰田明文 | ❌ 是**莱克（Liker）的学者归纳** |
| 5 | 今井正明 2024 年去世 | ❌ **2023-06-12** |
| 6 | 新乡重夫是丰田雇员 | ❌ 主要在**旭化成**等化学企业与日本能率协会任职，是外部顾问 |
| 7 | Borel《Manufacturing Excess》/ Callahan《Toyota Catalysts》 | ❌ **两书均无法核实**，判定误记 |
| 8 | 三个 M（Muda/Muri/Mura）是并列关系 | ❌ **是因果链**：Mura → Muri → Muda |
| 9 | 大野原文用「自働化」 | ❌ 1978 中译本**全书 29 处均写「自動化」** |

> 第 8、9 条是**本技能自身曾犯过的错**，已据原文自纠——
> 这套纪律对自己和对行业一视同仁。

## 诚实边界

这套技能**明确知道自己的局限**，并写在了 `SKILL.md §7` 与 `§12`：

- 班组安全管理、牛鞭效应、水蜘蛛、逆向退货流程等主题**语料未覆盖**
- IMA 订阅知识库的**课件正文**受导出保护，只能取到简介级信息
- 精益效果的**学术实证结论并不都正面**：与运营绩效相关，与财务绩效弱相关；
  JIT 与自働化效果最强，而 Kaizen/TPM/VSM 部分研究显示效应偏低甚至为负；
  失败率常被估 60–90%。—— 这些**如实写入**，不做宣传口径的美化。
- 一手来源占比约 35%（中文圈精益一手材料客观稀缺，丰田官方与 LEI 主要是英文/日文）
