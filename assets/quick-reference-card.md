## B. 必背公式

| 指标 | 公式 | 参照 |
|---|---|---|
| 节拍 T/T | 可用工作时间 ÷ 客户需求数量 | C/T > T/T 即瓶颈 |
| 周期 C/T | 一件产品的全部手工操作时间（观测 10 次取最小值） | 快过 T/T = 假效率 |
| 编成效率 | Σ各工程时间 ÷（PT × 工程数）× 100 | 目标 ≥90% |
| OEE | 时间稼动率 × 性能稼动率 × 良品率 | 世界级 >85% |
| 时间稼动率 | 运转时间 ÷ 负荷时间 | — |
| 前置时间 L/T | 情报前置时间 + 制造前置时间 | 案例 16H → 0.3H |
| 制造前置时间 | （工程内半成品 + 1 箱收容数）× Takt | — |
| 增值比 | 增值时间 ÷（生产周期天数 × 每日工时） | 实测例 0.85% |
| 外协看板张数 | 日使用量 ÷ 盛装数 × [a(c+1)/b] + 安全天数 | 示例取整 8 张 |
| 直方图组数 | K = 1 + 3.32 log N | — |
| 直方图组距 | H = R / K（R = 最大值 − 最小值） | — |
| Cpk | min[(USL−X̄)/3σ, (X̄−LSL)/3σ] | 配 Ca/Cp 双套等级表 |
| X̄-R 管制界限 | CL ± 3σ（用 A2 / D3 / D4 / d2 系数，n=4 时 A2=0.729、D4=2.282、D3=0、d2=2.059） | **绝不可用规格界限代替** |
| QCC 目标值 | 现况值 + (1 − 现况值) × 改善重点 × 圈能力 | — |
| QCC 达标率 | (改善后 − 改善前) ÷ (目标值 − 改善前) | ≥100% 才算达标 |
| 年化绩效 | 月绩效 × 12 | — |
| 生产能力 | m = Fe / ti；M = S·Fe / ti | — |

## C. 12 条底层判据（用来"卡"方案）

1. 价值只能由最终客户定义。
2. 真效率 = 用最少的人生产仅需要的量；超产是最严重的浪费。
3. 停滞即是浪费；看停滞有没有变短、钱有没有落袋。
4. 不先标准化，就没有改善的资格（SDCA → PDCA）。
5. 拉动优于推动。
6. 异常必须停（仅 Run Stop 立即停，其余按 FPS）。
7. 三现主义 + 用数据说话。
8. 先分层，再分析（4M1E）。
9. 质量源于源头，不靠检验兜底（不接收/不制造/不流出）。
10. Muda / Muri / Mura 一起治。
11. 成果必须年化成金额或时间。
12. 精益是每天一点点（改善），不是一次性大项目（革新）。

## D. 诊断五步（默认输出骨架）

1. **确认是不是问题** —— 问清：客户要什么 / 现状数字 / 是维持问题还是改善问题 / 范围边界 / 谁执行多久
2. **分层诊断** —— 系统层（前置时间）→ 流程层（编成效率）→ 工序层（损失构成）→ 缺陷层（主因）→ 稳定层（管制图）
3. **开方** —— 工具组合：做什么 → 谁做 → 什么表单 → 多久 → 什么数字算成
4. **固化** —— 标准化 + 指标（口径/目标线/不良线/责任人/频次）+ 年化效益 + 点检机制
5. **声明边界** —— 证据范围 / 语料缺口 / 哪些数字是"某企业实测"

## E. 三条纪律

- **不编数据**：语料没有就说没有。缺口清单见 SKILL.md §7。
- **不把案例当基准**：OEE 57.1%、编成效率 90%、提案数 61.6 vs 0.4 都是**某企业实测**。
- **不忘出处**：每条结论标 `〔出处：文件名〕`。

## F. 最容易忘的 8 个数字

| 数字 | 含义 |
|---|---|
| **≥90%** | 生产线编成效率目标线 |
| **>85%** | OEE 世界级水位 |
| **≥70%** | 柏拉图前 2-3 项累计占比（则只改这几项） |
| **0.85%** | 某案例的增值比（说明大量时间在停滞） |
| **≤20 项** | 方针管理年度目标项数上限（最好 ≤15） |
| **10-15%** | 方针向下展开时下层目标加严幅度 |
| **30 天** | 现场整理"要/不要"的判定线（30 天用不着即移出） |
| **×12** | 月绩效换算年绩效的系数 |
